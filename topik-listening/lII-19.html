TOPIK II 19번 · 중심 생각 고르기 · The main point · 대본 · Script

👩요즘은 직원을 뽑을 때 지원자의 자격증이나 어학 성적 같은 정량적 점수만 확인하는 기업이 많아진 것 같아요.
👨지원자가 워낙 많다 보니 서류 검토 시간을 줄이려고 어쩔 수 없이 점수로 기준을 두는 거죠.
👩그렇긴 하지만 점수가 높다고 해서 실제 업무 역량이나 소통 능력이 뛰어난 건 아니잖아요. 시험 점수보다는 지원자가 프로젝트를 진행하면서 겪은 문제 해결 경험을 면밀히 평가하는 채용 방식이 더 확산되어야 한다고 봐요.
👨맞는 말씀입니다. 정량적인 수치만으로는 개인의 잠재력을 온전히 파악하기 어렵죠.

여자의 중심 생각으로 가장 알맞은 것을 고르십시오.

  • 1지원자의 어학 능력과 자격증 취득 기준을 높여야 한다.
  • 2서류 심사에 걸리는 시간을 단축하는 방안을 찾아야 한다.
  • 3점수보다 실제 문제 해결 경험을 평가하여 채용해야 한다.
  • 4신입 사원의 빠른 적응을 위해 소통 교육을 강화해야 한다.

해설 · Explanation

여자는 시험 점수만으로 평가하는 방식의 한계를 지적하며 「시험 점수보다는 지원자가 프로젝트를 진행하면서 겪은 문제 해결 경험을 면밀히 평가하는 채용 방식이 더 확산되어야 한다고 봐요」라고 핵심 주장을 드러내고 있으므로 「점수보다 실제 문제 해결 경험을 평가하여 채용해야 한다.」가 정답입니다. 어학 점수 기준 상향이나 서류 심사 시간 단축은 여자의 주장과 정반대이거나 대화의 중심 생각이 아닙니다.
