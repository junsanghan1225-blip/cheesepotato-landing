중급 03-01: 추측의 단계 (-ㄹ 것 같다 / -나 보다 / -겠군요) · 4분

추측 표현의 결합 규칙

세 표현은 품사와 받침에 따라 붙는 모양이 다릅니다.

* -(으)ㄹ 것 같다 — 받침이 없으면 -ㄹ, 있으면 -을
* -나 보다 / -(으)ㄴ가 보다 — 동사는 -나 보다, 형용사는 -(으)ㄴ가 보다
* -겠군요 — 품사를 가리지 않고 어간에 그대로

오다 — to come (동사)올 것 같아요 · 오나 봐요 · 오겠군요
먹다 — to eat (동사)먹을 것 같아요 · 먹나 봐요 · 먹겠군요
바쁘다 — to be busy (형용사)바쁠 것 같아요 · 바쁜가 봐요 · 바쁘겠군요
적다 — to be few (형용사)적을 것 같아요 · 적은가 봐요 · 적겠군요
-나 보다 와 -(으)ㄴ가 보다 가 품사로 갈립니다.

동사는 -나 봐요 — 먹다 → 먹나 봐요, 오다 → 오나 봐요
형용사는 -(으)ㄴ가 봐요 — 바쁘다 → 바쁜가 봐요, 적다 → 적은가 봐요

다만 있다·없다 는 형용사처럼 보여도 -나 봐요 를 씁니다 — 없나 봐요 (○), 없은가 봐요 (✕).

-겠군요 는 품사를 가리지 않고 어간에 바로 붙습니다.
손님이 많이 올 것 같아요.I think a lot of guests will come. — 근거 없는 짐작
식당에 줄이 긴 걸 보니 맛있는가 봐요.Judging by the long line, the food must be good. — 형용사 → -(으)ㄴ가 봐요
하루 종일 걸으셨으니 다리가 아프겠군요.You walked all day, so your legs must ache. — 듣고 공감
