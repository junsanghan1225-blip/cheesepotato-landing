2강. 일상 구어의 만능 연결 (-아/어 가지고)

중급 63: 시간과 순서를 나타낼 때 · 4분

앞의 상태를 유지하며 이어가거나 구어에서 이유를 나타낼 때

-아/어 가지고 는 한국인이 일상 대화(말)에서 가장 흔하게 쓰는 연결 표현 중 하나입니다.

1. 수단과 순서 (원래 용법): 앞의 행동을 마친 상태로 다음 행동을 함
> 과일을 깎아 가지고 방으로 들어왔어요.
> 도시락을 싸 가지고 공원에 소풍을 갔습니다.

2. 이유와 원인 (구어 확장): '-아서/어서' 대신 대화에서 이유를 설명할 때
> 어제 비가 너무 많이 와 가지고 약속이 취소됐어.
> 길이 막혀 가지고 약속 시간에 조금 늦었습니다.

💡 말맛 팁: 일상 구어에서는 흔히 줄여서 -아/어 갖고 로 발음합니다. 공식적인 보고서나 글에는 쓰지 않습니다.

양성 모음 (ㅏ, ㅗ)싸다 / 모으다 · 싸 가지고 / 모아 가지고 · 싸 갖고 / 모아 갖고
음성 모음 (ㅓ, ㅜ 등)챙기다 / 만들다 · 챙겨 가지고 / 만들어 가지고 · 챙겨 갖고 / 만들어 갖고
하다 동사준비하다 / 연락하다 · 준비해 가지고 / 연락해 가지고 · 준비해 갖고 / 연락해 갖고
이유 용법 (형용사)바쁘다 / 춥다 · 바빠 가지고 / 추워 가지고 · 바빠 갖고 / 추워 갖고
주말에 먹으려고 집에서 반찬을 넉넉히 만들어 가지고 왔어요.To eat on the weekend, I made generous side dishes at home and brought them.
어제는 날씨가 너무 추워 가지고 하루 종일 집에만 있었어요.Yesterday the weather was so cold, so I stayed only at home all day long.
퇴근하면서 필요한 서류를 미리 챙겨 가지고 나왔습니다.While leaving work, I packed the necessary documents in advance and stepped out.
격식체(글) vs 비격식체(말)
- 말할 때(구어): "늦어 가지고 못 갔어요", "사 가지고 왔어요" (자연스럽고 생생함)
- 글쓸 때(문어): "늦어서 못 갔습니다", "구입하여 왔습니다" ('-가지고'는 글에서는 자제)
