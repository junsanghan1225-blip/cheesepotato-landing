How to use it

  • The first row shows the name. Trace the light letters in rows 2–4, then write it on your own in the empty rows.
  • Korean is written top to bottom and left to right inside each block. The dashed cross helps keep each block square.
  • Section 2 lists every consonant and vowel in the name with its Korean name and sound.
  • Teachers: type each student’s name and print one sheet each — a nice first-class activity.
