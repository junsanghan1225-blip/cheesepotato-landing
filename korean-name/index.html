How it works

Korean writes foreign names by sound, one syllable block at a time. Common names (Emily → 에밀리, Michael → 마이클, Nguyen → 응우옌) use the spelling Koreans usually see. Japanese names follow the standard Japanese-to-Korean rules (Yuki → 유키). Other names are estimated from their sound.

Under your name you see each block in English letters (Revised Romanization), so you can read it out loud.
