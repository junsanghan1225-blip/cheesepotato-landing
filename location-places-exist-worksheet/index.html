Location, Places & Existence · 위치 · 장소 · 있다/없다

Position nouns, common places, and the existence verbs 있다 and 없다. 앞 · 뒤 · 위 · 아래 위치 표현, 주요 장소 명칭, 있다 · 없다 문장

1 · Position & Direction Words · 위치와 방향 명사
PositionKoreanPositionKorean
On / Above / Up위Under / Below / Down아래 / 밑
In front of앞Behind뒤
Inside안Outside밖
Beside / Next to옆Between사이
Left side왼쪽Right side오른쪽

Sentence pattern: Noun + 위치 + 에 있어요. For example: 책상 위에 있어요 (It is on the desk).

2 · Everyday Places · 자주 가는 장소
PlaceKoreanPlaceKorean
House / Home집School학교
Company / Office회사Hospital병원
Pharmacy약국Supermarket마트
Restaurant식당Cafe카페
Bank은행Park공원
Restroom화장실Convenience store편의점

To ask where a place is: [장소]이/가 어디에 있어요? For example: 화장실이 어디에 있어요? (Where is the restroom?)

3 · Existence Verbs: 있다 and 없다 · 존재와 소유: 있다 · 없다
MeaningBasic formPolite present (해요체)Formal present (합쇼체)
To exist / To have있다있어요있습니다
Not exist / Not have없다없어요없습니다

Use the particle 이/가 for the subject: 우산이 있어요 (I have an umbrella). 시간이 없어요 (I don't have time).

How to use it

  • Learn the fundamental position words: 위 (on), 아래 (under), 앞 (front), 뒤 (back), 안 (inside), 옆 (next to).
  • Practice using the location pattern: [Noun]이/가 [Place / Position]에 있어요 / 없어요.
  • Solve Practice A to D and verify your answers using the answer key.

한국어

기초 위치 명사(위, 아래, 앞, 뒤, 안, 밖, 옆), 일상 주요 장소(집, 학교, 회사, 병원, 은행...), 그리고 존재·소유를 나타내는 있다/없다 문형을 한 장에 정리했습니다. 위치와 장소 어휘, 있다/없다 선택 연습을 풀고 정답지로 확인하세요.
