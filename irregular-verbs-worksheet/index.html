Irregular Verbs: ㅂ, ㄷ & 르 · 동사 · 형용사 불규칙 활용: ㅂ · ㄷ · 르

Rules and patterns for ㅂ-irregular, ㄷ-irregular and 르-irregular verbs and adjectives. ㅂ 불규칙, ㄷ 불규칙, 르 불규칙의 어미 결합 규칙과 예외

1 · ㅂ-Irregular Verbs & Adjectives · ㅂ 불규칙 용언
Base wordMeaningVowel change rulePolite form (해요체)Regular exception
춥다To be coldㅂ changes to 우추워요입다 → 입어요 (regular)
덥다To be hotㅂ changes to 우더워요잡다 → 잡아요 (regular)
맵다To be spicyㅂ changes to 우매워요접다 → 접어요 (regular)
어렵다To be difficultㅂ changes to 우어려워요뽑다 → 뽑아요 (regular)
돕다To helpㅂ changes to 오 (special)도와요곱다 → 고와요 (special)

When followed by a vowel suffix (-아/어 or -(으)-), final ㅂ changes to 우 (or 오 for 돕다 and 곱다). Regular exceptions keep ㅂ: 입다 → 입어요, 잡다 → 잡아요.

2 · ㄷ-Irregular Verbs · ㄷ 불규칙 동사
Base wordMeaningVowel change rulePolite form (해요체)Regular exception
듣다To listen / hearㄷ changes to ㄹ들어요받다 → 받아요 (regular)
걷다To walkㄷ changes to ㄹ걸어요닫다 → 닫아요 (regular)
묻다To ask (a question)ㄷ changes to ㄹ물어요믿다 → 믿어요 (regular)
싣다To load (cargo)ㄷ changes to ㄹ실어요얻다 → 얻어요 (regular)

When meeting a vowel suffix (-아/어, -(으)면), final ㄷ becomes ㄹ. Regular exceptions keep ㄷ: 받다 (받아요), 닫다 (닫아요), 믿다 (믿어요).

3 · 르-Irregular Verbs & Adjectives · 르 불규칙 용언
Base wordMeaningDoubled ㄹ rulePolite form (해요체)Example sentence
빠르다To be fastDrop 으, add ㄹ to previous syllable빨라요비행기가 빨라요.
부르다To call / singDrop 으, add ㄹ to previous syllable불러요노래를 불러요.
모르다To not knowDrop 으, add ㄹ to previous syllable몰라요그 소식을 몰라요.
고르다To chooseDrop 으, add ㄹ to previous syllable골라요선물을 골라요.
다르다To be differentDrop 으, add ㄹ to previous syllable달라요생각이 서로 달라요.

When 르 meets -아/어, 으 drops, a ㄹ is added as 받침 to the preceding syllable, and 라/러 is appended: 빠르다 → 빨 + 라요 = 빨라요.

How to use it

  • Remember that ㅂ turns into 우 (or 오 for 돕다/곱다) when meeting a vowel ending.
  • Pay attention to ㄷ changing to ㄹ before vowels (듣다 → 들어요), while remembering regular verbs like 받다 (받아요).
  • For 르 verbs, drop 으 and double the ㄹ (빠르다 → 빨라요). Solve Practice A to D.

한국어

한국어의 대표적인 3대 불규칙인 ㅂ 불규칙(춥다→추워요), ㄷ 불규칙(듣다→들어요, 규칙 예외 받다→받아요), 르 불규칙(빠르다→빨라요)의 원리와 활용 연습을 한 장에 정리했습니다. 문제를 풀고 정답지로 확인하세요.
