퀴즈 Quiz

Q1Which sentence correctly uses the object marker 을/를?

  • ① 신문를 읽어요.
  • ② 신문을 읽어요.
  • ③ 신문이 읽어요.
  • ④ 신문에 읽어요.

신문 ends with a final consonant (ㄴ), so it requires the object marker 을.

Q2Which sentence has an INCORRECT object marker?

  • ① 편지를 써요.
  • ② 우유를 마셔요.
  • ③ 창문를 열어요.
  • ④ 라면을 끓여요.

창문 ends with a final consonant (ㄴ), so it must take 을 (창문을 열어요).

Q3Which particle correctly completes: '부모님께 안부 전화___ 드렸어요'?

  • ① 를
  • ② 을
  • ③ 이
  • ④ 과

전화 ends with a vowel, so the object marker 를 attaches to complete the object of 드렸어요.

Q4Why is '빵을 먹어요' correct instead of '빵를 먹어요'?

  • ① 빵 ends with a vowel.
  • ② 빵 ends with a final consonant (ㅇ).
  • ③ 빵 is a subject.
  • ④ 빵 indicates location.

Because 빵 has a final consonant (받침 ㅇ), it takes 을 instead of 를.

Q5Which sentence correctly marks the object in: 'I bought shoes yesterday'?

  • ① 어제 신발이 샀어요.
  • ② 어제 신발을 샀어요.
  • ③ 어제 신발에 샀어요.
  • ④ 어제 신발로 샀어요.

신발 is the object of the transitive verb 샀어요 (bought), so it takes 을.
