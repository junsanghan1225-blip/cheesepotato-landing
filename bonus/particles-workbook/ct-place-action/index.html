퀴즈 Quiz

Q1Which pair contrasts static existence versus an active behavior correctly?

  • ① 방에서 자요 / 방에서 침대가 있어요
  • ② 방에 침대가 있어요 / 방에서 잠을 자요
  • ③ 방에 자요 / 방에 침대가 있어요
  • ④ 방을 자요 / 방을 침대가 있어요

침대가 있다 is static existence taking 에, while 잠을 자다 is an action taking place inside the room taking 에서.

Q2Which particle fits in: '저는 매일 헬스장___ 열심히 운동해요'?

  • ① 에서
  • ② 에
  • ③ 을
  • ④ 보다

Exercising (운동하다) is an active dynamic behavior, so it requires 에서.

Q3Which sentence has an INCORRECT particle?

  • ① 식당에서 점심을 먹어요.
  • ② 거실에 소파가 있어요.
  • ③ 공원에 축구를 했어요.
  • ④ 교실에서 시험을 봐요.

Playing soccer (축구를 하다) is a dynamic action, so the location must be marked by 에서 (공원에서 축구를 했어요).

Q4Fill in the blank: '지갑이 가방 안___ 들어 있어요.'

  • ① 에
  • ② 에서
  • ③ 으로
  • ④ 까지

들어 있다 expresses the static state of being inside, which takes 에.

Q5Which sentence correctly uses 에 for the destination and 에서 for the place of the action?

  • ① 친구 집에 가서 거기에서 저녁을 먹었어요.
  • ② 친구 집에서 가서 거기에 저녁을 먹었어요.
  • ③ 친구 집에 가서 거기에 저녁을 먹었어요.
  • ④ 친구 집에서 가서 거기에서 저녁을 먹었어요.

가다 takes the destination particle 에 (친구 집에 가서). Eating is an action done at that place, so it takes 에서 (거기에서 저녁을 먹었어요).
