Polite Present Tense: -아요 / -어요 / 해요 · 해요체 현재형 만들기

How to turn a dictionary form into the everyday polite present tense. 사전형(-다)을 일상 존댓말 현재형으로 바꾸는 법

1 · The rule in one line · 한 줄 규칙

Remove 다 from the dictionary form to get the stem. If the last vowel of the stem is ㅏ or ㅗ, add 아요. Otherwise add 어요. Verbs ending in 하다 become 해요.

2 · Stems with ㅏ or ㅗ → add -아요 · ㅏ · ㅗ 로 끝나는 어간 → -아요
Dictionary formStemPolite presentMeaning
좋다좋-좋아요to be good
살다살-살아요to live
앉다앉-앉아요to sit
받다받-받아요to receive
가다가-가요to go (가 + 아요 → 가요)
오다오-와요to come (오 + 아요 → 와요)
보다보-봐요to see / to watch (보 + 아요 → 봐요)

When the stem ends in a vowel, the 아 merges with it: 가 + 아요 = 가요 (not 가아요).

3 · All other stems → add -어요 · 그 밖의 어간 → -어요
Dictionary formStemPolite presentMeaning
먹다먹-먹어요to eat
읽다읽-읽어요to read
있다있-있어요to exist / to have
없다없-없어요to not exist / to not have
마시다마시-마셔요to drink (시 + 어요 → 셔요)
주다주-줘요to give (주 + 어요 → 줘요)
배우다배우-배워요to learn (우 + 어요 → 워요)
기다리다기다리-기다려요to wait (리 + 어요 → 려요)

The 어 merges with a vowel-ending stem too: 시 → 셔, 주 → 줘, 우 → 워, 리 → 려.

4 · 하다 verbs → 해요 · 하다 동사 → 해요
Dictionary formPolite presentMeaning
하다해요to do
공부하다공부해요to study
일하다일해요to work
운동하다운동해요to exercise
말하다말해요to speak / to say
좋아하다좋아해요to like

Any noun + 하다 follows the same rule: 요리하다 → 요리해요 (to cook).

5 · Exceptions in one place · 예외 한곳에 모아 보기
Case · 경우Dictionary → polite present · 기본형 → 해요체Meaning · 뜻
Stem ends in ㅡ · ㅡ로 끝나는 어간크다 → 커요 · 쓰다 → 써요 · 바쁘다 → 바빠요 · 예쁘다 → 예뻐요big · to write · busy · pretty
Stem ends in ㅏ · ㅓ (the vowels merge) · ㅏ, ㅓ로 끝남가다 → 가요 · 서다 → 서요 · 만나다 → 만나요to go · to stand · to meet
ㅗ + 아 → ㅘ오다 → 와요 · 보다 → 봐요to come · to see
ㅜ + 어 → ㅝ배우다 → 배워요 · 주다 → 줘요to learn · to give
ㅣ + 어 → ㅕ마시다 → 마셔요 · 기다리다 → 기다려요to drink · to wait
Stem ends in ㅐ · ㅔ (just add 요) · ㅐ, ㅔ로 끝남보내다 → 보내요 · 지내다 → 지내요to send · to spend time
되다 → 돼요되다 → 돼요to become
ㅂ irregular · ㅂ 불규칙춥다 → 추워요 · 덥다 → 더워요 · 맵다 → 매워요 · 쉽다 → 쉬워요 · 어렵다 → 어려워요 · 돕다 → 도와요cold · hot · spicy · easy · difficult · to help
ㄷ irregular · ㄷ 불규칙듣다 → 들어요 · 걷다 → 걸어요 · 묻다 → 물어요to listen · to walk · to ask
르 irregular · 르 불규칙모르다 → 몰라요 · 다르다 → 달라요 · 빠르다 → 빨라요 · 부르다 → 불러요not to know · different · fast · to call
이다 · 아니다학생이에요 · 의자예요 · 학생이 아니에요to be · not to be

Learn the ㅂ · ㄷ · 르 irregulars word by word; these are regular, so do not change them: 입다 → 입어요, 좁다 → 좁아요, 받다 → 받아요, 닫다 → 닫아요. After a vowel use 예요 (의자예요), after a consonant use 이에요 (학생이에요).

How to use it

  • Read the three tables aloud, then fill in practice A–D and check with the answer key.
  • Remember the single rule: ㅏ or ㅗ before 다 → 아요; everything else → 어요; 하다 → 해요.
  • Teachers: ask students to say each answer aloud before writing it.

한국어

사전형에서 다를 떼고(어간), 마지막 모음이 ㅏ · ㅗ 이면 -아요, 그 밖은 -어요, 하다는 해요가 됩니다. 가요 · 와요 · 봐요 · 마셔요 · 줘요처럼 모음이 합쳐지는 것도 연습합니다.
