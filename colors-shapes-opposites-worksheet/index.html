Basic color words, everyday shapes, and common adjective antonym pairs. 기본 색깔 이름, 도형 모양, 자주 쓰는 반대말 형용사

1 · Basic Colors · 기본 색깔
ColorNoun (Color)Adjective baseExample noun phrase
Red빨간색빨갛다빨간 사과 (red apple)
Blue파란색파랗다파란 하늘 (blue sky)
Yellow노란색노랗다노란 바나나 (yellow banana)
Green초록색초록색이다초록색 나뭇잎 (green leaf)
Black검은색검다검은 모자 (black hat)
White흰색 / 하얀색하얗다하얀 눈 (white snow)
Orange주황색주황색이다주황색 귤 (orange tangerine)
Purple보라색보라색이다보라색 포도 (purple grape)

Colors as nouns usually end in 색 (color): 빨간색, 파란색. To modify a noun directly, use descriptive forms: 빨간, 파란, 노란, 하얀, 검은.

2 · Everyday Shapes · 기본 모양
ShapeEveryday KoreanFormal termExample object
Circle동그라미원시계 (clock)
Triangle세모삼각형삼각김밥 (rice triangle)
Square / rectangle네모사각형창문 (window)
Star별 모양—별 (star)
Heart하트 모양—하트 사탕 (heart candy)

Children and everyday speakers usually say 동그라미, 세모, and 네모. Formal (math / school) words are 원, 삼각형, 사각형.

In polite present speech (해요체): 커요/작아요, 많아요/적어요, 좋아요/나빠요, 더워요/추워요, 빨라요/느려요, 쉬워요/어려워요.

How to use it

  • Learn the common color names and practice using them with nouns (e.g., 빨간 사과).
  • Familiarize yourself with native shape words: 동그라미, 세모, 네모.
  • Pair up opposite adjectives to double your vocabulary, and complete Practice A to D.

한국어

기본 색깔(빨간색, 파란색, 노란색...), 일상 모양(동그라미, 세모, 네모), 기초 반대말 형용사 쌍(크다/작다, 많다/적다, 덥다/춥다)을 정리했습니다. 연습 문제를 풀고 정답지로 확인하세요.
