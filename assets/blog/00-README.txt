블로그 글에 넣는 사진을 여기 둔다.

  blog.js 의 블록에서 { "t":"img", "src":"/assets/blog/파일이름.jpg", "alt":"…" }

지킬 것

1. **남의 사진을 가져오지 않는다.** 직접 찍었거나, 우리가 만든 그림이거나,
   상업적 사용이 열린 것(CC0·CC BY)만. CC BY 면 cap 에 출처를 적는다.
   구글 이미지에서 받은 것은 안 된다 — 나중에 연락이 온다.

2. **가로 1600px 이하, 파일 300KB 이하.** 이 사이트는 웹폰트도 안 부르는데
   사진 하나가 2MB 면 앞뒤가 안 맞는다. 줄여서 넣는다.

     # 크기와 무게를 한 번에
     magick 원본.jpg -resize 1600x -quality 82 assets/blog/이름.jpg

3. **파일 이름은 소문자·숫자·하이픈만.** 한글 이름은 주소에서 깨진다.
   글 slug 를 앞에 붙이면 어느 글 것인지 안다 — hangul-jamo-chart.png

4. **alt 를 반드시 적는다.** 눈으로 못 보는 사람에게는 alt 가 사진의 전부다.
   「사진」이나 「이미지」는 alt 가 아니다. 무엇이 찍혀 있는지 적는다.

5. 넣은 뒤 `node tools/check-blog.mjs` 를 돌린다. 파일이 실제로 있는지,
   alt 가 있는지, 너무 무겁지 않은지 본다.
