Essential Korean Particles · 기초 필수 조사

Topic (은/는), subject (이/가), object (을/를), location (에/에서), and with/by particles. 은/는, 이/가, 을/를, 에, 에서, 와/과, (으)로

1 · The Core Three Pairs: Topic, Subject & Object · 기초 3대 조사 쌍
Particle pairGrammar roleAfter consonant (받침 O)After vowel (받침 X)
은 / 는Topic / Contrast (as for)은 (선생님은, 가방은)는 (저는, 친구는)
이 / 가Subject / Specific identifier이 (밥이, 물이)가 (사과가, 날씨가)
을 / 를Direct object (action target)을 (책을, 음악을)를 (커피를, 영화를)

Phonetic rule: nouns ending in a final consonant (받침) take 은, 이, 을. Nouns ending in an open vowel take 는, 가, 를.

2 · Location & Time Particles: 에 vs 에서 · 시간과 장소 조사: 에와 에서
ParticleCore functionCommon verbsExample sentence
에Destination (to)가다, 오다, 다니다학교에 가요.
에Static location (at / in)있다, 없다, 살다지금 집에 있어요.
에Specific point in time (at / on)만나다, 시작하다오후 2시에 만나요.
에서Action location (at / in)공부하다, 일하다, 먹다도서관에서 공부해요.
에서Starting point (from)출발하다, 오다서울에서 부산까지 가요.

Key distinction: use 에 for static presence or movement destinations. Use 에서 for the dynamic location where an action takes place.

3 · Connecting & Tool Particles: 와/과 and (으)로 · 접속과 수단 조사
ParticleFunctionFormsExample sentence
와 / 과And / With (polite/written)Consonant: 과 / Vowel: 와빵과 우유를 사요.
하고And / With (everyday speech)Noun + 하고 (no change)친구하고 영화를 봐요.
(으)로By / With (tool / vehicle)Consonant: 으로 / Vowel & ㄹ: 로버스로 학교에 가요.
(으)로Toward (direction)Consonant: 으로 / Vowel & ㄹ: 로오른쪽으로 가세요.

With (으)로, nouns ending in ㄹ drop the 으: 지하철 + 로 = 지하철로 (not 지하철으로).

How to use it

  • Check whether the preceding noun ends in a consonant (받침) or vowel to choose between 은/는, 이/가, and 을/를.
  • Distinguish between 에 (destination / static presence / time) and 에서 (action venue / starting point).
  • Complete Practice A to D and check your answers with the answer key.
