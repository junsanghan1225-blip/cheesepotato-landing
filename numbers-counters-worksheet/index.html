4 · Telling the time · 시간 말하기

Hours use native numbers + 시 and minutes use Sino-Korean numbers + 분. 3:15 → 세 시 십오 분. 7:30 → 일곱 시 삼십 분 (or 일곱 시 반). 11:05 → 열한 시 오 분.

How to use it

  • Learn the two number systems separately: Sino-Korean for money and minutes, native for counting things and hours.
  • Read the counters table aloud, then do practice A–D and check the answer key.
  • Teachers: ask students to count real objects in the room using 개.

한국어

한자어 수(일 이 삼)는 날짜 · 돈 · 분에, 고유어 수(하나 둘 셋)는 물건 · 나이 · 시에 씁니다. 세는 말(개 · 명 · 마리 · 권 · 잔 · 병 · 살 · 시 · 분 · 원)과 시각 읽는 법을 연습합니다.
