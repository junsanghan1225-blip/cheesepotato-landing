# 표지 부분 글꼴

표지 그림에 쓰는 글자만 뽑은 부분 글꼴이다. 글꼴 자체를 팔지 않으며, 수정한 글꼴에도 원 라이선스(OFL)를 그대로 적용한다.

| 파일 | 원본 | 라이선스 | 쓰는 곳 |
|---|---|---|---|
| `Cafe24Ssurround-grammar-sheets.woff` | 카페24 써라운드(Cafe24 Ssurround) — 카페24(주) | OFL(Open Font License). 상업적 이용 가능, 글꼴 자체를 유료로 파는 것만 금지, 수정 · 재배포 가능(수정본에도 OFL). 결과물이 카페24 홍보에 쓰일 수 있고 원치 않으면 카페24에 연락(운영자 2026-11-11 확인) | `grammar-sheets-beginner.html` |
| `NotoSerifKR-Bold-idioms.ttf` | Noto Serif KR 700 — Google | OFL 1.1 | `korean-idioms.html` |
