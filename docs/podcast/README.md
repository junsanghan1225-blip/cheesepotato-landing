## 한 편의 틀 (5~7분)
1. 인트로 20초 — 오늘의 주제 한 줄
2. 표현 5개 — 각 50~60초: 뜻 → 예문(한국어를 천천히, 영어로 뜻) → 짧은 대화 → 한마디 팁
3. 따라 말하기 40초 — 5개를 한 번씩 천천히
4. 마무리 20초 — 사이트 안내(everykoreans.com 「단어 › 표현」)

## 올리는 순서 (제안)
- 유튜브: 정지 그림(제목 + 표현 5개)을 붙인 영상으로 올리면 자막이 자동으로 달린다(한국어 · 영어). 틀린 곳은 유튜브 화면에서 고친다.
- 스포티파이: 방송 목록(RSS)에 올린 뒤 대본 기능이 있는지 확인(조건은 아직 확인 못 함).
- 대본은 블로그 글로도 올릴 수 있다(검색 입구가 하나 더).
