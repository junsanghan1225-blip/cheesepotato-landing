# 안티 그래비티 작업 지시 — TOPIK I 낱말 채우기 (500개 한 묶음)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해.」

> **지금: 2묶음.** 1묶음(앞 499개, B급)은 main 에 들어갔다. 이번에는 **① 1묶음 고치기 → ② 다음 500개**.

## 왜
치즈감자에 「단어」 섹션을 만든다(`docs/vocab-plan.md`). 첫 대상은 TOPIK I 필수 낱말이다.
`vocab/data/topik1.json` 에 **씨앗 1,997개**가 있다 — 국립국어원 표준 교육과정 어휘 1 · 2급과 우리 자료에서 더한
낱말. 표제어 · 급수 · (있으면) 사전 영어 뜻 · 길잡이말(`hint`)만 있는 **C급**이다.
이것을 학습자가 바로 외울 수 있는 **B급**으로 올린다. 모양은 `docs/vocab-schema.md`.

## ① 먼저: 1묶음 고치기 (약 100줄)
`node tools/check-vocab.mjs --all` 을 돌리면 「예문이 길다」 · 「문법이 초급보다 어렵다」 줄이 나온다. **그 예문만** 다시 쓴다.
1묶음 예문은 너무 길고 꾸밈말이 많았다 — 학습자는 1~2급이다.

| ✗ 너무 어렵다 | ✓ 이렇게 |
|---|---|
| 나른한 오후에 잠을 깨려고 따뜻한 원두커피 한 잔을 마셔요. | 아침에 커피를 마셔요. |
| 주말마다 시골에 계신 인자하신 할머니께 안부 전화를 드려요. | 할머니께 전화를 드려요. |
| 오후부터 하늘이 어두워지더니 비가 내려요. | 오늘 비가 와요. |

영어 번역도 같이 고친다. 1묶음의 다른 칸(topics · rel …)은 손대지 않는다.

## ② 이번 묶음: **grade 가 `"C"` 인 줄 중 앞 500개**
파일은 우리 자료에 자주 나오는 순서로 서 있다. B 줄이 끝난 뒤의 C 줄부터 500개만 한다(모두 4묶음).

낱말마다:
1. **pos** — 비었으면 채운다(명사 · 동사 · 형용사 · 부사 · 대명사 · 수사 · 관형사 · 감탄사 · 의존 명사).
   **en** — 비었으면 채운다(사전식 짧은 영어 뜻, 예: `to eat; to have a meal`). 채워져 있으면 고치지 않는다.
2. **topics** — `vocab/taxonomy.json` 에서 **1~3개**, 「대분류/소분류」 꼴(예: `food/dishes`).
   맞는 칸이 없으면 억지로 넣지 말고 가장 가까운 것 하나 + PR 설명에 「새 칸이 필요한 낱말」로 적는다.
   taxonomy 파일은 고치지 않는다.
3. **purposes** — `topik1` 은 그대로 두고, 맞으면 더한다: `intro`(첫 300개 수준의 아주 기초) ·
   `eps`(직장 · 안전 · 생활) · `life` · `travel` · `work` · `medical`.
4. **en_simple** — 학습자용 쉬운 영어 뜻 1~4단어(`to eat` · `friend` · `because of`). `en` 은 고치지 않는다.
5. **examples** — **두 개**로 맞춘다(이미 하나 있으면 하나 더).
   - 낱말 **하나를 배우는 짧은 문장**. 꾸밈말(나른한 · 정성이 가득 담긴 · 인자하신)을 빼고, 새 낱말을 여럿 넣지 않는다.
   - 빈칸 빼고 **18글자 안팎**(검사기는 22글자를 넘으면 짚는다).
   - 문법은 -아요/어요 · -았/었어요 · -고 · -아서/어서 · -(으)ㄹ 거예요 · -(으)세요 · -고 싶어요 까지.
     -느라 · -더니 · -던 · -도록 · -듯 · -잖아 는 쓰지 않는다.
   - 표제어가 문장에 들어가야 한다(활용형이면 된다). 검사기가 본다.
   - `en` 번역을 반드시 단다. 기존 예문의 번역이 비었으면 채운다.
   - `hint`(길잡이말, 예: 「가게에 가다」)가 있으면 그 짝말을 살려 쓴다 — 표준 교육과정이 권하는 쓰임이다.
   - 새로 쓴다 — 드라마 · 노래 · 기출 문장을 옮기지 않는다.
6. **rel** — 확실한 것만: `syn`(비슷한 말) · `ant`(반대말) · `hon`(높임말, 예: 먹다 → 드시다). 모르면 비운다.
   - `ant` 는 뜻이 **정반대인 짝**만(크다↔작다 · 열다↔닫다). 짝꿍 말(할머니·할아버지 · 형·동생 · 오늘·내일)은 반대말이 아니다.
   - `hon` 은 **이 낱말의 높임말**이다(집 → 댁). 이미 높임말인 낱말(댁 · 성함 · 모시다)에는 적지 않는다. 저 · 제 는 낮춤말이라 hon 이 아니다.
   - `syn` 에 초급 학습자가 모를 한자어(금일 · 양친 · 조모)를 넣지 않는다.
7. **grade** — 위를 다 채웠으면 `"B"` 로 바꾼다.
8. **level** — `std` 가 있는 낱말(표준 교육과정 급수)은 **고치지 않는다.** `std` 가 없는 낱말만, 급수가
   이상해 보이면 고치지 말고 PR 설명의 「급수가 이상한 낱말」에 적는다.

**손대지 않는 것:** `id` · `head` · `freq` · `src` · `std` · `hint` · 채워진 `en`, 그리고 이번 500개 뒤의 C 줄.
낱말이 아닌 것(조사 · 어미 조각 · 사람 이름 「민수」 같은)이 보이면 지우지 말고 PR 설명에 적는다.

## 순서
```bash
git checkout main && git pull origin main
git checkout -b vocab-topik1-b2
# ① 짚힌 1묶음 예문 고치기 → ② C 줄 앞 500개 채우기 — 한 줄에 낱말 하나 모양을 지킨다
node tools/check-vocab.mjs --all  # 「고쳐야 할 것」 0 · B급 999 · 「길다」 「어렵다」 0
git add vocab/data/topik1.json
git commit -m "vocab: TOPIK I batch 2 to grade B (+ batch 1 fixes)"
git pull origin main
node tools/stamp.mjs && node tools/stamp.mjs --check
git push -u origin vocab-topik1-b2
```
**`git push` 까지 해야 끝이다** — 올리지 않으면 운영자와 Claude 가 볼 수 없다.

## PR 설명에 적을 것
- B급이 된 수, 고친 1묶음 예문 수, `check-vocab` 결과(짚어 둘 것 수)
- 새 주제 칸이 필요한 낱말 · 급수가 이상한 낱말 · 낱말이 아닌 줄
