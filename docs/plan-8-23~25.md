## 일요일 저녁 — ElevenLabs (1시간)

**왜 이걸 먼저 하나.** 목소리가 마음에 안 들면 다시 만드는 데 2~6시간이
걸린다. 화요일에 알면 늦다. 오늘 밤에 한 개만 구워 보고 목소리만 확인해
두면, 잘못돼도 월요일에 다시 만들 시간이 있다.

전체 절차는 `docs/tts-windows.md` 에 있다. 여기서는 순서만.

```powershell
cd ~\Documents\cheesepotato-landing
git pull origin main

$env:ELEVEN_API_KEY = "sk_..."
node tools\tts-build.mjs --voices          # 목소리 id 확인 (글자 안 씀)
$env:ELEVEN_VOICE_M = "★ 내 목소리 id"
$env:ELEVEN_VOICE_W = "아무 한국어 여자 목소리 id"

node tools\tts-manifest.mjs --only course --write tts\course.jsonl
node tools\tts-build.mjs --in tts\course.jsonl --limit 1      # 딱 한 개 (12자)
```

`✓` 가 뜨면 들어 본다:

```powershell
start assets\audio\저는_한국_사람이에요.mp3
```

**내 목소리가 맞나?** 맞으면 나머지를 굽는다 (154개 · 1,425자 · 5~10분).

```powershell
node tools\tts-build.mjs --in tts\course.jsonl
```

### 다 구우면 낱자부터 들어 본다

```powershell
start assets\audio\ㄱ.mp3
start assets\audio\ㅏ.mp3
start assets\audio\ㅁ.mp3
```

「ㄱ」이 **「그」** 로 들려야 한다. 「기역」이라고 읽거나 뭉개면 휴대폰
녹음기로 직접 녹음해 같은 이름으로 덮어쓴다. 39개면 10분이고, **한글을
처음 배우는 사람이 가장 먼저 듣는 소리**라 여기만큼은 손으로 할 값이 있다.

```powershell
node tools\stamp.mjs
git add -A ; git commit -m "코스 소리 154개" ; git push origin main
```

`✗` 가 뜨면 — 401=열쇠, 404=목소리 id, 429=크레딧. **422 는 제 쪽 문제이니
그 줄을 그대로 적어 두었다가 저한테 보여 달라.**

## 월요일 — Gemini 로 듣기 문항 (2시간)

### 도는 방법 (한 묶음에 5분)

1. 아래 **주문서**를 하나 골라 복사
2. `docs/listening-gemini-prompt.md` 의 「보낼 글」 + 그 주문서를 Gemini 에 붙여넣기
3. 받은 것을 통째로 `new.json` 에 저장 — **다듬지 말 것.**
   ` ```json ` 울타리나 앞의 설명 문장이 붙어 있어도 도구가 알아서 벗긴다
4. 넣고 검사한다

```powershell
node tools\add-listening.mjs new.json
node tools\check-listening.mjs
```

5. `문제 없음` 이 뜨면 **바로 커밋한다** (묶음마다 커밋해 두면 되돌리기 쉽다)

```powershell
git add -A ; git commit -m "TOPIK II 듣기 7~8번" ; git push origin main
```

> **topik-listening.js 를 손으로 열지 마세요.** 쉼표 하나가 빠지면 그 파일이
> 안 읽히고, 듣기만 죽는 게 아니라 **판 전체가 안 뜬다.** 도구를 쓰면 그럴
> 일이 없다.
>
> `check-listening.mjs` 가 뭘 지적하면 그 항목만 고치면 된다. 아예 되돌리려면
> `git checkout topik-listening.js`.

### 주문서 여덟 개

번호가 작은 것부터. **A~D 는 각 2문항이라 금방 끝난다.**

<br>

**A · TOPIK II 이어지는 말 (7~8번)**
```
이번에 만들 것:
  시험 : TOPIK II    유형 : follow (이어지는 말)
  자리 : 7~8번       급수 : 3급      개수 : 2문항
  id   : lII-07, lII-08

이미 만든 것: 서류 보내기, 회의 시간 바꾸기, 예약 확인
```

**B · TOPIK II 이어서 할 행동 (11~12번)**
```
이번에 만들 것:
  시험 : TOPIK II    유형 : act (이어서 할 행동)
  자리 : 11~12번     급수 : 4급     개수 : 2문항
  id   : lII-11, lII-12

이미 만든 것: 부품 배송 확인, 업체에 전화 걸기
```

**C · TOPIK II 들은 내용과 같은 것 (15~16번)**
```
이번에 만들 것:
  시험 : TOPIK II    유형 : detail (들은 내용과 같은 것)
  자리 : 15~16번     급수 : 4급     개수 : 2문항
  id   : lII-15, lII-16

이미 만든 것: 단수 안내 방송, 도서관 층 안내
```

**D · TOPIK II 중심 생각 (19~20번)**
```
이번에 만들 것:
  시험 : TOPIK II    유형 : main (중심 생각)
  자리 : 19~20번     급수 : 5급     개수 : 2문항
  id   : lII-19, lII-20

이미 만든 것: 안내판 글자 크기, 회의 방식
```

<br>

**E · TOPIK II 긴 담화 (23~30번) — 네 쌍**
```
이번에 만들 것:
  시험 : TOPIK II    유형 : long (긴 담화, 한 대본에 두 문제)
  자리 : 23~30번     급수 : 5급     개수 : 8문항 (네 쌍)
  id   : lII-23 부터 lII-30 까지 차례로
  pair : lII-p2 (23·24), lII-p3 (25·26), lII-p4 (27·28), lII-p5 (29·30)

짝지은 두 문항은 script 를 글자 하나까지 똑같이 두 번 적으세요.
한 쌍은 「중심 생각/화제」와 「세부 내용」을 각각 물으세요.

소재는 대담·인터뷰로. 이미 만든 것: 도시 나무 심기
```

**F · TOPIK II 긴 담화 (31~40번) — 다섯 쌍**
```
이번에 만들 것:
  시험 : TOPIK II    유형 : long
  자리 : 31~40번     급수 : 5급     개수 : 10문항 (다섯 쌍)
  id   : lII-31 부터 lII-40 까지 차례로
  pair : lII-p6 (31·32), lII-p7 (33·34), lII-p8 (35·36),
         lII-p9 (37·38), lII-p10 (39·40)

소재는 강연·대담으로. 이미 만든 것: 도시 나무 심기,
그리고 E 묶음에서 만든 것들 (여기에 적어 주세요)
```

**G · TOPIK II 긴 담화 (41~50번) — 다섯 쌍**
```
이번에 만들 것:
  시험 : TOPIK II    유형 : long
  자리 : 41~50번     급수 : 6급     개수 : 10문항 (다섯 쌍)
  id   : lII-41 부터 lII-50 까지 차례로
  pair : lII-p11 (41·42), lII-p12 (43·44), lII-p13 (45·46),
         lII-p14 (47·48), lII-p15 (49·50)

6급이므로 논설·학술 강연으로. 말하는 사람의 태도와 함축을 묻는 문항을
섞으세요. 이미 만든 것: (E·F 에서 만든 것들을 적어 주세요)
```

**H · TOPIK I 긴 담화 (29~30번) — 한 쌍**
```
이번에 만들 것:
  시험 : TOPIK I     유형 : long
  자리 : 29~30번     급수 : 2급     개수 : 2문항 (한 쌍)
  id   : lI-29, lI-30
  pair : lI-p3

TOPIK I 이므로 쉬운 말로. 안내 방송이나 네 줄짜리 대화면 됩니다.
이미 만든 것: 도서관 삼 층 안내, 영화 시간 바꾸기
```

> 「이미 만든 것」을 **꼭 채워 넣으세요.** 안 적으면 열 문항 중 서넛이
> 같은 소재로 나온다. E 를 끝냈으면 그 소재들을 F 주문서에 적는 식으로.

## 화요일 — 소리 굽고 마무리 (1시간)

문항을 다 만든 뒤에 굽는다. **이미 있는 파일은 건너뛰므로** 어제 구운
글자 카드는 다시 안 구워지고 돈도 안 나간다.

```powershell
cd ~\Documents\cheesepotato-landing
git pull origin main
winget install Gyan.FFmpeg      # 대화를 이어 붙이려면 필요
```

**PowerShell 을 새로 열고** (경로가 새로 잡혀야 한다):

```powershell
cd ~\Documents\cheesepotato-landing
$env:ELEVEN_API_KEY = "sk_..."
$env:ELEVEN_VOICE_M = "..."
$env:ELEVEN_VOICE_W = "..."
ffmpeg -version                 # 나오면 준비 끝

node tools\tts-manifest.mjs --only listen --write tts\listen.jsonl
node tools\tts-build.mjs --in tts\listen.jsonl --limit 1    # 한 개 먼저
node tools\tts-build.mjs --in tts\listen.jsonl              # 나머지
```

문항 75개면 6,000자쯤. 한도(100,000자)의 6% 다.

들어 볼 때 하나만 보면 된다 — **남자와 여자가 실제로 갈려 들리는가.**
안 갈리면 「여자는 무엇을 합니까」를 풀 방법이 없다.

```powershell
node tools\stamp.mjs
git add -A ; git commit -m "듣기 소리" ; git push origin main
```
