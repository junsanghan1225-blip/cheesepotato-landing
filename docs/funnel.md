# 숫자 판 — 운영자 순서 (2026-10-08)

방문 → 공부 시작 → 레벨테스트 → 가입 → TOPIK 연습 → 모의고사 → 가격 화면 → 결제, 단계마다 몇 명이 넘어가는지와
어디서 온 사람(ChatGPT · 구글 · 인스타 …)이 가입 · 결제까지 가는지를 한 쪽에서 본다.

1. Supabase 대시보드 → SQL Editor → `db/add_funnel.sql` 을 통째로 붙여 넣고 Run (한 번만, 두 번 돌려도 괜찮다).
2. https://everykoreans.com 에서 운영자 메일로 로그인한다.
3. https://everykoreans.com/funnel.html 을 연다(검색에는 안 걸린다). 7일 · 28일 · 90일을 고른다.

- 숫자는 1번을 한 날부터 쌓인다. 하루 이틀 뒤부터 볼 만하다.
- 한 기기는 한 단계를 하루 한 번만 센다. 이메일 · 이름은 싣지 않는다(기기에 만든 무작위 id 만).
- 운영자 메일로 로그인한 기기는 세지 않는다. 로그아웃 상태로 둘러보면 세어진다.
- 「새 가입 · 지금 Pro」 타일은 서버 숫자라 가장 정확하다. 단계 막대는 앱 화면에서 센 것 — 사전 · 문항 쪽만 보고 나간 방문은 GA 에만 있다.
