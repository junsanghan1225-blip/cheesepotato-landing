# 문법 설명 영어로 옮기기 — Gemini 지시문

예문 만들기의 문법 290개는 설명이 **한국어뿐이다.** 한국어를 배우러 온 사람에게
한국어로 설명하면 설명이 또 하나의 숙제가 된다. 읽기 지문의 말풍선에도 그
설명이 그대로 나가므로, 영어 화면에서는 이름과 단추만 영어이고 속은 한국어다.

여기서 그 셋을 옮긴다 — `desc`(뜻·쓰임), `form`(형태), `care`(주의할 점).
`ex`·`dlg`·「자주 함께 쓰는 말」은 **안 옮긴다.** 한국어 예문과 한국어 낱말이라
옮길 것이 아니다.

## 하는 순서

한 묶음을 뽑는다 (이미 채운 것은 빠진다):

```bash
node tools/grammar-words.mjs 40 > /tmp/batch.txt
```

`/tmp/batch.txt` 를 아래 지시문 **뒤에** 그대로 붙여 보낸다. 받은 JSON 배열은
`docs/grammar-en.json` 의 배열에 이어 붙이고:

```bash
node tools/build-grammar.mjs && node tools/stamp.mjs
```

`build-grammar.mjs` 가 빠진 칸·겹친 id·옮기다 만 줄을 짚어 준다. 다 채울
때까지 같은 명령을 되풀이한다 — 채운 것은 다음 묶음에서 저절로 빠지므로
어디까지 했는지 따로 적어 둘 것이 없다.

**한 번에 마흔 개씩.** 290개를 한 번에 보내면 한국어만 23,000자다. 뒤로 갈수록
성의가 빠져서 「Used to say something.」 같은 줄이 늘어난다.

## 지시문 (여기서부터 복사)

당신은 외국인을 위한 한국어 교재의 영문 편집자입니다. 한국어로 적힌 문법
설명을 드릴 테니, **한국어를 배우는 영어권 학습자가 읽을 영어 설명**으로
옮겨 주세요.

**JSON 배열 하나만** 출력하세요. 인사말, 설명, 코드 블록 표시를 붙이지 마세요.

### 줄 하나의 모양

```json
{ "id": "51-4", "desc": "…", "form": "…", "care": "…" }
```

- `id` — 드린 것을 **그대로** 옮겨 적으세요. 이것으로 짝을 맞춥니다.
- `desc` — 이 문법이 무슨 뜻이고 언제 쓰는지. **한 문장이나 두 문장.**
  화면의 작은 말풍선에 들어가므로 **160자를 넘기지 마세요.**
- `form` — 어디에 붙는지. 한국어 꼴(`V + 는 바람에`)은 **그대로 두고**
  설명하는 말만 영어로 바꾸세요. 드린 줄에 `form:` 이 없으면 이 칸을 빼세요.
- `care` — 틀리기 쉬운 곳. 드린 줄에 `care:` 가 없으면 이 칸을 빼세요.

### 어떻게 쓰나

1. **기능부터 말하세요.** 「무엇을 하는 말인지」가 첫머리에 와야 합니다.
   - 좋음: `Says that an unexpected event caused the result — and the result
     is usually bad.`
   - 나쁨: `This is a very useful and common Korean grammar pattern that
     learners often encounter.` — 읽고 나도 무엇인지 모릅니다.
2. **평이한 영어로.** 읽는 사람은 영어 원어민이 아닐 수도 있습니다. 문법
   용어를 쓸 때는 흔한 것만 쓰세요 — `verb stem`, `noun`, `past tense`,
   `polite`, `formal` 은 괜찮고, `nominalizer`, `retrospective aspect`,
   `evidential` 은 안 됩니다.
3. **한국어 낱말을 영어 문장에 섞지 마세요.** 다만 **꼴 자체를 가리킬 때는**
   낫표 안에 넣어 그대로 씁니다 — `Attaches to a verb stem: 「-는 바람에」.`
   이것은 번역할 것이 아니라 배울 것입니다.
4. **드린 뜻을 옮기세요. 늘리지 마세요.** 한국어 줄에 없는 규칙·예외·뉘앙스를
   덧붙이지 마세요. 아는 것이 더 있어도 이 자리는 옮기는 자리입니다.
5. **비슷한 문법과 견주는 말은 원문에 있을 때만.** 원문이 「-아/어서와 달리」
   라고 했으면 옮기고, 안 했으면 만들지 마세요.
6. **원문의 말투를 따르세요.** 한국어 설명은 짧고 담담합니다. 영어도 그렇게.
   `!`, `Let's`, `Don't worry`, `Great job` 같은 것을 넣지 마세요.

### 반드시 지킬 것

1. **모르면 그 줄을 빼세요.** 한국어 설명이 무슨 말인지 확실하지 않으면 그
   `id` 를 통째로 내보내지 마세요. **빈 칸은 한국어로 물러서지만, 틀린 영어
   설명은 배우는 사람이 그대로 외웁니다.** 마흔 줄을 다 채우는 것보다 틀린
   줄이 없는 것이 훨씬 중요합니다.
2. **`id` 를 지어내지 마세요.** 드린 것만, 드린 그대로.
3. **`desc` 는 반드시 있어야 합니다.** `form` 과 `care` 는 드린 줄에 있을
   때만 넣습니다.
4. **낫표(「」) 밖에 한글을 남기지 마세요.** 검사기가 잡아냅니다. 소리 나는
   대로 적을 때는 대괄호를 쓰세요 — `written 「-ㄹ 거예요」, said [-ㄹ 꺼에요]`.
   낫표 안과 대괄호 안은 검사에서 뺍니다.
5. **160자.** `desc` 가 길면 말풍선이 글을 덮습니다.

### 보기

드린 줄:

```
## 51-4  |  -는 바람에  |  intermediate  |  까닭 말하기
desc: 예상 밖의 일이 터져서 그 탓에 이렇게 됐다는 뜻입니다.
form: V + 는 바람에
care: 내 뜻과 상관없는 돌발 상황에 씁니다. 뒤에는 대개 안 좋은 결과가 옵니다.
ex:   지하철이 멈추는 바람에 늦었어요.
```

낼 것:

```json
{
  "id": "51-4",
  "desc": "Something unexpected happened, and that is why things turned out this way.",
  "form": "Verb stem + 「-는 바람에」",
  "care": "For events outside your control. What follows is usually a bad outcome."
}
```
