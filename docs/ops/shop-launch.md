# 상점 먼저 열기 — 첫 책 1~2권 (운영자 2026-10-21 「1~2권만 완성해서 우리 상점부터」)

> 70권을 기다리지 않는다. 서점 입점(예스24 등)은 따로 진행하고, **우리 상점 `/shop/` 은 책이 준비되는 대로** 연다.
> 상점 코드는 이미 있다(`docs/shop.json` → `node tools/build-sheets.mjs`). 「사기」 단추는 Polar 결제 링크를 붙이면 켜진다.

## 운영자 할 일 (순서)
1. **검수**: 보낸 PDF(에브리코리안즈_도서검수본_…)를 훑어보고 고칠 곳을 쪽 번호로 알려 주기.
2. **통신판매업 신고증 번호**: 납부 뒤 번호가 나오면 알려 주기 — 상점 아래 사업자 정보 줄에 넣는다(사실만).
3. **Polar 상품 만들기**(책마다): Polar 대시보드 → 상품 → 「한 번 결제」 가격 9.90달러 → 혜택 「파일 다운로드」에 **속지 PDF** 올리기 → 결제 링크 `buy.polar.sh/…` 를 Claude 에게 주기.
   - 올리는 PDF 는 Claude 가 만든 최종본(판권면 빈칸은 「ISBN 없음(자체 배포 PDF)」 같은 사실만 — 아래 ⚠).
4. 링크를 받으면 Claude 가 `docs/shop.json` 의 그 책 `polar` 에 붙이고 상태를 「판매 중」으로 → PR → 머지.

## Claude 할 일
- 검수에서 나온 고칠 곳 반영 → 최종 PDF(속지 · 표지) 만들어 주기.
- 판권면 · 상점 책 쪽 문구(소개 · 목차 · 이런 분께) 사실만 점검. 기출 아님 문구 확인.
- 링크가 오면 상점 켜기 · 자국 · preflight · PR.
- 첫 책이 팔리기 시작하면 사이트의 쓰기 쪽(검색 클릭이 가장 많은 쪽)에서 책으로 가는 링크를 단다.

## ⚠ 운영자가 정할 것 · 확인할 것
- 출판사 이름(`에브리코리안즈 출판` 가안) — 출판 신고 때 쓴 이름과 같아야 한다.
- 자체 PDF 판매에 ISBN 이 필요한지는 **확인 못 했다**(서점 유통에는 책마다 ISBN). 필요하면 서지정보유통지원시스템에서 신청.
- 판매 시작 전: 약관 · 환불 쪽(`terms` · `refund`)이 책(디지털 파일) 판매를 다루는지 점검 — 필요하면 Claude 가 문구를 고쳐 운영자가 확인.
