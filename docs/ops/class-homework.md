# 반 · 숙제 — QR 로 들어오기 · 첫 화면 숙제 · 학생별 진도 (운영자 순서)

2026-10-07 운영자 결정: 반은 **숙제 · 복습용으로만** 쓴다 — 수업 · 결제는 지금처럼(Preply 등) 그대로, 사이트로 데려오지 않는다.
구글 캘린더 일정 연동은 만들었다가 뺐다(같은 날 운영자 「스케줄은 빼자」). 그때 만든 표(`db/add_class_calendar.sql` 의
class_calendar · class_member_cal)는 Supabase 에 남아 있지만 쓰지 않는다 — 지우지 않는다. `class-schedule` 함수를 이미 배포했다면 대시보드에서 지워도 된다(선택).

## 한 번만 하는 것 (운영자)
- Supabase → SQL Editor → `db/add_class_students.sql` → Run (학생 관리 · 레벨 배정 · 학생별 숙제).
- Supabase → SQL Editor → `db/add_class_feedback.sql` → Run (숙제 코멘트).

## 반마다 하는 것 (선생님)
1. 사이트 → 반 · 숙제 → 반 카드의 「📱 QR로 학생 부르기」 → 「QR 그림 저장」 → 학생에게 보낸다.
   학생은 카메라로 찍고 로그인만 하면 그 반에 들어간다(이름은 계정 이름). Preply 학생이면 **정규 수업을 시작한 뒤에만** 보낸다(체험 결제 전 링크 공유 금지 규정).
2. 「＋ 숙제 내기」로 숙제를 낸다.
3. 「학생 관리」 탭 → 학생을 눌러 **레벨**(감자 L0~L7 또는 TOPIK 치즈 급수) · **학생에게 한마디**(학생 첫 화면에 뜸) · **내 메모**(선생님만) → 저장.
   레벨을 정하면 학생은 레벨테스트 없이 그 레벨로 바로 시작한다(학생이 사이트를 열 때 맞춰진다).
4. 1:1 숙제는 「＋ 숙제 내기」의 「누구에게」에서 학생을 고르거나, 학생 카드의 「이 학생에게만 숙제」.
5. 수업을 그만둔 학생은 「📊 진도 리포트」의 학생 카드 → 「반에서 빼기」(숙제 기록은 남는다, 다시 QR 로 들어오면 그대로).

## 학생이 보는 것
- 첫 화면 맨 위 「🏫 반 이름 · 숙제 N개 남았어요」 + 남은 숙제(기한 가까운 것부터) 「하기 →」. 반이 아니면 이 카드는 안 보이고 첫 화면은 그대로.
- 반에 들어오기 전(초대 칸)과 들어온 뒤에 개인정보 안내 한 줄: 선생님이 이름(계정 이름)과 숙제 기록(한 날 · 점수)을 본다 · 숙제 · 복습에만 쓴다 · 언제든 「반 나가기」.

## 선생님이 보는 것
- 「📊 진도 리포트」 → 학생마다 카드(완료율 막대 · 기한 지남 · 평균 점수 · 마지막으로 한 날). 누르면 숙제마다 결과.
  챙겨야 할 학생(기한 지난 숙제)이 맨 위 · 빨간 테두리. 「표로 한눈에 보기」 · CSV 받기.

## 편의 기능
- **오늘 챙길 학생**: 반 화면 맨 위 — 기한 지난 학생(빨강) · 3일 넘게 숙제 기록 없는 학생(노랑) · 이틀 안에 끝냈는데 코멘트 안 단 것(초록). 누르면 그 학생 카드.
- **묶음**: 「＋ 목록에 담고 하나 더」로 여러 개 담고 「N개 한 번에 내기」(같은 학생 · 같은 기한).
- **다시 내기**: 숙제 줄의 「↻ 다시 내기」 → 폼이 그 숙제로 채워짐 → 학생 · 기한만 고르면 끝.
- **매주 반복**: 「2 · 4 · 8주 동안 매주」 → 기한을 1주씩 늘려 한 번에 만들어 둔다(제목에 「1주차」…).
- **코멘트**: 학생 관리 → 학생 카드의 숙제 줄 「💬 코멘트 달기」 → 학생 「끝낸 숙제」에 뜸(새 코멘트는 위에 알림).
- **학생 리포트 PDF**: 학생 카드 「📄 리포트 PDF」 → 인쇄 창에서 「PDF로 저장」.
- **반 이름 바꾸기**: 반 카드 아래 줄 — 학생 「내 반」 제목이 이 이름.
