# 예스24 디지털 콘텐츠 공급 계약(전자서명 완료) — 핵심만

> 2026-10-29 운영자가 서명 완료 PDF(15쪽, 2026-10-27 계약일)를 올리며 「메모리에 저장」. **원본 PDF 는 저장소에 넣지 않는다**(계약서 · 계정 정보 — 운영자 보관). 아래는 Claude 가 읽고 뽑은 요약이고, 법적 해석은 아니다 — 판단이 필요하면 계약서 원문을 본다.

| 항목 | 내용 |
|---|---|
| 계약 상대 | 예스이십사㈜ · 출판사 = 에브리코리안즈(everykoreans). 계약 업체 계정은 예스24 SCM(공급망 관리 프로그램)에 있음 |
| 계약일 · 기간 | 2026-10-27 · 2년, 만료 3개월 전까지 서면 통지가 없으면 같은 조건으로 1년 자동 연장 |
| 정산(B2C) | 판매가의 **70%** — 매출 월의 익월 25일 현금(25일이 휴일이면 다음 영업일) |
| 정산(B2B) | 저작권자가 정한 정가의 **50%**(무료 배포용은 정산 제외) |
| 크레마클럽 구독(별도 부속) | 정가의 80%, 1카피 = 25회 대여 권한, 25×n+1회차 대여마다 정산 · 익월 20일 지급. **크레마클럽에 동의한 상품만** 해당 |

| 미리보기 | 예스24 가 미리보기용으로 일부를 편집해 쓸 수 있고, 그 저작권은 출판사 |
| 책임 | 출판사가 저작권 · 제3자 권리 침해 없음을 보증(제6조) |

## 다른 일과 겹치는 점
- **KDP Select(90일 디지털 독점)와 충돌 가능**: 예스24 에 올린 책과 **같은 내용**을 KDP Select 에 넣으면 안 된다. 그래서 KDP 새 책(짧은 이야기 시리즈)은 예스24 에 올리지 않는다(`docs/plans/kdp-original.md`). 예스24 에는 PDF 판 6권 계열.
- ISBN 이 붙은 책을 올린다(전자책 ISBN 칸 — `docs/ops/isbn-forms.md`).

## 운영자 할 일(결정 필요)
1. 예스24 SCM 에 책을 올릴 때 **정가**(B2C · B2B)를 정한다 — B2B 정가를 안 알리면 B2C 와 같다고 본다(제9조).
2. 크레마클럽 구독에 넣을 책을 고른다(넣으면 정가의 80%, 안 넣어도 됨).
