# Polar 상품 자동으로 올리기 (운영자 2026-10-27 「API 받아서 편하게」)

> 책마다 Polar 에서 상품 · 파일 · 가격 · 링크를 손으로 만드는 일을 `tools/polar-publish.mjs` 가 대신한다.
> 한 번 준비해 두면 「이 책 Polar 에 올려」 한마디로 된다.

## 도구가 하는 일 (책 한 권마다)
PDF 올리기 → 표지 그림 올리기 → 「파일 다운로드」 혜택 → 상품(한 번 결제 · 달러 · 영어 설명) → 결제 링크 → `docs/shop.json` 에 링크 적기(상태 「판매 중」) → 상점 쪽 다시 만들기.
- 이름 · 가격 · 영어 설명은 `docs/shop.json` 에서, ISBN 은 책 틀에서 가져온다. 쓰기 전에 **점검만 하는 판**(아무것도 안 올림)으로 내용을 먼저 보여 준다.
- 같은 책을 두 번 만들지 않는다. 이미 상품이 있는 책의 **파일 · 가격 바꾸기**는 하지 않는다(Polar 대시보드에서).

## 운영자가 한 번만 할 일 (비밀 값은 채팅에 적지 않는다)
1. **Polar 토큰 만들기** — 개인 토큰(Personal access token)은 이제 못 만든다(Polar 안내, 2026-10-27). **조직 토큰(Organization access token)** 을 만든다: Polar → 우리 조직(everykoreans) 설정 → Access tokens → 새 토큰. 조직 토큰은 조직 하나에만 걸려 있어 도구가 조직 번호를 따로 안 보내도 된다.
   권한은 이 다섯 개만: `products:read` · `products:write` · `files:write` · `benefits:write` · `checkout_links:write`.
   (주문 · 고객 · 환불 쓰기는 주지 않는다. 만료는 짧게 — 예: 30일.) 만든 직후 한 번만 보이는 토큰을 복사.
2. **Claude 환경에 넣기** — 이 세션 위쪽 환경 메뉴(클라우드 환경) → Edit →
   - 환경 변수(또는 Network secrets / API credentials 칸)에 이름 **`POLAR_ACCESS_TOKEN`**, 값은 복사한 토큰.
   - Network access: **`api.polar.sh`** 를 허용 도메인에 추가. 파일 올릴 때 Polar 의 파일 저장소(아마존 S3)에도 접속하므로 `*.amazonaws.com` 도 허용(번거로우면 올리는 동안만 넓은 접근으로 두었다가 되돌리기).
3. **새 세션을 연다**(환경 설정은 새 세션부터 적용). 「Polar 에 단어장 3 올려」라고 하면 된다.
4. 다 올린 뒤에는 토큰을 Polar 에서 지워도 된다(다음에 올릴 때 새로).

## 처음에는 한 권만
단어장 3(가장 새 책)으로 한 권 올려 → Polar 대시보드에서 상품 · 파일 · 가격 · 링크가 맞는지 보고 → 결제 링크로 **본인 카드로 한 번 결제**해 파일이 받아지는지 확인(→ Polar 에서 환불) → 나머지 책을 한꺼번에.

## 알아 둘 것
- 이 도구는 **공식 사용 설명서(polar-js SDK 문서)로 만들었고 실제 Polar 에 접속해 시험하지는 못했다**(이 세션에서 api.polar.sh 접속이 막혀 있었다). 첫 실행에서 오류가 나면 오류 문장을 그대로 알려 주면 고친다.
- 연습장(sandbox.polar.sh)에서 먼저 시험하려면 별도 계정 · 토큰이 필요하다(`--sandbox`).
- KDP · 예스24 · 쿠팡은 이 도구와 상관없다(그쪽은 API 로 책을 올릴 수 없다 — 복사판 도구 `tools/listing-html.py` · `coupang-html.py` 로 편하게).
