# 안티 그래비티 작업 지시 — 레벨테스트 문제 종류 늘리기 (L1 ~ L7, 레벨마다 27문제 × 3묶음)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해. 이번은 **N묶음**이야.」
> 브랜치: `leveltest-variety` (main 에서 새로). 운영자 요청 2026-10-07:
> 「다 문법만 나오고 비슷한 표현만 묻는다 — 알맞은 말, 간단한 빈칸, 이어지는 말처럼 레벨테스트에서 자주 쓰는 문형으로 다양하게」.

## 왜

`leveltest-overall.js` 240문제 중 L2 ~ L7 은 **90% 넘게 「문법 빈칸」**(___ 에 어미 · 조사 넣기)이다.
그래서 시험이 한 가지 모양으로만 느껴진다. **문법이 아닌 종류**로 레벨마다 27문제를 더한다.
사이트는 이제 바로 앞 두 문제와 **다른 종류**를 먼저 낸다(종류 = `t`). 그러니 종류가 고루 있어야 한다.

## 묶음

- 1묶음: **L1 · L2 · L3** 각 27문제
- 2묶음: **L4 · L5** 각 27문제
- 3묶음: **L6 · L7** 각 27문제

## 레벨마다 27문제 — 종류(`t`)와 수

| `t` | 이름 | 수 | 모양 · 예 |
|---|---|---|---|
| `vocab` | 알맞은 말(낱말 빈칸) | 4 | 어미가 아니라 **낱말**을 넣는다. `배가 고파서 ___을/를 먹었어요.` → 밥 / 책 / 물건 / 바다 |
| `reply` | 이어지는 말 · 대답 | 4 | `passage` 에 짧은 대화(가: … / 나: ___), `q` 「나의 말로 알맞은 것은?」 |
| `situation` | 상황에 맞는 말 | 3 | `q` 「친구의 생일 선물을 받았을 때 하는 말로 알맞은 것은?」 |
| `meaning` | 비슷한 말 · 반대말 · 뜻이 같은 문장 | 3 | `q` 「「」 안의 말과 뜻이 비슷한 것은? — 이 식당은 음식이 「싸요」.」 → 저렴해요 … |
| `connect` | 두 문장 잇기 | 3 | `q` 「두 문장을 알맞게 이은 것은? — 비가 와요. 집에 있어요.」 → 비가 와서 집에 있어요. … |
| `read` | 짧은 글 읽기 | 3 | `passage` 에 2~4문장 글(안내문 · 메모 · 문자 · 일기), `q` 「글의 내용과 같은 것은?」 또는 「무엇에 대한 글입니까?」 |
| `wrong` | 어색한 문장 고르기 | 2 | `q` 「문장이 틀린 것을 고르세요.」 — 보기 넷이 다 문장, 셋은 맞고 하나만 틀림 |
| `honor` | 높임 · 공손한 말 | 2 | `q` 「할머니께 하는 말로 알맞은 것은?」 → 할머니, 진지 드세요. … |
| `conj` | 이어 주는 말(접속사) | 3 | `passage` 에 두 문장(사이에 `___`), `q` 「___ 에 들어갈 말로 알맞은 것은?」 — `배가 고파요. ___ 밥을 먹었어요.` → 그래서 / 그런데 / 하지만 / 그리고 |

**`conj` 레벨별 낱말**(운영자 요청 2026-10-07 「그런데 · 근데 같은 접속사도」) — 그 레벨 것을 정답으로, 보기도 같은 레벨 접속사에서:
- L1 · L2: 그리고 · 그래서 · 그런데 · 하지만 · 근데(말할 때)
- L3 · L4: 그러니까 · 그러면 · 그래도 · 그러나 · 그럼 · 왜냐하면
- L5: 그런데도 · 게다가 · 그 대신 · 아니면 · 그러다가
- L6 · L7: 그러므로 · 따라서 · 반면에 · 즉 · 오히려 · 더구나 · 그럼에도 불구하고 · 하물며
- 「근데 · 그럼」처럼 **말할 때 쓰는 말**은 대화(`가: … 나: …`)로, 「그러므로 · 따라서」는 글말로 낸다.
- 정답이 둘이 되지 않게 조심: 「그런데」와 「하지만」이 둘 다 되는 문장은 피한다(앞뒤가 정반대면 하지만 · 그러나, 화제를 바꾸면 그런데).

- 레벨 수준은 아래 표 그대로 지킨다 — **낱말 · 글 길이 · 상황이 그 레벨에 맞아야 한다.**
  L1 은 인사 · 숫자 · 물건 이름 정도, L7 은 신문 · 논설 · 관용 표현까지.
- `read` 의 글은 L1 · L2 는 1~2문장, L3 ~ L5 는 3문장, L6 · L7 은 4문장 안팎. 너무 길면 폰에서 안 읽힌다.

| 레벨 | 낱말 · 상황 수준 |
|---|---|
| L1 | 입문: 인사 · 나라 · 직업 · 숫자 · 물건 · 가족 |
| L2 | 초급 1: 하루 일과 · 장소 · 음식 · 시간 · 날씨 |
| L3 | 초급 2: 쇼핑 · 교통 · 약속 · 취미 · 지난 일 |
| L4 | 초급 3: 병원 · 부탁 · 계획 · 감정 · 전화 |
| L5 | 초급 4: 여행 · 경험 · 직장 · 공공장소 안내 |
| L6 | 중급(TOPIK 3 · 4급): 사회생활 · 건강 · 환경 · 뉴스 일상 기사 · 관용 표현 쉬운 것 |
| L7 | 고급(TOPIK 5 · 6급): 논설 · 학술 · 정책 · 속담 · 관용 표현 |

## 모양

```js
{ lv: 3, t: 'reply', passage: '가: 주말에 같이 영화 볼래요?\n나: ___', q: '나의 말로 알맞은 것은?',
  options: ['좋아요. 몇 시에 만날까요?', '네, 영화가 아니에요.', '어제 영화를 봤어요.', '아니요, 주말이에요.'],
  answer: 0, why: '같이 보자는 말에 좋다고 하고 시간을 묻는 것이 자연스러워요.' }
```

- `lv` · `t` · `q` · `options`(꼭 4개) · `answer`(0~3) · `why`(꼭, 해요체 한두 문장). `passage` 는 `reply` · `read` 에서만(줄바꿈은 `\n`).
- `g`(문법 꼬리표)는 **꼭 맞는 문법이 있을 때만**(`connect` · `honor` 에서 흔하다). 억지로 달지 않는다.
- 각 레벨 주석 칸 아래, 그 레벨 마지막 문제 뒤에 더한다(순서 유지). L0 은 손대지 않는다.

## 지킬 것

- **정답은 하나뿐.** 오답은 그 문장 · 상황에서 **확실히 틀리거나 어색한 것.** 「이것도 되는데?」가 나오면 안 된다.
- 정답 자리를 0~3 에 **고루**(한 레벨 24문제에서 자리마다 5~7개).
- 이미 있는 문제와 같은 문장을 낱말만 바꿔 쓰지 않는다. 같은 묶음 안에서도 상황을 겹치지 않는다.
- 사실을 지어내지 않는다: 통계 · 기관 · 실존 인물 · 연예인 · 브랜드 · 가게 · 은행 이름 · 전화번호 · 요금을 쓰지 않는다. 이름은 「민수 · 지영 · 수진」처럼 흔한 것만.
- 실제 TOPIK 기출 문장을 베끼지 않는다(모두 창작).
- HTML 태그(`<u>` `<b>` 등)는 쓰지 않는다 — 화면에 글자로 보인다. 짚을 말은 「」 로 감싼다: `이 식당은 음식이 「싸요」.`
