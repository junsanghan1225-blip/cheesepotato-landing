# 안티 그래비티 작업 지시 — 쓰기 레벨테스트 문제 채우기

> 이 파일 전체를 안티 그래비티에 붙여 넣는다.

## 왜

레벨테스트의 「쓰기」 목적은 계단식이다 — 맞히면 한 레벨 위, 틀리면 한 레벨 아래 문제를 낸다.
그런데 문제가 **6개뿐**이라 레벨마다 한두 개거나 아예 없다. 경계를 찾으려면 한 레벨을
두세 번 물어야 하는데 물을 문제가 없어서, 결과가 거칠다.

```bash
node tools/check-leveltest.mjs
# 쓰기(writing) 6문제 — L2 2 · L3 0 · L4 1 · L5 2 · L6 1 · L7 0
```

**목표: L2~L7 레벨마다 8문제 (모두 48문제).** 지금 있는 6문제는 두고 42문제를 더한다.

## 순서

```bash
git checkout main && git pull origin main
git checkout -b leveltest-writing
```

`leveltest-writing.js` 의 `LT_CUSTOM_WRITING` 배열에 더한다. **레벨 순서대로 모아서**
(`// ── L3 ──` 같은 주석 아래) 넣는다.

```js
{ lv: 4, q: '비가 오___ 우산을 챙겼어요.', options: ['어서', '지만', '거나', '는데도'], answer: 0,
  why: '앞의 일이 이유가 될 때는 「-아/어서」를 써요.' },
```

- `options` 는 꼭 4개, `answer` 는 정답 자리(0부터). 보기는 화면에서 섞이므로 정답을 0에 둬도 된다.
- `why` 는 한 줄, 학습자에게 보이는 말투(-요)로.

다 넣으면:

```bash
node tools/check-leveltest.mjs      # 「이상 없음」, 「짚어 둘 것」에 쓰기가 안 나와야 한다
node tools/stamp.mjs && node tools/stamp.mjs --check
git add -A && git commit -m "leveltest: writing pool to 8 per level (L2–L7)"
git push -u origin leveltest-writing
```

## 레벨마다 무엇을 묻나

「쓰기」는 **문장을 정확히 완성하는지**를 본다 — 빈칸에 맞는 조사·어미·표현을 고른다.

| 레벨 | 묻는 것 |
|---|---|
| L2 초급 1 | 조사 을/를 · 이/가 · 에 · 에서 · 에게, 안/못, 현재 -아요/어요 |
| L3 초급 2 | 과거 -았/었-, -고 있다, -기 전에 · -(으)ㄴ 후에, 불규칙 ㄷ · ㅂ · 르 |
| L4 초급 3 | -아서/-(으)니까, -(으)면, -는데, -고 싶다, -아/어 주다, -아야 하다 |
| L5 초급 4 | -아/어 본 적이 있다, -(으)러, -(으)ㄹ 것 같다, 관형형(-는/-(으)ㄴ/-(으)ㄹ), 높임말 |
| L6 중급 | -느라고, -는 바람에, -(으)ㄹ 텐데, -다가, -도록, -더라고요, -아/어 놓다 |
| L7 고급 | -(으)ㄹ수록, -기는커녕, -는 한, -(으)ㅁ에도 불구하고, 문어체 연결(-(으)며 · -(으)나) |

더 자세한 문법 목록은 `docs/curriculum-upper.md`(L6·L7)와 예문 만들기 자료(`sentences.js`)에 있다.

## 반드시 지킬 것

1. **정답이 하나뿐이어야 한다.** 오답 보기를 빈칸에 넣어도 말이 되면 그 문제는 버린다.
   (예: 「비가 오___ 우산을 챙겼어요」에 「오니까」도 맞으면 「니까」를 보기에 넣지 않는다.)
   레벨테스트 전체에서 가장 흔한 실수였다 — 지난번 64문제 중 6문제가 이랬다.
2. **그 레벨 문법으로만 풀려야 한다.** L3 문제에 L6 낱말이 섞이면 문법이 아니라 낱말 때문에 틀린다.
3. 같은 문법을 한 레벨에서 두 번 넘게 묻지 않는다 — 여덟 문제가 여덟 가지를 보게.
4. 사람 이름은 흔한 것(민수 · 지현 · 수미)만.

## 하지 말 것

- `app.module.js` 를 고치지 않는다 — 문제만 더하면 된다.
- `check-leveltest.mjs` 와 `stamp.mjs` 를 건너뛰지 않는다. CI 가 같은 검사를 돌려서, 건너뛰면 PR 이 빨갛게 뜬다.

PR 설명에 레벨별 문제 수를 적는다.
