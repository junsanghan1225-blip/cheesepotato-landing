## 7. 핵심 흐름 (이대로 동작해야 한다)
1. **처음 온 사람**: 첫 화면 「내 레벨 찾고 시작하기」 → 레벨테스트(질문 넷 → 문제) → 결과 리포트 → 맞는 길 · 「오늘 공부 바로 시작」 → 끝에 요금제 상자.
2. **검색으로 온 사람**(사전 · 문항 쪽, 7~9초에 떠나는 문제): 쪽마다 「다음 한 걸음」 단추 → 앱 화면으로.
3. **매일**: 「오늘 공부 시작」 한 단추 → 칸을 차례로 → 다 끝나면 보상 → 「내일 알림 받기」.
4. **로그인 문**: 기록이 남는 것은 둘째 날부터 · TOPIK 유형 연습은 하루 10문항 · 모의고사는 로그인. 코스 · 문법 · 사전 · 게임은 로그인 없이.
5. **결제**: Pro 잠금 → 가격 화면 → Polar → 돌아와서 바로 Pro.
6. **반**: 선생님이 반 만들기 → 링크 · QR → 학생 로그인만 하면 입장 → 숙제 · 진도.

## 8. 하지 않는 것 (범위 밖)
- 실제 TOPIK · EPS **기출 문항**을 싣지 않는다 — 모두 창작, 「기출 아님」 표시.
- 반 기능으로 **수업 · 결제를 사이트로 데려오지 않는다**(Preply 규정). 반 학생에게는 선생님 쪽 링크를 숨긴다.
- 블로그 **매일 자동 글**은 하지 않는다(검색에서 대량 생성으로 보임) — 주 1회 초안 + 운영자 한마디.
- 광고를 띄우지 않고, 모은 정보를 팔지 않는다.
- 학습 자료(문항 · 낱말 · 예문)는 다른 말로 번역하지 않는다(화면 글만).
- ⚠ iOS 앱 — 지금은 안 함(애플 개발자 계정 연 $99). 시기는 운영자.
