## 방향 A — 종류별 틀 (레슨이 무엇을 가르치는지에 따라 흐름이 다르다)
같은 「읽기 → 문제」가 아니라 종류마다 처방:
| 종류 | 흐름(처방) |
|---|---|
| 한글 | 소리 듣기 → 따라 쓰기 느낌의 고르기 → 비슷한 소리 구분(listen) → 낱말 읽기 → 점검 |
| 낱말(first-words) | 낱말 카드(vocab) → 듣고 고르기 → 뜻 맞히기 → 받아쓰기 → 짧은 문장 만들기 → 내 단어장 |
| 문법(bg · grammar-core) | 한 줄 목표 → 예문 3개 보기 → **비교(헷갈리는 짝)** → 활용 표(conj) → 바꾸기 → 문장 만들기 → 내 문장 쓰기 → 점검 |
| 대화(bg-d) | 장면 듣기(passage) → 역할 고르기 → 빈칸 → 따라 말하기(speak) → 내 대답 쓰기 |
| 불규칙 | 규칙 한 장 → 활용 표 → 오류 찾기 → 섞어 연습 |
| 뉘앙스(im · ad) | 상황 → 비교 → 오류 찾기 → 상황에 맞는 말 고르기 → 내 문장 |
구현: 레슨 종류(코스 id 규칙)마다 **처방 순서표**(`LESSON_RECIPE`)를 두고, 합친 블록들을 그 순서로 정렬 · 단계 막대(① 배우기 ② 연습 ③ 써 보기 ④ 점검)를 위에 보인다. 블록 자료는 그대로(`courses*.js` · `lesson-extra/`).

## 방향 B — 학생별 맞춤 (같은 레슨도 사람마다 다르게)
1. **레슨 시작 「빠르게 / 차근차근」** — 빠르게는 문제 약 절반(쉬운 것 건너뜀), 차근차근은 전부. 마지막 고름을 기억.
2. **틀리면 같은 레슨 안에서 한 번 더** — 틀린 문제와 같은 종류 · 같은 레슨의 다른 문제를 뒤에 1~2개 끼워 넣는다(`lsQueue`). 맞히면 넘어간다.
3. **첫 세 문제 진단** — 시작 세 문제를 모두 맞히면 「이미 아는 것 같아요. 점검만 할까요?」로 압축(건너뛴 레슨은 진도 인정 여부는 운영자 결정).
4. **복습 간격** — 끝낸 레슨의 문제를 1 · 3 · 7일 뒤에 「지난 시간 복습」에 넣는다(지금은 무작위 3개).
5. **내 약점 모음** — 틀림 · 「아직이에요」를 문법 갈래(조사 · 시제 …)로 모아 「오늘의 한 가지」 추천(오늘 할 일 · 오답 노트에 한 줄).
6. (나중) 서버 저장 — 지금은 이 기기에만. 로그인한 사람은 기기를 바꿔도 이어지게(표 필요 → SQL 파일, 운영자 실행).

## 방향 C — 학습 스타일 「치즈 / 감자」 (운영자 2026-10-15: 두 길과 별개의 새 스타일 · 짧은 테스트 + 고르기)
길(치즈 = TOPIK 학생 · 감자 = 일반)은 **무엇을** 배우나이고, 스타일은 **어떻게** 배우나이다. 한 사람이 「감자 길 + 치즈 스타일」일 수 있어 이름이 겹치니, 화면에서는 「스타일」 카드에 따로 둔다(예: 🧀 치즈형 · 🥔 감자형). ⚠ 이름 · 설명은 운영자 확인(아래 제안은 임시).
| | 🧀 치즈형 (구조 · 정확) | 🥔 감자형 (체험 · 유창) |
|---|---|---|
| 새 문법을 만나면 | 규칙 설명 · 표 · 비교를 먼저 | 예문 · 대화를 먼저 보고 규칙은 나중에 |
| 레슨 순서 | 배우기 → 연습 → 써 보기 → 점검 | 연습 → 보기(틀린 뒤 설명) → 말하기 · 쓰기 |
| 문제 양 · 속도 | 차근차근(전부) · 힌트 기본 켜짐 | 빠르게(절반) · 힌트는 눌러야 |
| 틀렸을 때 | 까닭 · 규칙 바로 보여 줌 | 짧게 「다시」, 까닭은 접어 둠 |
| 복습 | 규칙 정리 카드(표) | 문장 하나씩 다시 말하기 |
- **정하기**: 처음 레슨 전에 질문 5~6개(「새 문법을 배울 때 먼저 …」 같은 양자택일) → 결과 카드(공유 가능) → **언제든 바꾸기**(설정). 건너뛰면 기본은 중간(지금과 같은 흐름).
- **효과는 방향 A · B의 설정값**으로 구현한다(별도 레슨을 새로 안 만든다): 블록 순서표(A)를 두 벌, 「빠르게/차근차근」(B-1) 기본값, 힌트 · 해설 노출. 그래서 A · B 위에 얹는 **3단계 이후**의 얇은 층이다.
- 저장: 이 기기(`cp-style-v1`). 로그인한 사람은 6단계(서버)에서 이어짐.

## 방향 D — 취약점 엔진 (레슨을 풀며 드러나는 약한 곳에 집중)
1. **꼬리표**: 문제마다 「무슨 실력인지」를 단다 — ① 문법 id(레슨 ↔ 문법은 `path-map.js` · 레슨 제목) ② 문제 종류(듣기 · 쓰기 · 순서 · 고르기 …) ③ 레슨 종류. 새 자료를 만들지 않고 **이미 있는 정보에서 자동으로** 붙인다.
2. **기록**: 문제 하나를 풀 때마다 꼬리표별 「맞음 · 틀림 · 걸린 시간」을 가볍게 쌓는다(최근 것에 무게 — 오래된 틀림은 흐려진다). 이 기기(`cp-skill-v1`), 오답 노트(`cp-wrong-v1`)와 별도.
3. **약점 지도**: 오답 노트 · 오늘 화면에 「내 약한 곳 3개」(예: 조사 에/에서 · 과거형 · 듣기)를 막대로.
4. **집중 훈련**: 약점 하나를 누르면 **그 꼬리표의 문제만** 5~10개(오답 노트 + 같은 꼬리표의 다른 레슨 문제 + 새로 만든 비교 · 바꾸기) — 맞히면 약점 막대가 내려간다. 레슨 안에서도 약점 꼬리표 문제를 한 번 더 끼워 넣는다(B-2).
5. **레슨 추천**: 「오늘의 한 가지」 = 가장 약한 꼬리표 + 그것을 다루는 레슨 연결.
6. **정직하게**: 문제가 몇 개 안 쌓였으면(꼬리표당 3개 미만) 「아직 잘 모르겠어요」로 두고 약점이라 단정하지 않는다.

## 방향 E — 세부 유형 (운영자 2026-10-15 「치즈 · 감자 안에서 모짜렐라 치즈 · 무슨무슨 감자처럼 종류를 나눠 유형을 만들자」 — 각 3가지 · 공부 성향 기준)
방향 C 의 치즈형 · 감자형은 **큰 갈래**(공부 방식)이고, 그 안을 3가지씩 더 나눈다 → 6가지 유형. 테스트는 5문항에서 **8~10문항**으로 늘려 「큰 갈래 → 세부」 순으로 가른다(첫 2~3문항이 갈래, 나머지가 세부). ⚠ 이름 · 설명은 **임시안**(운영자가 고침, 글자는 `STY` 한 곳).
| 큰 갈래 | 세부 유형(임시) | 한 줄 | 설정값에 닿는 곳 |
|---|---|---|---|
| 🧀 치즈형(구조 · 정확) | **모짜렐라** — 쭉쭉 이어 가는 꾸준형 | 매일 조금씩, 끊기지 않게 | 복습 간격 촘촘히 · 오늘의 한 가지 자주 · 연속 일수 강조 |
| | **체다** — 규칙을 파고드는 분석형 | 왜 그런지 알아야 넘어감 | 설명 먼저 펼침 · 비교 블록 우선 · 틀리면 풀이 바로 |
| | **크림치즈** — 가볍게 시작하는 부드러운 형 | 부담 없이 시작해 천천히 | 첫 문제 쉽게 · 레슨 짧게(빠르게 기본은 아님) · 힌트 친절 |
| 🥔 감자형(체험 · 유창) | **햇감자** — 새것에 도전하는 형 | 새 레슨을 먼저 달리고 싶다 | 빠르게 기본 · 미니 테스트로 건너뛰기 제안 · 만들기 문제 앞당김 |
| | **군감자** — 말하며 부딪히는 실전형 | 말하고 써 보며 배운다 | 만들기(문장 · 번역 · 내 문장) 비중 ↑ · 대화 레슨 먼저 추천 |
| | **포슬감자** — 느긋하게 쌓는 형 | 주말에 몰아서 / 느리지만 오래 | 복습 알림 부드럽게 · 구간 테스트 간격 넓게 |
- 세부 유형은 **레슨 자료를 바꾸지 않고** 설정값(빠르게 · 접기 · 힌트 · 문제 종류 비중 · 복습 간격 · 추천)만 다르게 한다(방향 C 와 같은 원칙).
- 결과 카드는 큰 갈래 + 세부 이름 한 쌍(예: 🧀 모짜렐라 · 🥔 군감자), 공유 가능. 설정에서 언제든 바꿈. 이 기기에만(서버 저장은 7단계).

## 방향 F — 코스 목록 · 길 재정비 (운영자 2026-10-15 「코스 목록 · 길 구조도 재정비하자」)
지금: 길 3(기초 43코스 · 중급 30 · 고급 24) + 코스 97개 + TOPIK · EPS 갈래가 따로. 코스 안은 평균 4레슨. 재정비는 **레슨 안(1~4단계)과 별개로** 목록 · 길 화면과 순서를 다시 짠다.
- 방향(제안, ⚠ 운영자 확인): ① 코스를 **구간**(예: 한글 · 첫 문장 · 기초 문법 · 일상 대화 · 중급 · 고급 …, 한 구간 = 코스 5~8개)으로 묶고 목록은 구간 단위로 펼친다 ② 길 위에 「지금 여기」와 구간 끝의 **구간 테스트**를 보인다 ③ 코스 카드에 유형(문법 · 대화 · 불규칙 · 낱말)과 걸리는 시간을 보인다 ④ 길 · 목록 · 오늘 화면이 같은 「다음 한 걸음」을 가리킨다.
- 하기 전에 정할 것: 구간 이름 · 경계(코스 id 로), 길 3개를 유지할지(기초 · 중급 · 고급) 구간 하나로 이을지, 목록에서 코스를 접어 둘지.

## 방향 G — 구간 테스트 · 미니 테스트 (운영자 2026-10-15 「미리 알면 건너뛴 레슨은 진도에 넣지 않아도 / 구간별로 테스트해서 아는지 확인 / 미니 테스트도」 — 위치: 구간 끝 + 레슨 앞 미니)
- **미니 테스트(레슨 앞)**: 레슨을 열면 그 레슨의 문제 중 쉬운 것 · 보통 3개를 먼저 낸다. **모두 맞히면** 「이미 아는 레슨 같아요」→ 건너뛰기(바로 다음 레슨) 또는 그대로 하기를 고르게 한다. **건너뛴 레슨은 진도(끝낸 레슨 수 · 레벨 승급 계산)에 넣지 않는다** — 「아는 레슨」으로 따로 표시만 하고 지난 시간 복습 재료로는 쓴다. 틀리면 그대로 레슨 시작(이미 푼 3문제는 세지 않는다).
- **구간 테스트(구간 끝)**: 구간 코스들이 끝나면 그 구간의 레슨 문제에서 **10문제**를 뽑아 낸다. 80% 이상이면 「구간 통과」 배지, 미만이면 약한 레슨 · 문법을 짚어 집중 훈련으로 잇는다. 레벨 승급 테스트(기존)와는 별개.
- **구간 시작 배치 테스트(선택)**: 새 구간에 들어갈 때 5~8문제로 미리 재서, 알면 구간 안의 쉬운 레슨은 미니 테스트 없이 건너뛰기를 권한다.
- 저장: 이 기기(`cp-skip-v1` · `cp-sect-v1`), 기록은 약점 지도(꼬리표 · 방향 D)에도 같이 쌓는다.
