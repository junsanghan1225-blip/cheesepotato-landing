운영자가 정할 것이 먼저 있다(애플 개발자 계정). 코드는 이미 iOS 설정(`com.cheesepotato.app`)이 들어 있다.

## 2. 친구 초대 → 둘 다 Pro 30일 (만듦)
- 내 링크 `?ref=코드` 로 새로 가입 → 둘 다 30일. 한 사람이 보상받는 초대는 6명까지(그 뒤는 친구만 받음).
- 서버 `db/add_referrals.sql`(운영자가 SQL Editor 에서 한 번) — 표 셋(`ref_codes` · `referrals` · `pro_bonus`) + `is_pro()` 에 보너스 한 줄.
- 화면: 설정 「친구 초대」(내 코드 링크) · 계정 칸 「친구 초대 덕분에 Pro」 · 가입 뒤 알림. 클라이언트 `billing.js` `isPro()` 에도 같은 규칙.
- 막는 것: 자기 자신 · 가입한 지 3일 지난 계정 · 이미 초대받은 사람 · 6명 상한. **남는 틈**: 가짜 이메일로 만든 계정은 서버가 못 구별한다 → 상한 6명이 피해를 막는다.
- 숫자: 이벤트 `referral_redeem`(GA4) — 숫자 판에서 매주 본다.

## 3. 결과 카드 공유 — 이미 있는 것 위에서
레벨테스트 결과 · TOPIK 모의고사 결과 · 학습 스타일 · 도장 판 · 이름 도장은 이미 공유 그림이 있다. 새로 만들기 전에 **어느 것이 실제로 공유되는지**(`level_share` 등 이벤트)를 숫자 판에서 보고, 안 되는 것의 단추 위치를 고친다. (아직 숫자 없음)

## 4. 검색 늘리기 — 운영자 자료를 받은 뒤
이미 사이트맵 약 1.6만 쪽(사전 1.3만 · 학습 977 · TOPIK 1,474 · 블로그 73). 새 쪽을 더 찍기 전에 **Search Console 「실적」 내보내기**(검색어 · 쪽 · 노출 · 클릭 · 순위)를 받아 「노출은 되는데 클릭이 적은 쪽」(제목 · 설명 고치기)과 「순위 8~20위 쪽」(내용 보태기)부터 한다.
