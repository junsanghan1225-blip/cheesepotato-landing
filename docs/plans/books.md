> 운영자: 「예스24처럼 한국어 책 출판」 · 「학습지 형태로 개별로 파는 것도」 · 「우리 자체적으로 출판」 · 「정말 퀄리티 있게, 정말 책처럼 — 표지 디자인부터 속지 · 목차까지 다 구현하자. 일단 계획만」.
> 상태: **계획 + 상점 쪽(/shop/) + 책 틀 도구(`tools/build-book.mjs`) + 1권 시안 PDF 만듦(2026-10-17).** ⚠ 는 제안안(출판사 가안 · 첫 책 = 첫걸음 워크북 · POD · 글자와 색 표지)으로 진행 — 운영자가 바꾸면 그대로 다시 찍는다.

## 1. 무엇을 파나 — 두 갈래
| 갈래 | 무엇 | 어디서 팔기 | 결제 |

| **디지털 학습지** | 인쇄용 PDF — 낱장(학습지 + 정답지) · 급별 묶음 · 전체 묶음 | 우리 상점 `/shop/` | Polar(이미 씀) — 「한 번 사는 상품 + 파일 다운로드」 |

## 3. 「정말 책처럼」 — 한 권에 들어가는 것
- **표지**: 앞표지(제목 · 부제 · 급 · 시리즈 색 · 출판사) · 책등(쪽수에 따라 두께 계산) · 뒤표지(소개 · 이런 분께 · 바코드 자리 · 가격). 시리즈마다 같은 틀 · 다른 색(워크북 = 주황/파랑, TOPIK = 초록/보라 — 상점 쪽 표지와 같다).
- **앞부분**: 속표지 → **판권면**(펴낸이 · 출판사 · 신고번호 · ISBN · 펴낸 날 · 「TOPIK 문제는 새로 만든 연습 문제로 기출이 아닙니다」) → 머리말 → 이 책 쓰는 법 → **목차**(자료에서 자동 · 쪽 번호 자동).
- **본문**: 단원 첫 쪽(단원 번호 · 목표) → 설명 · 표 → 연습 → 단원 끝 확인 문제. 쪽 머리(책 이름 · 단원), 쪽 번호, 여백은 제본 쪽을 넓게.
- **뒷부분**: 정답과 풀이 · 낱말 찾아보기(색인) · 「온라인에서 더 공부하기」(사이트 QR).
- **판형**: B5(182 × 257mm) 기본 — 쓰는 칸이 넉넉. 글꼴은 상업 인쇄가 되는 무료 글꼴(Pretendard · Noto Sans KR — OFL)만.

## 4. 만드는 방법 (Claude) — 도구 만듦
- **`node tools/build-book.mjs <책 id>`**: 책 틀 `docs/books/<id>.json`(제목 · 머리말 · 쓰는 법 · 부 · 단원 순서) + `docs/worksheets/*.json` → `books-out/<id>/interior.pdf`(속지) · `cover-spread.pdf`(뒤 + 책등 + 앞, 재단 여유 3mm) · `front-cover.png`. PDF 는 파는 파일이라 저장소에 안 둔다(`books-out/` 은 .gitignore).
- 1권 시안(첫걸음 워크북): **속지 96쪽** — 속표지 · 판권면 · 머리말 · 쓰는 법 · 목차(쪽 번호 자동) · 4부 표지 · 19단원(단원 표지 + 표 + 연습 4묶음) · 정답 · 찾아보기(271낱말, 단원 번호) · 메모. B5, 안쪽 여백이 넓은 좌우 쪽, 쪽 머리(왼쪽 책 이름 · 오른쪽 단원) · 쪽 번호. 책등 약 6mm(종이 0.11mm/장 가정 — **인쇄소가 정해 주는 값으로 다시 계산**).
- 비어 있는 자리(운영자): 출판사 신고번호 · ISBN · 발행일 · 정가 · 바코드 · 지은이 이름(지금 「준상 · Junsang」 가안, 소개 글은 운영자가 영상에서 한 말).
- 아직 못 한 것: 앞표지 그림(글자 · 색 · 한글 무늬만) · 사이트 QR · 학습지 PDF(낱장 · 묶음) 파는 파일 만들기 · 색인을 쪽 번호로(지금은 단원 번호) · 흑백 인쇄판(지금 컬러 — 인쇄비가 올라간다).

1. **책 틀 도구** `tools/build-book.mjs`(만들 것): 우리 자료(JSON) → 인쇄용 HTML(CSS `@page` — 판형 · 여백 · 쪽 머리 · 쪽 번호) → **PDF**(브라우저로 인쇄, 이미 쓰는 Playwright). 표지는 따로 한 장(앞 + 책등 + 뒤).
2. 1권으로 **시안 PDF**(표지 + 앞부분 + 1단원 + 정답 몇 쪽) → 운영자 확인 → 전체.
3. 검사: 쪽 넘침 0 · 목차 쪽 번호 = 실제 쪽 · 글꼴 모두 넣음 · 300dpi 이상(그림) · 빈칸 오타.
4. 양이 많은 덧붙임(단원 설명 늘리기 · 확인 문제 · 낱말 색인 뜻)은 **안티 그래비티** 지시서로 — Claude 는 검토.

## 5. 자체 출판 순서 (운영자 — 공식 안내로 다시 확인할 것)
> 아래는 검색으로 확인한 일반 흐름이다. 서류 · 비용 · 기간은 관할 구청 · 국립중앙도서관 공식 안내로 운영자가 확인한다(Claude 가 지어내지 않는다).
1. **출판사 신고** — 관할 시 · 군 · 구청(출판사 이름 정하기). 사업자 등록(이미 있는 에브리코리안즈)에 업종 추가가 필요한지 세무서에 확인.
2. **발행자 번호 → ISBN** — 국립중앙도서관 「서지정보유통지원시스템」(nl.go.kr/seoji)에서 신청 → 책마다 ISBN · 바코드.
3. **인쇄 · 유통 방식 고르기** — ① POD(주문받으면 찍는 방식 — 재고 · 첫 비용 부담이 적다. 부크크 · 교보 퍼플 같은 곳이 서점 유통까지 해 준다고 알려져 있다 — 조건 확인 필요) ② 인쇄소에서 한 번에 찍고 도매(서점 공급)와 계약.
4. **납본** — 펴낸 뒤 국립중앙도서관에 납본(도서관법).
5. 서점에 책 정보 · 표지 · 소개 등록 → 우리 상점 책 쪽에 서점 링크.

## 6. 상점 쪽 (만듦 — `/shop/`)
- 자료 `docs/shop.json` → `node tools/build-sheets.mjs` → `/shop/`(책 4권 · 학습지 묶음 3 · 낱장 29) + 책마다 `/shop/<id>/`(표지 · 소개 · 이런 분께 · 목차 · 판형 · 쪽수 · ISBN 자리).
- 결제 링크가 없는 상품은 「준비 중」만 보인다. 켜는 법: Polar 대시보드 → 상품(한 번 결제 · 파일 다운로드 혜택에 PDF 올림) → `buy.polar.sh/…` 링크를 `docs/shop.json` 에 → 다시 만들기.
- 가격은 Claude 제안(낱장 $1.99 · A1 묶음 $9.99 · A2 묶음 $7.99 · 전체 $14.99) — 운영자가 정한다.
- 아직 메뉴 · 사이트맵에 안 걸었다 — 첫 상품을 켤 때 건다.

## ⚠ 운영자가 정할 것
1. **출판사 이름** — 지금 상점에 「Every Koreans Books · 에브리코리안즈 출판」(가안). 출판사 신고 이름과 같아야 한다.
2. **첫 책** — 기본안 = 1권 「한국어 첫걸음 워크북」.
3. **인쇄 방식** — POD 로 시작(기본안, 재고 0) vs 인쇄소.
4. **디지털 가격 · 판매 시작 시점** — 1권 시안 전에 학습지 PDF 부터 팔지.
5. **표지 그림** — 글자 · 색만(지금 상점 표지) vs 그림(Midjourney 를 쓰려면 상업 사용이 되는 유료 요금제였는지 확인 — 2026-10-16 미정).

**블록(2026-10-17)**: 핵심 정리 · 참고 · 연습 · TIP · WARNING(주의) · MORE(더 알아보기). 새 책을 쓸 때 표 설명 · 글 칸을 읽고 `blocks` 에 종류를 정한다(주의 = 자주 하는 실수 · 예외, 팁 = 요령 · 자연스러운 말, 더 알아보기 = 소리 변화 · 유래 · 덧붙임). 안내 쪽(`guidePage`)이 자동으로 앞에 들어간다.

**PATTERN 블록(2026-10-17)**: 문장 틀을 갈아 끼우는 자리(점선) + 고정 부분(굵게)으로 한눈에. 새 책에서 「Pattern: …」 「Formula: …」 식 설명을 만나면 `blocks` 를 `pattern` 으로 하고 `patterns` 에 [글자, s(자리)/f(고정)] 로 적는다(예문은 원래 설명에 있던 것만).
