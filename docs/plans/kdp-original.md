# KDP 전용 새 책 계획 (Kindle 오리지널 · Select)

> 2026-10-28 운영자 「KDP 는 우리 내용 안 따라가도 되고 · KDP Select 도 등록 · 수익성을 조금 올리자 · 아예 개별 책으로 ISBN 도 빼자」.
> 배경: 첫걸음 워크북이 「Kindle 밖 도구(종이 · QR · 웹)가 필요한 상호작용형」이라 내려갔다. PDF 판 6권을 KDP 판으로 바꿔 둔 것(`build-book.mjs --kdp`)은 내용이 PDF 와 같아서 Select 에 못 넣는다(아래 ⚠).

## 원칙
1. **Kindle 안에서 읽기만으로 끝나는 책.** QR · 웹 링크로 가는 연습 · 쓰기 줄 · 인쇄물 · 「Workbook」 · 「write」 가 없다. 문제가 있으면 정답을 바로 아래에.
2. **PDF 책과 겹치지 않는 새 글**(Polar · 예스24 에서 파는 PDF 와 같은 내용이면 Select 독점 조건에 걸릴 수 있다 — ⚠ 확인 못 함). 사이트에 공개한 글(동화 · 회화 · 학습지)도 쓰지 않는다.
3. **ISBN 을 쓰지 않는다**(전자책은 KDP 가 주는 ASIN 으로 판다). 책 틀 `docs/books/` 에 넣지 않고 `docs/kdp-orig/<id>.json` 에 따로 둔다. 발행자번호 · 판권지의 한국 ISBN 칸 없음.
4. **긴 글은 안티 그래비티**(지시문 `docs/antigravity/antigravity-kdp-stories-task.md`), Claude 는 검토 · ePub 만들기.
5. 모든 글은 창작. 실제 기관 · 인물 · 사건 · 제도 · 요율을 쓰지 않는다. 기출 아님.

## 책 후보 (수익 순서 제안)
| # | 가제 | 왜 | 분량(제안) |
|---|---|---|---|
| 1 | **Korean Short Stories for Beginners** — 읽고 이해하는 짧은 이야기 40편(A1~A2), 한 줄씩 한국어 + 영어, 낱말 · 이해 문제(정답 바로 아래) | 읽는 책이라 Kindle 에 맞고, 길어서 Kindle Unlimited(쪽 수 기준 수익)에 유리 | 이야기 40 × 250자 안팎 |
| 2 | **Hangul in 7 Days** — 소리 → 글자 → 단어를 읽으며 따라가는 입문(로마자 도움, 쓰기 없음) | 입문자 검색이 많다 | 7장 |
| 3 | **Korean Mini Dialogues for Daily Life** — 짧은 대화 80개 + 표현 설명 | 반복해 읽기 좋음 | 대화 80 |

## 수익성 기준 (운영자 2026-10-28 「부가 수입이라서 수익성만」) — 웹 조사(2026-10-28), 아마존 공식 값은 아님
- **읽힌 쪽 수익(KENP)**: 제3자 집계로 쪽당 약 0.0048달러(2026.4 0.00482 · 2026.5 약 0.00489, 매달 바뀜). 300쪽을 끝까지 읽으면 약 1.45달러. → 한 권으로는 작고, **시리즈 · 여러 권 · 독자가 이어서 읽는 것**이 돈이 된다. 출처: kindlepreneur · profitable.app 의 KENP 집계.
- **판매 로열티**: 2.99~9.99달러 구간 70%가 모든 자료에서 같다(2026 글 두 곳은 상한이 12.99달러로 올랐다고 하나 아마존 쪽 확인 못 함 — 올릴 때 KDP 화면에서 확인). **전송료 MB 당 0.15달러**(70% 구간) → ePub 이 크면 한 권마다 깎인다. 우리 KDP 판 6권은 2~3MB 라 권당 약 0.3~0.45달러 손해 → 그림(PNG)을 줄여 1MB 안쪽으로.
- **Select 독점은 디지털만**: 같은 내용을 PDF 로 내 사이트 · 예스24 에서 팔면 안 된다(종이책은 상관없음). 90일마다 자동 갱신 — 끄는 것을 잊으면 90일 더 묶인다. 새 글을 더해도 독점 조건을 피하지 못한다. 그래서 Select 책은 PDF 와 **겹치지 않게**.
- **무엇이 잘 팔리나**: 한국어 학습 책의 Kindle 순위 · 판매량은 조사로 확인하지 못했다(검색에서 나오지 않음). 한글 입문(Hangul for Beginners 류) · 「7 Books in 1」 같은 묶음 · 대화 책이 목록에 있다는 것까지만 확인. → 운영자가 아마존에서 「Korean Language Learning」 · 「Foreign Language Study」 베스트셀러 순위 쪽을 캡처해 주면 Claude 가 분석해 책 순서를 다시 정한다.

### 아마존 순위 캡처 분석(운영자 2026-10-28, 「Korean Language Learning」 상위 21권)
- ⚠ 캡처는 **Audible(오디오북) 순위**였다 — 전부 「Audible Audiobook」 표시. Kindle 전자책 순위는 아니다. 수요의 모양(어떤 주제 · 묶음이 팔리나)을 보는 용도로만 쓰고, Kindle 순위(「Kindle eBooks」 탭)는 따로 받아 확인한다.
- **묶음이 상위를 차지**: #1 Learn Korean Bundle(5 levels) · #2 Complete Learn Korean for Adult Beginners(3 in 1, 평가 659) · #3 Complete Beginner's Course(10 books in 1) · #10 7 Books in 1(378) · #14 Bundle 5 in 1. → 합본은 효과가 있는 틀(오디오북 기준).
- **이야기 · 문맥 속 낱말이 상위**: #13 Korean Stories for Language Learners(평가 2,100, 한국어 · 영어 민담) · #11 2000 Most Common Korean Words in Context(평가 1,242). → 우리 책 1(이야기)과 TOPIK II 단어장 방향이 맞다. 우리 단어장 3권(KDP 판)은 제목을 「N Most Common Korean Words in Context」 꼴로 다듬으면 검색에 더 걸린다(제안).
- **주제 곁가지**: #5 Korean for K-Pop Fans(255) · #9 · #12 수면 학습 · #4 차에서 배우기. → K-pop · 드라마 낱말 책은 수요가 있어 보이나 **실제 가사 · 이름 · 방송 인용은 쓰지 않는다**(저작권 · 상표 위험). 우리 창작 문장으로.
- 이 캡처의 순위 · 평가 수는 책 한 권 한 권의 판매량이 아니다(평가 수는 인기의 대략적인 힌트).

### 수익성으로 정한 순서 (제안 — 만드는 돈이 적고 틀을 다시 쓰는 순)
1. **이야기 시리즈**: 책 1(A1~A2 40편, 안티 진행 중) → 책 2(A2~B1) → 책 3. 같은 틀(`build-kdp-original.mjs`) 재사용, 시리즈로 읽으면 쪽 수익이 이어진다. 가격 4.99달러 근처.
2. **Hangul in 7 Days**: 입문 검색이 가장 넓은 출입구. 2.99달러(70% 하한)로 두고 시리즈로 이어지게 뒷표지에 다른 책 소개.
3. **Mini Dialogues 80**.
4. **묶음(3권 합본)**: 시리즈가 3권 모이면 합본을 9.99달러 근처로(이미 이 분야에 「7 Books in 1」 합본이 있다 — 효과는 확인 못 함).
- 책마다 **전송료를 줄이려고 ePub 은 1MB 안쪽**(글 중심, 그림 최소).

## KDP 설정 (운영자가 화면에서)
- KDP Select 등록(90일 독점 — ⚠ 같은 내용을 다른 곳에서 디지털로 팔면 안 된다는 것이 제 이해이고, KDP 도움말에서 확인 못 했다).
- 로열티: 가격이 2.99~9.99달러면 70%, 밖이면 35%(KDP 안내 — 화면에서 확인). 처음엔 4.99달러 근처 제안, 운영자 결정.
- AI 사용 표시는 사실대로.

## 순서
1. 책 1 이야기를 안티에게(지시문 완료) → 올라오면 「안티가 올렸어」 로 검토.
2. Claude: `tools/build-kdp-original.mjs`(이야기 → 흐르는 ePub + 표지 + 복붙표) 만들기.
3. 운영자: KDP 올리기 · 심사 결과 알려 주기 → 통과하면 책 2 · 3.
