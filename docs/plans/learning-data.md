## 무엇을 쌓나 (한 문제 = 한 줄, `answer_events`)
| 칸 | 뜻 |
|---|---|
| `did` · `user_id` | 기기 무작위 id(funnel 과 같은 `cp_fn_id`) · 로그인했으면 계정 id(서버가 JWT 로 채움) |
| `sec` | 어디서: lesson · drill(집중 훈련) · topik_read · topik_listen · topik_write · mock · leveltest · other |
| `item` · `label` | 문제 번호(레슨 id + 문제 내용 해시, TOPIK 은 문항 id) · 문제 앞 90자(우리가 낸 글) |
| `ok` · `tries` | 첫 답이 맞았나 · 몇 번째에 맞혔나. AI 채점 같은 점수형은 `ok` 비움 |
| `pick` · `ans` | 고른 보기 글자(우리 보기 중 하나) · 정답 글자 — 「자주 고르는 오답」을 보려고 |
| `ms` | 문제가 뜬 뒤 첫 답까지 걸린 시간(레슨 · 집중 훈련) |
| `tags` | 꼬리표 `g:<문법 id>` · `k:<문제 종류>` · `c:<코스 종류>` (레슨 대격변 방향 D 와 같은 것) |
| `score` · `max` | TOPIK 쓰기 AI 점수(내용 없이 점수만) |
- **저장 안 하는 것**: 쓰기 · 번역 · 내 문장 · 대화에서 학생이 직접 쓴 글, 이메일 · 이름. 한 기기 하루 1,500줄까지(도배 막기). 운영자 본인과 자동 브라우저는 안 센다. 설정 「학습 기록」에서 끌 수 있고, 쿠키 동의를 안 한 비로그인은 안 보낸다.

## 운영자 판 `/insights.html` (interactive)
기간(7 · 28 · 90일) · 섹션 칩 · 검색 · 꼬리표 거르기가 모두 숫자를 다시 계산한다. 섹션 막대 · 약한 꼬리표를 누르면 그 범위로 좁혀지고, 문제 표(정렬 가능, CSV 내려받기)에서 문제를 누르면 오른쪽 서랍에 **고른 보기 분포 · 하루별 틀린 비율 · 걸린 시간 · 고칠 점**(너무 어려움 · 한 보기에 몰림 · 오래 걸림 · 너무 쉬움)이 열린다. 숫자는 `admin_answer_overview` · `admin_answer_item`(운영자 메일일 때만).
