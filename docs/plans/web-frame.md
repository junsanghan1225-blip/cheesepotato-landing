## 1. 기본 틀 (제안 — 운영자 확인 전)
1. **머리글 하나**: 로고 · TOPIK · 단어 · 책 · (언어) · 「무료로 배우기」. 폰은 로고 + 「무료로 배우기」 + 메뉴. 첫 화면(앱)은 검색 · 로그인을 더한 같은 모양.
2. **폭 두 가지**: 읽는 쪽 720(사전 · 문법 · 쓰기 · 블로그 글) · 넓은 쪽 1120(첫 화면 · 상점 · 책 · 목록). 좌우 여백 폰 20 · PC 40.
3. **기준점 세 개**: 폰 ≤600 · 태블릿 ≤900 · PC. 새로 쓰는 CSS 는 이 셋만.
4. **글꼴 하나**: Pretendard 먼저(모든 쪽).
5. **색 · 크기 이름 하나**(공통 파일 하나에 `--bg` `--ink` `--ink-2` `--line` `--accent` · 제목 크기 3단계) — 만든 쪽 · 상점 · 첫 화면이 같은 파일을 읽는다.
6. 바닥글 하나(소개 · 개인정보 · 약관 · 언어).
