# 이야기 만들기 — 계획 (운영자 2026-10-18 「긴 글 만드는 연습 · 접속사 · 이야기를 설명하는 연습 섹션」)

## 무엇
배우기 → 읽기 · 쓰기 · 말하기 묶음 안의 새 칸 「🧵 이야기 만들기」(주소 `#learn/weave`). 번역 연습(한 줄씩 영어→한국어) · TOPIK 쓰기(시험 형식)와 겹치지 않는 **문장을 이어 짧은 이야기를 만드는 연습**.
- **접속사 카드**(`#learn/weave/connectors`): 역할별(더하기 · 차례 · 결과 · 반대 · 조건 · 이유 · 예 · 마무리) 카드 — 뜻 · 쓰임 · 예문 2 · 팁.
- **이야기**(`#learn/weave/<id>`): ① 흩어진 문장을 순서대로 → ② 문장 사이마다 알맞은 접속사 4지선다(이유가 바로) → ③ 내 이야기 쓰기(문장 수 · 접속사 수를 규칙으로 확인) → 모범 이야기.
- 수준: 초급 · 중급 먼저(운영자 선택). 고급(글말 접속사 · 문단 연결, TOPIK 쓰기와 이어짐)은 나중.
- AI 채점은 쓰지 않는다(한도를 아낌). 쓰기 ③은 규칙 확인 + 모범 이야기와 견주기.

## 자료 · 도구
- 원본 `docs/weave.json`(접속사 16 · 이야기 6 — Claude 가 시범으로 씀) → `node tools/build-weave.mjs` → `weave.js`(자국 대상). 검사 `node tools/check-weave.mjs`(CI `check.yml`).
- 늘리기: 안티 지시서 `docs/antigravity/antigravity-weave-task.md` — 초급 · 중급 이야기 각 10편씩 묶음, 접속사 카드 더하기. 검토는 gap 마다 「정답이 하나뿐인지」.
