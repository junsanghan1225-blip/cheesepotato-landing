# 웹 리팩터링 — 천천히 단계별로 (2026-10-12 운영자 「웹쪽은 천천히 단계별로 리펙터링해줘」)

## 왜 · 무엇이 문제인가
- `app.module.js` 한 파일이 **21,000줄 · 최상위 선언 1,400개**. 구역(단어 · TOPIK · 메모장 · 반 · 게임 …)이 한 덩이의 전역 변수를 같이 쓴다.
- 고치려면 한 파일 전체를 읽어야 하고, 한 구역을 바꾸다 다른 구역이 깨져도 눈으로는 안 보인다.
- 첫 화면에서 21,000줄을 다 내려받는다(메모장 · 블록 편집기 · 반 · 동화책 같은 무거운 구역은 처음엔 필요 없다).

## 원칙
1. **동작은 바꾸지 않는다.** 화면 · 글 · 저장 모양 · 주소는 그대로. 새 기능 · 디자인 변경은 섞지 않는다.
2. **한 단계 = 한 PR.** 단계가 끝나면 스모크 · preflight 가 같은 결과여야 머지(운영자 「머지해줘」 뒤).
3. **되돌릴 수 있게 작게.** 한 번에 한 구역. 옮긴 다음 줄 수가 아니라 「깨진 곳 0」이 성공 기준.
4. **안전장치가 먼저.** 코드를 건드리기 전에 `node tools/smoke.mjs` 로 기준선(오류 0)을 잡는다.
5. 자국(stamp) · CSP · 새 `.js` 는 `tools/stamp.mjs` 의 `ASSETS` 에 넣는 규칙은 그대로 지킨다.

## 안전장치 (끝) — `node tools/smoke.mjs`
주요 화면 30곳을 폭 390 · 1280 에서 열어 **잡히지 않은 JS 오류 · ReferenceError/TypeError · 가로 스크롤**을 센다(서버 연결 실패는 제외). 기준선 = 60곳 오류 0. 의도적으로 오류를 넣어 잡히는 것도 확인했다. 브라우저가 필요해서 CI 에는 안 넣고 손으로 돌린다. 한계: 로그인한 사람의 화면 · 클릭 흐름은 못 본다 → 단계마다 아래 「손으로 볼 곳」을 같이 본다.

## 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 스모크 시험 만들기 · 기준선 | ✅ |
| 1 | **안 쓰이는 코드 지우기** — 어디서도 안 부르는 최상위 선언 6개 삭제(`ntCatNames` · `nbFind` · `rdFind` · `gateMock` · `sbHasBat` · `pathBar`). 일부러 남겨 둔 `nbFromCourseBlock` · `nbBlocksFromLesson`(주석에 「남겨 둔다」)은 그대로 | ✅ |
| 2 | **겹치는 도우미 모으기** — `read/write`(localStorage) · `shuffle` · `mean` · `dayKey` 처럼 파일마다 따로 있는 것을 한 모듈로. 먼저 겹침 목록을 뽑아 운영자에게 보여 준다 | ⏳ 다음 |
| 3 | **게임 인라인 둘 분리** — 스피드 퀴즈(15026~) · 숫자 읽기(15167~)를 `word-blocks.js` 처럼 따로 모듈로(필요한 것은 deps 로 넘김) | ⏳ |
| 4 | **무거운 구역을 늦게 받는 모듈로** — 메모장(6828~) · 블록 편집기(7380~) · 이모지 고르개(8694~) · 동화책 · 반/숙제(19811~) · 약점 리포트. 구역마다 「전역 변수를 얼마나 쓰나」를 먼저 재서 쉬운 것부터 1개씩 | ⏳ |
| 5 | **전역 상태를 구역 객체로** — `let` 로 흩어진 상태를 구역마다 한 객체에 | ⏳ |
| 6 | `app.module.js` 를 얇은 부팅 + 구역 파일로 | ⏳ |

## 단계마다 하는 것 (체크리스트)
1. `node tools/smoke.mjs` — 기준선 오류 0 확인(전) → 작업 → 같은 결과(후).
2. `node tools/stamp.mjs && node tools/preflight.mjs` 통과.
3. 첫 화면 내려받는 JS 크기 전 · 후(4단계부터 의미 있음).
4. **손으로 볼 곳**(로그인 · 클릭 흐름은 자동으로 못 봄): 로그인 · 레슨 하나 끝내기 · TOPIK 한 문제 · 단어 하나 담기 · 게임 한 판 · 메모장 새 글 · 설정 열기.
5. PR 설명에 「무엇을 옮겼나 · 줄 수 · 스모크 결과 · 못 본 것」을 적는다.

## 위험 · 못 하는 것
- 로그인한 화면과 결제 · 반 기능은 자동 시험이 없다. 건드리는 단계(4)에서는 운영자 계정으로 손으로 확인이 필요하다.
- 전역 변수가 구역 사이에 얽혀 있어(예: `tqExam` 이 TOPIK · 모의고사 · 성적표에 걸침) 구역 분리는 쉬운 것부터. 얽힘이 크면 먼저 5단계(상태 묶기)로.
