# 반 시스템 설계 (2026-10-14 운영자 「구글 클래스룸처럼 · 선생님 학생 모두 편하게」)

목표: **수업은 Preply 등 밖에서 하고, 이 사이트는 숙제 · 복습 · 제출 · 확인만.** 전 세계 학생이 링크 하나로 들어오고, 선생님은 제출을 바로 확인해 수업 화면에 띄운다.

## 역할 · 한 줄
- **선생님**: 반 만들기 → 링크 · QR · 코드로 초대 → 숙제 내기 → 제출 확인(수업에서 보여주기).
- **학생**: 링크 누르기(또는 코드 6자) → 숙제 보기 → 하기 / 제출 → 선생님 확인 · 코멘트 보기.

## 숙제의 상태(학생 · 선생님 같은 말)
`할 일` → `제출함`(확인 대기) → `확인됨`. 기한이 지났는데 안 했으면 `기한 지남`. (레슨 · 문법 · TOPIK 처럼 앱이 점수를 아는 숙제는 끝내면 바로 `했음` — 제출은 선택.)

## 화면
| 누가 | 어디 | 핵심 |
|---|---|---|
| 선생님(웹 반 화면) | 맨 위 「확인할 제출 N개」 | 아직 안 확인한 제출 최근 순 · 「바로 확인하기」 |
| | 「이렇게 시작해요」 | ① 반 ② 초대 ③ 숙제 ④ 제출 확인 — 네 걸음, 다 하면 사라짐. 학생이 없으면 초대 탭부터 열림 |
| | 숙제 줄 | 학생별 제출 칩 · 「제출 보기 · 수업에서 보여주기」 |
| | 발표 화면 | 큰 글씨 전체 화면 · ← → 로 학생 넘기기 · 한 줄 코멘트 · 「확인했어요」(다음 학생으로) · Esc |
| 학생(앱) | 오늘 화면 | 「남은 숙제 N개」 줄 |
| | 우리 반 | 코드 한 칸(링크 통째로 붙여넣기 가능, 6자가 차면 자동 가입) · 「할 일 / 제출함 / 확인됨」로 묶인 숙제 · 선생님 코멘트 |
| 학생(웹) | 반 링크 | 로그인만 하면 자동 가입 · 숙제 줄에 「제출」 |

## 데이터(Supabase) — `db/add_classes*.sql`, `db/add_class_submit.sql`
classes · class_members · class_homework(kind 에 `free`) · class_done · class_feedback · class_submission(글 + 사진 경로 + 확인 시각) · 비공개 버킷 class-submissions(`학생id/숙제id/파일`).
쓰기는 함수로만: cls_join · cls_mark · cls_submit(반 학생인지 서버가 확인) · cls_review(숙제를 낸 선생님만).

## 말 · 규칙
- 학생에게 보이는 말은 쉬운 말 · 5개 언어(앱은 `app-strings`). 선생님 화면은 한 · 영.
- 개인정보: 선생님은 이름 · 숙제 기록 · 제출물만 본다. 학생은 언제든 반을 나갈 수 있다.
- 사진: 폰 사진은 1280px JPEG 로 줄여 올린다(장당 4MB 이내). 제출물 읽기는 본인과 그 반 선생님만.
