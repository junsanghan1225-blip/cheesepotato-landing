# 안티 그래비티 작업 지시 — 문법 「블록으로 맞추기」 연습 문장 (205개 표현 × 5문장)

> 이 파일 전체를 안티 그래비티에 붙여 넣는다. (운영자 요청 2026-10-05)

## 왜 하나

사이트 「예문 만들기」의 문법마다 아래에 **블록으로 맞추기** 연습이 있다. 섞인 어절(띄어 쓴 덩어리)을 눌러 문장을 맞추는 연습이다.
지금은 이 연습이 **바로 위에 보여 준 예문을 그대로 다시 낸다**. 학생은 방금 본 문장을 외워서 맞출 뿐이다.
85개 표현은 사이트 안의 다른 문장으로 바꿨다. 아래 **205개 표현**은 그런 문장이 없어서 새로 써야 한다.

## 할 일

아래 표의 표현마다 **새 연습 문장 5개**와 그 **영어 뜻**을 쓴다.
결과는 `docs/grammar-practice.json` 한 파일에 담는다.

```json
{
  "33-1": [
    { "ko": "창문 좀 열어 주세요.", "en": "Please open the window." },
    { "ko": "…", "en": "…" }
  ],
  "31-1": [ … 다섯 … ]
}
```

## 문장 규칙 — 꼭 지킨다

1. **그 문법이 꼭 들어가고, 그 뜻으로 쓰인다.**
   - 「① · ②」처럼 뜻이 둘로 나뉜 표현은 표의 뜻풀이에 맞는 쪽으로만 쓴다.
     - 예: `V-(으)ㄹ까요? ① (제안)`은 「같이 ~할까요?」, `② (의향)`은 「제가 ~할까요?」.
   - 활용(받침 · 불규칙)이 맞아야 한다. 헷갈리면 그 문장은 버리고 다른 문장을 쓴다.
2. **레벨에 맞게 쓴다.**
   - 초급: 생활 낱말, 3~7어절, 해요체.
   - 중급: 5~9어절.
   - 고급: 8~10어절까지. 글말(-ㄴ다/-다)도 괜찮다.
3. **3~10어절**(띄어 쓴 덩어리 수). 문장 부호 `. ? !`로 끝낸다. 한 표현 안에서 문장 길이를 조금씩 다르게 한다.
4. **블록이 깨지는 것은 쓰지 않는다.** 따옴표(" ' 「 」), 괄호, `A:` · `B:` 같은 말하는 사람 표시는 쓰지 않는다.
   - 숫자는 한글로 쓴다(「세 시」, 「천 원」). 기계 목소리가 읽는다.
5. **표의 「화면 예문」과 같거나 거의 같은 문장은 안 된다.** 낱말만 하나 바꾼 것도 안 된다. 학생이 처음 보는 문장이어야 한다.
6. **사실을 지어내지 않는다.**
   - 통계 · 기관 · 법 · 가격 정보 · 실존 인물 · 연예인 · 브랜드 · 가게 이름을 쓰지 않는다.
   - 이름이 필요하면 「민수 · 지영 · 수진」 같은 흔한 이름만 쓴다.
   - 유명한 노래 가사 · 시 · 광고 문구 · 속담 풀이도 쓰지 않는다.
7. **영어(`en`)는 자연스러운 번역 한 문장.** 학생은 영어를 보고 한국어 블록을 맞춘다. 그러니 한국어와 뜻이 정확히 같아야 한다.
8. **다섯 문장은 상황이 다 다르게.** 집 · 회사 · 학교 · 가게 · 여행 · 친구 사이 등으로 고루 나눈다.
9. 자신 없는 문장에는 `"note": "운영자 확인 — 이유"`를 단다(Claude 가 검토한다). 검사기가 note 를 막으니, 남겨 두면 Claude 가 보고 고친다.

## 내는 법

```bash
git checkout main && git pull origin main
git checkout -b grammar-practice
# docs/grammar-practice.json 을 만든다(아래 205개 표현 전부 — 여러 번 나눠 써도 된다)
node tools/check-grammar-practice.mjs     # 「문제 없음」이 나와야 한다(note 는 남겨도 된다 — Claude 가 본다)
git add docs/grammar-practice.json && git commit -m "grammar practice: 205 points × 5"
git push -u origin grammar-practice
```

- **다른 파일 · 도구(`tools/`)는 고치지 않는다.** 자국(stamp)도 찍지 않는다. `grammar-usage.js`도 손대지 않는다 — Claude 가 검토하고 도구로 굽는다.
- 한 번에 다 못 하면 초급 → 중급 → 고급 순서로 나눠 커밋해도 된다(커밋마다 검사 통과).
