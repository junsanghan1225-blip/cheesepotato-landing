# 에브리코리안즈 책 PRD — 책 출판 사업 (초안 v1, 2026-10-26)

> 운영자 2026-10-26 「책 타겟은 영어권 학습자 아니야? PRD 다시 세워보자 정교하게」. 사이트 전체 PRD(`prd.md`)의 한 갈래로, **책(전자책 · 종이책)만** 다룬다.
> 이미 정한 것(`decisions.md` · `plans/books.md` · `plans/publishing-launch.md`)을 한곳에 모았고, **⚠ 는 운영자가 정할 것**, **(확인 못 함)** 은 공식 화면에서 확인해야 하는 것이다. 숫자 · 제도 · 요율은 지어내지 않았다.
> 문서 순서: `prd.md`(사이트) → **이 문서(책)** → `roadmap.md`(숫자) → `decisions.md`(정한 것) → `plans/books.md`(만드는 법) · `ops/book-listings.md`(판매처 글).

## 1. 한 줄 정의
**영어로 한국어를 배우는 사람이, 혼자 끝까지 풀 수 있는 한국어 워크북과 TOPIK 문제집.**
한 권마다 정답 · 풀이 · 책 속 QR 보너스가 있고, 이어서 공부하고 싶으면 everykoreans.com 으로 이어진다.

## 2. 누구를 위한 책인가 (독자)
> 운영자 질문 「타겟은 영어권 학습자 아니야?」에 대한 정리: **맞다.** 근거는 다 이미 책에 있다 — 가격이 달러, 설명은 영어가 먼저 나오고 한국어가 같이 있는 두 언어판, 판매처 1순위가 KDP · 구글(영어권 서점), 사이트 대상이 「TOPIK 을 준비하는 외국인」(`prd.md` §1).
> ⚠ 「영어권」의 범위: **영어 사용 국가 학습자만**인지, **영어로 설명을 읽을 수 있는 모든 외국인 학습자**(베트남 · 필리핀 · 인도 · 유럽 등)인지 정한다. 책 글은 어느 쪽이든 같다 — 쉬운 영어. 광고 · 키워드만 달라진다.

| | 독자 | 원하는 것 | 우리 책 |
|---|---|---|---|
| **A. TOPIK 준비생** (핵심) | 유학 · 취업 · 비자로 급수가 필요한 외국인 | 시험 날까지 점수 | TOPIK I 읽기 모의고사 · TOPIK II 쓰기 51~52 · 53~54 · 단어장 · (계획) 읽기 · 듣기 유형별 |
| **B. 초급 독학생** | 한글부터 시작하는 사람, K-콘텐츠 · 여행 · 취미 | 처음부터 막히지 않기 | 한국어 첫걸음 워크북 · 조사 워크북 · (계획) 문법 워크북 초급~고급 |
| **C. 한국어 선생님 · 튜터** | Preply · 학원 · 대학 | 숙제로 내줄 학습지 | 인쇄해서 쓰는 워크북(B5, 정답 뒤쪽) · 반 기능(사이트) |
| **D. 한국 거주 외국인** | 한국에서 일하고 공부하는 사람 | 국내 서점에서 바로 구입 | 예스24 · 쿠팡 · 네이버(원화) — ⚠ 영어 설명이 오히려 장점 |

- 우선순위: A → B → C → D. 책 내용을 정할 때 A · B 가 읽고 풀 수 있는가를 먼저 본다. 한국어 모국어 화자는 **타겟이 아니다**(설명이 영어가 먼저라서 맞지 않는다).
- 수준 약속: **아주 쉬운 영어.** 문법 용어는 영어 이름 + 한국어 이름을 같이(예: particle · 조사). 번역투 · 어려운 영어 단어를 쓰지 않는다.
- 이 독자들이 겪는 문제 → 책의 답:

| 겪는 것 | 책의 답 |
|---|---|
| 한국어 교재는 한국어 설명이 많아 막힌다 | 설명은 영어가 먼저, 한국어 예문 옆에 영어 뜻 |
| TOPIK 기출은 해설이 적고 영어 해설은 더 적다 | **새로 만든 문항** + 정답마다 근거와 선지별 이유(모의고사 책) |
| 쓰기는 채점해 줄 사람이 없다 | 쓰기 100제 + 정답 예시 + (사이트) AI 채점으로 이어짐 |
| 혼자 하면 이어지지 않는다 | 단원 20개 안팎, 하루 한 단원, 다시 보는 날(1 · 3 · 7일) 안내 |
| 낱말이 너무 많다 | 급 → 주제 → 빈출 순서, 치즈(급수) · 감자(빈출) 표시 |

## 3. 책이 약속하는 것 (가치 제안)
1. **혼자 끝낼 수 있다** — 정답 · 풀이 · 연습이 한 권 안에 있다.
2. **기출이 아니라 우리가 새로 만든 문제** — 「기출 아님」을 책에 적는다. (실제 기출을 베끼지 않는다 — 규칙)
3. **영어 + 한국어 두 언어** — 영어권 독자도, 한국어 교사도 같은 책을 쓴다.
4. **사이트로 이어진다** — 책 속 QR 은 책 밖 보너스 연습(낱말 카드 · 퀴즈 · 빈칸)으로 열린다. 더 하고 싶으면 사이트(무료) → Pro.

## 8. 품질 기준 (책이 나가기 전)
1. **사실**: 기관 · 제도 · 요율 · 숫자를 지어내지 않는다. 확인 못 한 것은 표시.
2. **기출 아님**: 문항 전부 창작. 안티 검수 → Claude 가 사실 · 기출 여부 검토 → 운영자.
3. **정답 · 풀이**: 정답 하나만 맞는가, 풀이가 맞는가(모의고사는 근거 + 선지별 이유).
4. **일관성**: 표지 · 책 · 신청서 · 판권지의 제목 · 부제 · 저자 · 발행일 일치(`tools/check-isbn.mjs`).
5. **형식**: B5 · 모든 쪽이 깨지지 않음 · QR 이 열림 · PDF 검수본 + 검수 글(`antigravity-book-review-task.md`).
6. **AI 도움 공개**: KDP 의 「AI 생성 여부」 질문엔 사실대로. ISBN 화면의 「AI 저자」 선택은 운영자 판단 ⚠(`ops/isbn-forms.md` §먼저 정할 것).

## 9. 책 ↔ 사이트 연결 (우리 서비스의 이점)
책 속 QR → `bonus/<책>/<단원>/`(낱말 카드 · 퀴즈 · 빈칸, 책 밖 새 문항) → 사이트 무료 연습 → AI 쓰기 채점 · Pro.
- 책은 **돈이 되는 입구**이자 **사이트로 사람을 데려오는 입구**다. 모의고사 · 쓰기 책은 QR 이 없거나(모의고사) 7~8단원이다(쓰기).
- ⚠ 측정: 책 QR 스캔 수를 따로 재지 않는다(지금 `bonus/` 쪽 방문은 숫자 판에 합쳐짐). 책별 QR 구분(`?src=book-…`)을 넣을지.

## 11. 하지 않는 것
- 실제 TOPIK · EPS 기출을 싣지 않는다. 지어낸 수상 · 판매량 · 후기 · 기관 정보를 소개 글에 쓰지 않는다.
- 한국어 모국어 화자를 타겟으로 책을 만들지 않는다(필요하면 따로 정한다).
- 판매처에 자동으로 올리는 비공식 확장 프로그램 · 로그인 정보 위임을 쓰지 않는다(약관 위험).
- 학습 자료를 다른 말로 번역해 팔지 않는다(영어 + 한국어 두 언어만). ⚠ 베트남어 · 일본어판은 나중에 정한다.

## 13. 운영자가 정할 것 (⚠ 모음)
1. **독자 범위**: 영어 사용 국가만 vs 영어로 읽는 모든 외국인 학습자(§2). 한국 거주 외국인(D)을 얼마나 챙길지.
