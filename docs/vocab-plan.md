## 1층 — 왜

**한 문장:** 치즈감자에 오는 사람이 **오늘 외울 낱말을 고민 없이 받고, 잊기 전에 다시 만나게** 한다. 그리고
누군가 한국어 낱말을 검색하면 **우리 사이트가 위에 떠서** 새 학습자가 들어오게 한다.

- 지금의 빈자리: 사전(5,779 낱말)은 **찾는** 곳, 내 단어장은 **모으는** 곳 — **외우는 길**이 없다.
- 사이트에 주는 것: 매일 다시 오는 이유(복습) · 검색 유입(낱말 · 목록 쪽) · 나중에 Pro 의 재료.

**성공 기준 (석 달 뒤, 초안 — 첫 달 값을 보고 고친다)**
| 기준 | 목표 |
|---|---|
| 단어 섹션을 연 사람 중 첫날 10개를 끝낸 비율 | 40% ↑ |
| 이틀 이상 다시 와서 복습한 사람 | 15% ↑ |
| 낱말 · 목록 쪽 검색 노출 | 서치 콘솔에서 새 쪽들이 노출되기 시작 |

## 3층 — 구조

**이름: 「단어」.** 지금의 「국어사전」과 「내 단어장」을 하나로 합친다 — **단어는 단어에서 다 공부한다.**

```
단어 (#words)
├─ [검색창] — 맨 위, 어느 탭에서든
├─ 오늘 할 일: 「복습 12개 · 새 낱말 10개」 (복습이 먼저)
└─ 탭: 외우기 │ 복습 │ 내 단어장 │ 기록
```

- 예전 주소(`#dictionary`, 내 단어장)는 새 자리로 넘긴다. `/dictionary/*.html` 정적 쪽은 그대로 두고 「단어에서
  공부하기」 단추를 단다.
- 이어지는 곳: 레벨테스트 → 단어장 추천 · 레슨/지문/문제에서 낱말 누르면 담기 · 녹음소의 녹음 순서.
- 이번 계획에 넣지 않는 것: 점수 경쟁 · 랭킹, 사진으로 단어 만들기(앱 기능), 반 · 선생님 기능.

| S4 | 퀴즈 | 뜻 고르기 · 듣고 고르기 · 예문 빈칸. 틀린 것은 내일 복습 |

### 퀴즐렛에서 가져올 것 (아이디어만 — 이름 · 디자인 · 문구는 우리 것)
| 우리 이름 | 하는 일 | 차수 |
|---|---|---|
| 카드 | 뒤집어 외우기 | 1차 |

| 쓰기 | 뜻 보고 한국어로 치기(띄어쓰기 · 작은 오타 너그럽게) | 1차 |
| 별표 | 어려운 낱말만 모아 공부 | 1차 |
| 방향 | 한 → 영 / 영 → 한 | 1차 |
| 받아쓰기 | 듣고 치기 | 2차 |
| 짝 맞추기 | 낱말 · 뜻 타일 짝짓기, 시간 기록 | 2차 |

우리만의 차이: 검수된 뜻 · 우리 예문 · 원어민 녹음 · TOPIK 수준 표시.

### 검색 — 구글처럼
| 이렇게 치면 | 이렇게 찾는다 |
|---|---|
| `먹었어요` `집에서` | 활용 · 조사를 떼서 → 먹다 · 집 (`gloss-find.js` 재사용) |
| `eat` `hospital` | 영어 뜻 → 먹다 · 드시다 · 식사하다 / 병원 |
| `meokda` `saranghae` | 로마자 → 먹다 · 사랑하다 |
| `ㅅㄹ` | 초성 → 사랑 · 사람 … |
| `먹따` | 오타 → 「이것을 찾으셨나요? 먹다」 |
| `한국 음식` | 띄어쓰기 무시 · 예문 속까지 |

- 자동완성(↑↓ · Enter) · 순위: 정확히 → 앞부분 → 활용형 → 영어 뜻 → 예문, 같으면 TOPIK I · 자주 쓰는 말 먼저
- 결과 카드: 낱말 · 품사 · 수준 · 뜻 한 줄 · 🔊 · 담기 / 없으면 비슷한 말 · 사이트의 다른 곳
- 최근 검색어(이 브라우저) · 주소에 남김(`#words/search/먹다`)
- 속도: 검색 색인을 미리 만들고 **첫 글자별로 쪼개** 필요한 조각만 받는다
- 범위: **1겹 단어**(이번) → **2겹 사이트 전체**(문법 · 레슨 · 문제 · 지문 · 블로그, 「전체 · 단어 · 문법 · 레슨 · 문제 · 글」 탭)

### 검색 유입 — 누가 낱말을 검색하면 우리가 위에
| 검색어 | 받을 쪽 |
|---|---|
| `먹다 meaning` `meokda in English` | 낱말 쪽(`/dictionary/`) — **보강** |
| `how to say hospital in Korean` `Korean word for eat` | **「영어로 찾기」 쪽 새로** — 자주 찾는 영어 낱말 1,000개 |
| `TOPIK 1 vocabulary list` `Korean food vocabulary` | **목록 쪽 새로** |

1. 낱말 쪽을 **사전 복사본이 아니게**: 로마자 · 활용표 · 우리 예문 · 원어민 발음 · 나오는 레슨/문제 · 같은 주제
   낱말 · 미니 퀴즈. 제목은 영어 검색에 맞춘다: `먹다 (meokda) — "to eat" in Korean: meaning, examples, conjugation`
2. 「영어로 찾기」: 한국어가 여럿이면 차이까지(eat → 먹다 / 드시다 / 식사하다).
3. 구조화 데이터(DefinedTerm · FAQ · Breadcrumb) · 쪽끼리 촘촘히 잇기.
4. 모든 낱말 쪽에 「이 낱말이 든 단어장 무료로 외우기 →」 — 검색 유입을 회원으로.
5. 정직하게: 경쟁 센 말은 몇 달. 긴 검색어부터 오른다.

## 5층 — 자료

### 규모와 품질
| 단계 | 낱말 | 품질 |
|---|---|---|
| 1단계 | 약 7,000 (지금 5,779 + TOPIK I 필수) | **A급** — 전부 채움 + 운영자 녹음 |
| 2단계 | 약 15,000 (TOPIK II · EPS · 생활 · 직장) | **B급** — 전부 채움 + 기계 음성 |
| 3단계 | 30,000~50,000 (한국어기초사전 규모) | **C급** — 뜻 · 예문 중심, 차츰 B급으로 |

**1년 목표는 2단계.** C급은 사이트 안에서 찾고 공부할 수 있지만 **검색용 정적 쪽은 B급이 된 뒤에** 연다(빈약한
쪽 수만 개는 사이트 전체의 검색 순위를 깎는다).

### 낱말 하나
```
기본: 표제어 · 품사 · 한자 · 발음 [먹따] · 로마자
수준: TOPIK 급수(1~6) · 빈도 순위
뜻:   한국어 뜻풀이 · 쉬운 영어 뜻 · (나중) 모국어
예문: 2~3개(쉬움 → 어려움) + 영어
활용: 먹어요 · 먹었어요 · 먹을 거예요 · 먹는 · 드세요
관계: 비슷한 말 · 반대말 · 높임말 · 같은 한자
분류: 주제(여럿) · 목적(여럿)
소리: 낱말 · 예문(예문 소리는 A급만 — 비용)
출처 · 품질 등급
```

### 찾는 길
- **목적별**(10~12): 입문 · TOPIK I · TOPIK II · EPS · 한국 생활(KIIP) · 여행 · 직장 · 대학 · 드라마/K-pop · 병원
  — 일단 이대로 만들고 나중에 고친다.
- **주제별**: 대분류 약 30 × 소분류 약 150 (음식 → 과일 · 채소 · 조리 · 맛 · 식당 …)
- 수준별(1~6급) · 품사별 · **한자별**(學 → 학교 · 학생 · 학습) · 초성별
- **세션**: 어떤 묶음이든 **10~15개씩 잘라** 「세션 1, 2 …」. 하루 한 세션. 쉬운 것 · 자주 쓰는 것 먼저.

### 어디서 가져오나
| 무엇 | 어디서 | 확인 |
|---|---|---|
| 표제어 · 뜻풀이 | 국립국어원 한국어기초사전 (CC BY-SA 2.0 KR, 이미 사용) | 출처 표시 · 같은 조건 공유 |
| 급수 · 필수 목록 | 공공 교육용 어휘 목록 + **우리 코스 · TOPIK 문항 등장 빈도** | 공공 목록 이용 조건은 Claude 가 확인, 안 되면 우리 자료로만 |
| 쉬운 영어 뜻 · 예문 · 주제 · 목적 · 관계 | 안티 그래비티 **500개씩** → 검사기 → 운영자 5% 검수 | |
| 활용 · 로마자 · 발음 | 규칙으로 자동 생성(Claude 의 도구) | 불규칙은 따로 목록 · 검수 |
| 소리 | A급 = 운영자 녹음(녹음소) · 나머지 기계 음성 | |

### 내 단어장 연동
- **어디서든 한 번 눌러 담기**: 검색 · 카드 · 낱말 쪽 · 목록 쪽 · 레슨 · 문제 · 지문 · 검색으로 들어온
  `/dictionary/*.html` 까지. **세션 통째로 담기.**
- 단어장 낱말에 **원본 낱말 연결 고리** + **담은 곳**을 적는다 → 단어장에서도 소리 · 예문 · 수준이 보이고 중복이 없다.
- **로그인 안 해도 담는다**(이 브라우저) → 로그인하면 계정으로 자동으로 옮긴다(겹치면 하나로).
- **복습은 한 목록, 저장은 따로**: 내 단어장(내가 고른 것)과 외우기 기록(공부한 진도)은 다른 표. 복습 탭이 둘을 합쳐 보여 준다.
- 내 단어장도 한 세트처럼 — 카드 · 외우기 · 쓰기 · 짝 맞추기 · 시험 · 별표 · 엑셀/CSV 내보내기.
- **웹과 안드로이드 앱이 같은 `words` 표**를 쓴다 — 이미 기기 사이가 이어진다. 새 칸은 앱이 몰라도 안 깨지게 더한다.
  **앱에 새 정보를 보여 주는 것은 나중**(앱 저장소 작업).
- 서버: `words` 에 칸 둘 · 외우기 기록 표 하나 — Claude 가 `db/*.sql` 로 쓰고 운영자가 SQL Editor 에서 한 번 돌린다.

## 7층 — 위험과 되돌리기

| 위험 | 막는 법 |
