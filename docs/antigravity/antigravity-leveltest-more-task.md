# 안티 그래비티 작업 지시 — 레벨테스트 문제 늘리기 (레벨마다 8 → 20)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해.」

**왜:** 승급 테스트(레벨 L → L+1)가 그 레벨 문제 8개 + 아래 레벨 2개로 10문제를 낸다. 레벨마다 문제가 **8개뿐**이라
다시 보면 똑같은 문제가 나온다. 레벨마다 **20개**가 되게 채운다(`docs/plans/level-plan.md` 6층 ②).

## 2차: L7 에 12문제 (2026-10-01) — ✅ 끝(L0 ~ L7 모두 20문제). 고칠 것 없었다 — 오답 보기도 다 확실히 틀린 꼴이었다.

1차(L0 ~ L6 각 20문제)는 끝났다. 이번에는 **L7 만** 8 → 20 으로 채운다(12문제). L0 ~ L6 은 건드리지 않는다.

```bash
git fetch origin && git checkout -b leveltest-l7 origin/main
```

- L7 = 고급(`docs/plans/curriculum-upper.md` 의 L7 문법 — -(으)ㄹ 뿐만 아니라, -는 반면에, -기 마련이다, -(으)ㄴ 끝에, -는 셈이다,
  -(으)ㄹ 법하다, -기는커녕, -더라도 …). 이미 있는 L7 8문제와 **같은 문법만 되풀이하지 말고** 고루 나눈다.
- 모양 · 지킬 것은 아래 1차와 같다(보기 4개 · `why` 필수 · L7 주석 아래 마지막 문제 뒤에).
- **오답 보기는 문장에 넣으면 확실히 틀린 말이어야 한다** — 같은 뜻의 다른 문법(「-더라도」 자리에 「-아도」)을 오답으로 쓰지 않는다.
- 끝나면 `node tools/check-leveltest.mjs` 로 L7 이 20 인지 보고,
  `git add -A && git commit -m "leveltest: L7 to 20 questions" && git push -u origin leveltest-l7`. PR 은 열지 않는다.

## 문제 모양 — 이미 있는 것과 똑같이

```js
{ lv: 4, q: '내일 비가 ___ 우산을 가져가세요.', options: ['오면', '와서', '오니까', '오지만'], answer: 0,
  why: '조건을 말할 때는 「-(으)면」을 써요.' },
```

- `options` 는 꼭 4개, 서로 달라야 한다. `answer` 는 정답 자리(0부터). 화면에서 섞이므로 정답을 늘 0 에 둬도 된다.
- `why` 는 **반드시** 쓴다. 한 줄, 학습자에게 보이는 말투(-요).
- **같은 레벨끼리 모아 둔다** — 그 레벨 주석(`// ── L4 …`) 아래, 그 레벨의 마지막 문제 뒤에.
- 이미 있는 문제와 **같은 문장을 또 쓰지 않는다**(검사기가 잡는다). 비슷한 문장도 피한다 — 승급 테스트가 다른 문제를 내려는 것이다.

## 레벨마다 무엇을 묻나

| 레벨 | 묻는 것 | 보기 |
|---|---|---|
| L0 | 한글 낱말을 소리 내어 읽기(받침 · 된소리 · 겹모음 ㅘ ㅝ ㅢ 도 섞는다) | 로마자 4개 (`ba-na-na` …) |
| L1 | 이에요/예요 · 은/는 · 이/가 · 인사말 · 아주 흔한 낱말 뜻 · 숫자 | |
| L2 | 조사 을/를 · 에 · 에서, 안/못, 현재 -아요/어요, 있어요/없어요, 하다 동사 | |
| L3 | 과거 -았/었-, -고 있다, -기 전에 / -(으)ㄴ 후에 / -(으)ㄹ 때, 불규칙 ㄷ · 르 · ㅂ, 높임 -(으)시- | |
| L4 | -아서/-니까, -(으)면, -는데, -아/어 주다, -아야 하다, -(으)ㄹ 수 있다, -고 싶다 | |
| L5 | -아/어 본 적이 있다, -(으)러, -(으)ㄹ 것 같다, 관형형 -는/-(으)ㄴ/-(으)ㄹ, 높임말 넓히기 | |
| L6 | 중급(`docs/plans/curriculum-upper.md` 의 L6 문법 — -느라고, -는 바람에, -(으)ㄹ 텐데, -다가 …) | |

> **1차(2026-09-30)에서 Claude 가 고친 것 — 다음엔 이것부터 본다:** 84개 중 15개. 빈칸 뒤 글자와 답을 **이어 붙여 읽어 본다**
> (「가___」+「싶어요」 = 가싶어요 ✗). 활용은 실제 꼴로(벗다 → 벗**어**야). 오답 보기를 넣어 **말이 되면 버린다**(가르쳐 봤어요 · 가도 돼요 · 입학하는 학생).

## 반드시 지킬 것

1. **정답이 하나뿐이어야 한다.** 오답 보기도 말이 되는 문장이면 그 문제는 버린다.
2. **그 레벨 문법 · 낱말로만 풀려야 한다.** L3 문제에 L5 낱말이 끼면 L3 학생이 문법이 아니라 낱말 때문에 틀린다.
3. 사람 이름은 흔한 것(민수 · 지현)만. 실제 TOPIK 기출 문장을 옮기지 않는다(전부 새로 쓴다).
4. 한자를 쓰지 않는다.
5. 검사기를 고치지 않는다.
