# 안티 그래비티 진행표

> 「안티가 올렸어」를 받으면 Claude 는 **이 표부터** 본다 → 그 브랜치를 main 과 견준다 → 검토해 넣고 이 표를 고친다.
> 칸: **올라옴**(브랜치에 푸시됨) · **넣음**(검토 끝, main 에 머지). 숫자는 묶음.

> 마지막 확인: 2026-10-10 (브랜치를 main 과 직접 견줘서).

- 브랜치가 main 보다 「앞서」 보여도 squash 머지 때문일 수 있다 — 파일 내용을 main 과 직접 견준다.
