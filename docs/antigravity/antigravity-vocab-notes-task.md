# 안티 그래비티 작업 지시 — TOPIK II 단어장 「헷갈리는 낱말」(유의어 · 동음이의어)

> 운영자 2026-10-25 「유의어나 동음이의어 구분 잘해서」. 단어장 책(`topik2-vocab-1000`)의 단원마다 **헷갈리는 낱말 표**를 더한다. 책의 단원 끝에 표로 들어간다.

## 무엇을
- 결과 파일: **`docs/vocab-book/topik2-vocab-1000.notes.json`** 한 파일(묶음마다 이어서 더한다, 있는 단원은 건드리지 않는다). 브랜치 `ag/vocab-notes-N`.
- 단원 목록과 낱말: `node tools/vocab-notes-list.mjs tv-01` (한자 · 품사 · 뜻 · 우리 자료의 비슷한 말/반대말이 나온다). 단원은 `tv-01` ~ `tv-50`.
- 모양: 키 = 단원 id, 값 = 항목 배열(단원마다 **2~4개**).

```json
"tv-01": [
  { "words": ["수면", "수면"], "kind": "homonym", "note": "睡眠 sleep vs 水面 surface of water. Same spelling, different meaning; context decides. 수면 부족 (lack of sleep), 수면 위 (on the water)." },
  { "words": ["취하다", "고르다"], "kind": "synonym", "note": "Both can mean to choose, but 취하다 is formal or written (취하는 태도), 고르다 is everyday (옷을 고르다)." }
]
```
- `kind`: `synonym`(뜻이 비슷한 말) · `homonym`(철자가 같고 뜻이 다른 말) · `contrast`(모양 · 소리가 비슷해 헷갈리는 말, 또는 반대말과 같이 구분할 것).
- `words`: 한국어 낱말 2개(동음이의어는 같은 낱말 두 번, 한자나 뜻으로 구분). 그 단원 낱말이 **적어도 하나** 들어가야 한다. 다른 낱말은 책 안(`tv-*`) 또는 아주 흔한 낱말.
- `note`: **영어 한두 문장 + 한국어 예 짧게**(280자 안쪽). 어떻게 다른지(격식 · 말투 · 쓰는 짝 · 뜻의 범위)를 구체적으로.

## 규칙 (꼭 지킬 것)
1. **사실이어야 한다.** 한국어 사전으로 두 번 확인한다. 의심스러우면 그 항목은 빼고 `docs/antigravity/vocab-notes-notes.md` 에 단원 id 와 한 줄로 적는다. 억지로 칸을 채우지 않는다(단원에 마땅한 항목이 1개뿐이면 1개).
2. **동음이의어는 한자 · 뜻이 정말 둘인 것만**(예: 수면 睡眠/水面). 한자가 같은 한 낱말의 여러 뜻은 동음이의어가 아니다.
3. 유의어는 **어떻게 다른지** 를 꼭 쓴다. 「비슷하다」만 적지 않는다. 바꿔 써도 되는 경우와 안 되는 경우를 하나씩.
4. 예문은 새로 짓는다. **실제 TOPIK 기출 문장을 쓰지 않는다.**
5. 줄표(—)를 쓰지 않는다(쉼표 · 쌍점으로).
6. 다른 파일 · 다른 단원 · 이미 있는 항목을 고치지 않는다.

## 하는 법
1. `git pull` 로 main 을 받고 브랜치를 만든다.
2. `node tools/vocab-notes-list.mjs tv-01` 처럼 한 묶음(단원 10개)을 본다.
3. 위 JSON 파일에 키를 더한다.
4. `node tools/build-topik2-vocab-book.mjs` 가 에러 없이 끝나는지 본다. 그다음 **notes JSON 만** 커밋한다(`docs/books/…` · `bonus/` 는 Claude 가 만든다).
- 커밋 메시지: `단어장 헷갈리는 낱말 · tv-01~tv-10 N단원`. 푸시한다(PR 은 만들지 않는다). 끝나면 한 줄: 「<브랜치> · N단원 · 건너뜀 K · <커밋 앞 7자리> 올림」.
