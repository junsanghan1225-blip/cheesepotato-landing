## 꼭 지킬 것
1. **`{0}` `{1}` 자리 표시는 그대로**(숫자 · 이름이 들어가는 자리). 순서는 몽골어에 맞게 바꿔도 된다: 자리 표시의 위치는 그 말의 어순에 맞게 옮긴다.
2. **HTML 태그 그대로**(`<br>` `<b>…</b>` `<em>` `<small>`) — 태그 수와 종류가 같아야 한다.
3. **한국어 학습 내용은 옮기지 않는다** — 영어 원문 안의 한국어 낱말 · 문법(`-아요`, `「가다」`, `TOPIK`, `L3`)은 그대로 둔다.
4. 사이트 이름 `CheesePotato` · `Cheesepotato` · `Every Koreans` · `Pro` · `TOPIK` · `AI` 는 **그대로 둔다**(영어 글자 그대로).
5. 말투: 친근하지만 예의 바르게 — 사용자에게는 **「Та」 높임말**(「чи」 반말은 쓰지 않는다). 단추는 1~3낱말, 명령형 동사(「Эхлэх」「Дараагийн」)로. 숫자는 **아라비아 숫자(0-9) 그대로**. 몽골 키릴 글자(Ө · Ү 포함)로 쓴다. 자리 표시 뒤 낱말이 수에 따라 바뀌는 곳(「{0} lesson(s)」)은 어느 수에서도 어색하지 않은 말(「Хичээлийн тоо: {0}」)로 풀어 쓴다.
6. 이모지 · 화살표(→ ✓ ·)는 그대로.

## 이 언어에서 더 알아 둘 것
몽골어 사용자는 한국에서 공부하거나 일하려는(EPS · 유학) 몽골 학습자다. 한국어 문법 용어(어미 · 조사 · 존댓말 등)는 몽골의 한국어 교육에서 흔히 쓰는 말을 따르되, 확실하지 않으면 쉬운 몽골어로 풀어 쓴다. 러시아어 외래어가 섞인 말은 피하고 몽골어 낱말을 우선한다.
