# 안티 그래비티 지시서 — 번역 연습 글 만들기(영어 → 한국어, 한 줄씩)

브랜치: `translate` (main 에서 새로). **`docs/translate.json` 하나만 고친다** — 도구(`tools/`) · 생성물(`translate.js`)은 손대지 말 것.
모든 글은 **창작**. 교과서 · 시험 · 기사 · 노래 가사를 옮기지 않는다. 실제 사람 · 회사 이름, 정확한 통계 · 법 · 요금 같은 「사실」은 넣지 않는다.

## 무엇인가
사이트의 새 섹션 「번역 연습」(`#learn/translate`). 학생이 짧은 영어 글을 **한 줄씩** 한국어로 옮겨 쓴다.
학생 답에서 띄어쓰기 · 문장부호를 뺀 뒤 `ko` 목록 가운데 하나와 같으면 정답이고, 다르면 `ko` 를 모두 보여 준다.
그래서 **맞는 답을 여러 개(2~4개) 넣는 것이 가장 중요하다.** 존댓말과 반말, 다른 낱말, 다른 어순까지 자연스러운 것은 모두 넣는다.

## 만들 양 — 모두 45편
| 단계 tier | 편수 | 줄 수 | 문장 수준 |
|---|---|---|---|
| `beginner` | 20편 | 5~7줄 | 해요체 · 한 문장 6~10어절 이하 · TOPIK 1~2급 낱말 · 일상 장면(카페 · 가게 · 길 묻기 · 가족 · 날씨 · 취미 · 학교) |
| `intermediate` | 15편 | 5~8줄 | 해요체/합니다체 · 이유 · 조건 · 추측 · 경험(-아서, -(으)면, -(으)ㄴ 적이 있다, -(으)ㄹ 것 같다 …) · 회사 · 병원 · 이사 · 여행 문제 |
| `advanced` | 10편 | 5~8줄 | 글말(-다 · -ㄴ다) · 짧은 칼럼 · 뉴스 해설 · 의견 글 · TOPIK II 쓰기 54번 같은 논리 흐름 |

이미 있는 견본 3편(`b-cafe` · `i-late` · `a-remote`)과 **장면이 겹치지 않게** 한다.

## 모양(이미 있는 견본과 똑같이)
```json
{
  "id": "b-family",
  "tier": "beginner",
  "title": { "ko": "우리 가족", "en": "My family" },
  "lines": [
    { "en": "There are four people in my family.",
      "ko": ["우리 가족은 네 명이에요.", "저희 가족은 네 명이에요.", "우리 가족은 모두 네 명이에요."],
      "hint": "명 = counter for people · 네 = four (native)",
      "g": "<문법 id, 있을 때만>" }
  ]
}
```
- `id`: 단계 첫 글자(`b-` · `i-` · `a-`) + 영문 소문자 · `-`. 겹치지 않게.
- `en`: 자연스러운 영어 한 문장(한글 섞지 않기). 줄들이 **하나의 글 · 대화로 이어지게** 쓴다.
- `ko`: 맞는 한국어 2~4개. **첫째가 모범 답**(그 단계에 가장 알맞은 말투). 영어 낱말을 섞지 않는다(숫자는 아라비아 숫자도 하나 넣어 줘도 좋다).
- `hint`: 영어로 짧게 — 열쇠 낱말 뜻이나 쓸 문법 이름. 답을 통째로 알려 주지 않는다.
- `g`: 그 줄의 핵심 문법이 사이트 문법 목록(`sentences.js` · `sentences-*.js` 의 `id`)에 있으면 그 id. 없으면 칸을 빼라.
- 확실하지 않은 줄에는 `"note": "운영자 확인"` 을 달아도 된다(검사가 막는다 — Claude 가 보고 지운다).

## 확인 · 끝나면
`node tools/build-translate.mjs` 를 돌려 오류가 없는지 본다(id · 단계 · 줄 수 · 영어/한국어 섞임 · 없는 문법 id 를 잡는다).
오류가 없으면 `docs/translate.json` 만 커밋 · 푸시. `translate.js` 와 자국은 Claude 가 main 기준으로 다시 만든다.
