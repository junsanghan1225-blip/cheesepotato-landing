# 안티 그래비티 작업 지시 — 감자와 치즈 동화책 10편

> 이 파일 전체를 안티 그래비티에 붙여 넣는다. (운영자 결정 2026-10-03)

## 가장 먼저 — 저작권 (이것을 어기면 사이트가 끝난다)

1. **전부 새로 지은 이야기만.** 이미 있는 동화 · 전래동화 · 그림책 · 교과서 이야기 · 만화 · 애니메이션 · 영화 · 드라마 · 노래 ·
   게임의 **줄거리 · 인물 · 장면 · 문장 · 제목**을 옮기거나 「조금 바꿔」 쓰지 않는다.
   - 안 되는 예: 토끼와 거북이처럼 경주하는 이야기, 흥부 놀부처럼 착한 형 · 욕심쟁이 동생, 신데렐라처럼 잃어버린 신발,
     아기 돼지 삼형제처럼 집 세 채, 금도끼 은도끼처럼 정직하면 상 받는 이야기. **이름만 바꾼 것도 안 된다.**
   - 「유명한 이야기의 교훈」을 그대로 따라가는 줄거리도 피한다. 우리 이야기는 **동네의 작은 하루**(장보기 · 날씨 · 이웃 ·
     요리 · 길 찾기 · 생일 · 버스 · 시장 · 도서관)에서 나온다.
2. **등장인물은 감자와 치즈, 그리고 이야기마다 새로 지은 이웃**(예: 빵집 사장님, 옆집 할머니, 우체부 아저씨)뿐.
   다른 작품의 캐릭터 · 실존 인물 · 연예인 · 브랜드(가게 이름 · 상품 이름)를 쓰지 않는다.
3. **노래 가사 · 시 · 속담 풀이 · 광고 문구를 넣지 않는다.** 노래를 부르는 장면이면 「감자가 노래를 불러요」로만.
4. 쓰고 나서 스스로 묻는다: 「이 줄거리, 어디서 본 적 있나?」 — 조금이라도 그렇다면 버리고 새로 쓴다.
   비슷한 것이 떠오르면 그 편에 `"note": "운영자 확인 — 비슷한 것: …"` 을 남긴다(Claude 가 검토한다).

## 누구를 위한 책

- **입문~초급 어른 외국인 학습자**(감자 레벨 1~3). 아이 말투(「~했단다」 「옛날옛날에」)는 쓰지 않는다.
- 문장은 짧게, 한 쪽에 한두 문장. 현재형 해요체 위주(L1), L2 부터 과거형 · -고 · -아서/어서 · -(으)려고 · -(으)ㄹ게요 정도.
- **10편**: L1 4편 · L2 4편 · L3 2편. 한 편 6~10쪽.
- 끝이 따뜻하고 작게 웃긴 이야기. 무섭거나 슬픈 것 · 다툼이 큰 것은 피한다.

## 모양 — `stories.js` 의 `sb-01` 을 그대로 따른다

먼저 `stories.js` 맨 위 설명과 `sb-01`(비 오는 날의 우산)을 읽는다. 새 이야기는 `sb-02` ~ `sb-11`.

```json
{ "id": "sb-02", "lv": 1,
  "title": { "ko": "…", "en": "…" },
  "blurb": { "ko": "한 줄 소개", "en": "…" },
  "pages": [ { "who": "n", "ko": "…", "en": "…" }, { "who": "potato", "ko": "\"…\"", "en": "\"…\"" } ],
  "words": [ { "ko": "기본형", "en": "뜻" } ],
  "quiz": [ { "q": { "ko": "…", "en": "…" }, "options": ["…", "…", "…", "…"], "answer": 2 } ] }
```

- `who`: `potato` 감자가 말함 · `cheese` 치즈가 말함 · `n` 해설(다른 이웃이 말하면 `n` 으로 두고 「사장님이 말해요. "…"」).
- 감자 · 치즈가 말하는 쪽은 **따옴표로 시작**한다.
- `en` 은 자연스러운 영어 번역(한 문장씩 맞춰서).
- `words` 5~8개 — 본문에 실제로 나오는 말의 기본형.
- `quiz` 2~3개 — 본문만 읽으면 풀리는 것. 정답 자리(`answer`)를 0~3 에 고루.
- 숫자 · 시간은 한글로(「세 시」, 「천 원」). 기계 목소리가 읽는다.

## 내는 법

```bash
git checkout main && git pull origin main
git checkout -b storybooks
# stories.js 의 STORIES 배열 끝(sb-01 뒤)에 sb-02 ~ sb-11 을 더한다
node tools/check-stories.mjs      # 「문제 없음」이 나와야 한다(이름난 작품 · 인물 이름이 있으면 막힌다)
git add stories.js && git commit -m "storybooks: sb-02 ~ sb-11"
git push -u origin storybooks
```

- **다른 파일 · 도구(`tools/`)는 고치지 않는다.** 자국(stamp)도 찍지 않는다 — Claude 가 검토하며 찍는다.
- `check-stories` 의 「짚어 볼 것」(쪽이 길다 · 낱말이 본문에 안 보인다)도 될 수 있으면 0 으로.
