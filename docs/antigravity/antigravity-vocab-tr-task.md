# 안티 그래비티(또는 Haiku) 작업 지시 — 낱말 뜻을 베트남어 · 일본어로 (1,000개 한 묶음)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해. 이번은 **N묶음**이야.」
> 브랜치: `vocab-tr` (main 에서 새로). 운영자 요청 2026-10-09 「글로벌하게 검색에 뜨려면」 — 베트남 · 일본 학생이
> 자기 말로 낱말을 찾을 때(「cửa hàng tiếng Hàn」 · 「店 韓国語」) 우리 사전 쪽이 뜨게 하려고, 낱말마다 그 나라 말 뜻을 붙인다.

## 무엇을
- `vocab/data/topik1.json` · `vocab/data/topik2.json` 의 낱말마다 **`tr` 칸 하나만 더한다**:
  ```json
  { "id": "오다", "head": "오다", "pos": "동사", "en": "to come", …, "tr": { "vi": "đến", "ja": "来る" } }
  ```
- `vi`(베트남어) · `ja`(일본어) 둘 다. 뜻 **한두 개, 짧게**(사전 표제어처럼). 문장으로 쓰지 않는다.
- 다른 칸(`head` · `en` · `topics` · `examples` …)은 **한 글자도 바꾸지 않는다.** 줄 차례도 그대로.

## 묶음
- 1묶음 = `topik1.json` 1~1,000번째, 2묶음 = 1,001번째~끝
- 3묶음부터 `topik2.json` — 3묶음 = 1~1,000번째, 4묶음 = 1,001~2,000 … 11묶음 = 8,001~끝
- 이미 `tr` 이 있는 낱말은 건너뛴다.

## 지킬 것
- 뜻은 **한국어 낱말(`head`) · 품사(`pos`) 를 보고** 정한다. 영어(`en`)는 참고만 — 영어를 다시 옮기면 뜻이 비틀어진다
  (예: 「아깝다」 en "to be a waste" → vi 「tiếc」 · ja 「もったいない」).
- 동사 · 형용사는 그 나라 말의 기본형으로(ja 「来る」, vi 「đến」). 명사는 명사로.
- 한자어는 일본어에서 같은 한자가 있어도 **뜻이 같을 때만** 그대로 쓴다(「공부」→「勉強」은 좋지만, 「방송」→「放送」처럼 같으면 그대로, 「애인」→「恋人」처럼 다르면 바꾼다).
- 뜻이 여럿이면 가장 흔한 것 하나, 많아도 둘(쉼표로).
- 모르면 비워 두지 말고 가장 가까운 뜻을 쓰되, 그 낱말 id 를 커밋 메시지에 「확인 필요: …」로 적는다.

## 올리기
