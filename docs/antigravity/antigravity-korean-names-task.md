# 안티 그래비티 지시서 — 한국 이름 늘리기(「나의 한국 이름 짓기」)

> 브랜치: `korean-names` · 묶음: 2(1묶음 60개 · 2묶음 60개) · 고칠 파일: **`korean-names.js` 의 `given` 목록만**
> 쓰이는 곳: `/my-korean-name/` — 외국인이 「한국에서 태어났다면 내 이름은?」을 받아 카드로 저장한다.

## 할 일
`korean-names.js` 의 `given: [ … ]` 끝에 이름을 더한다. 지금 45개 → 165개쯤.

한 줄 모양(지금 것과 똑같이):
```js
{ ko: '하은', g: 'f', hj: [['河', '물 하', 'river'], ['恩', '은혜 은', 'grace']], en: 'a river of grace' },
{ ko: '하늘', g: 'u', en: 'sky', native: true },
```
- `ko`: 이름 두 글자(한글). **요즘 한국에서 실제로 흔한 이름**만(2000년대 이후 출생 통계에 자주 보이는 이름 · 고유어 이름).
- `g`: `f`(주로 여자) · `m`(주로 남자) · `u`(둘 다 흔함).
- `hj`: 한자 두 개 — 각각 `[한자, '훈 음', '영어 뜻']`. 훈음은 **표준 훈음**(예: 智 「슬기 지」, 恩 「은혜 은」). 그 이름에 **실제로 흔히 쓰는** 한자 조합 하나.
- `en`: 두 한자 뜻을 합친 짧은 영어(4~7낱말, 소문자로 시작, 마침표 없음). 고유어 이름은 우리말 뜻.
- 고유어 이름(하늘 · 다솜 · 나래 …)은 `hj` 없이 `native: true`.

## 지킬 것
1. **이미 있는 줄 · `surnames` 는 건드리지 않는다.** 같은 `ko` 를 두 번 넣지 않는다.
2. **지어내지 않는다.** 한자의 훈음 · 뜻이 맞는지 하나씩 확인한다. 자신 없는 한자는 넣지 않는다.
3. 인명용으로 잘 안 쓰는 한자, 뜻이 나쁜 글자(죽을 사 · 슬플 비 …)는 쓰지 않는다.
4. 연예인 · 유명인 이름을 일부러 고르지 않는다(흔한 이름이 겹치는 것은 괜찮다).
5. 영어 뜻은 과장하지 않는다(「a god of …」 같은 말 금지).
6. 1묶음: 여 25 · 남 25 · 둘 다 5 · 고유어 5 / 2묶음: 같은 비율로 60개 더.

## 올리기
`korean-names.js` 만 고쳐서 `korean-names` 브랜치에 푸시. 커밋 메시지: `한국 이름 N묶음 — 60개`.
