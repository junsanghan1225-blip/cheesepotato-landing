# 뜻풀이 사전 채우기 — Gemini 지시문

사전이 덮는 만큼만 학습자의 뜻 칸이 채워진다. 지금 얼마나 덮는지는:

```bash
node tools/check-glossary.mjs
```

채울 차례를 뽑는다 (이미 사전에 있는 것은 빠진다):

```bash
node tools/glossary-words.mjs 200 > /tmp/words.tsv
```

세 칸이 탭으로 나온다 — `낱말`, `나온 횟수`, `처음 나온 문장`. 이 파일을
아래 지시문 뒤에 그대로 붙여서 보낸다.

받은 JSON 은 파일로 저장해서 검사기로 넣는다 — 모양(한글 표제어인지·영어
뜻이 있는지·활용형이 다른 표제어와 안 겹치는지)을 봐 준다:

```bash
node tools/add-glossary-words.mjs 받은것.json --dry   # 넣기 전에 먼저 훑어본다
node tools/add-glossary-words.mjs 받은것.json         # 문제 없으면 진짜로 넣는다
node tools/build-glossary.mjs && node tools/check-glossary.mjs && node tools/stamp.mjs
```

## 지시문 (여기서부터 복사)

당신은 한국어 교재의 어휘 목록을 만드는 편집자입니다. TOPIK 읽기 지문에서
뽑은 낱말 목록을 드릴 테니, 한국어를 배우는 외국인 학습자가 단어장에 담을
뜻풀이를 만들어 주세요.

**JSON 배열 하나만** 출력하세요. 설명, 인사말, 코드 블록 표시를 붙이지
마세요.

### 줄 하나의 모양

```json
{ "ko": "표제어", "en": "English gloss", "alt": ["활용형", "활용형"] }
```

- `ko` — **사전에 실리는 꼴**입니다. 받은 낱말이 「먹었습니다」처럼 활용형이면
  표제어 「먹다」로 바꿔 적고, 받은 꼴은 `alt` 에 넣으세요. 받은 낱말이
  「주말에」처럼 조사가 붙은 꼴이면 「주말」이 표제어입니다.
- `en` — 영어 뜻. **반드시 있어야 합니다.** 다른 말을 모를 때 대신 나갑니다.
  - 짧게. 두세 낱말이 알맞고, 60자를 넘기지 마세요. 단어장 한 줄에 들어가야
    합니다.
  - 뜻이 여럿이면 `;` 로 나누되 **두 개까지만**. 「눈」은 `eye; snow` 로 충분하고
    세 번째 뜻까지 적으면 외울 것이 아니라 읽을 것이 됩니다.
  - 동사·형용사는 `to ...` 꼴로. 「먹다」는 `to eat`, 「좋다」는 `to be good`.
    한국어 형용사는 영어에서 동사처럼 쓰이므로 `good` 이 아니라 `to be good`
    입니다.
  - 한글을 섞지 마세요.
- `alt` — 지문에 실제로 나오는 활용형. 없으면 이 칸을 빼세요.
  - **만들어 내지 마세요.** 드린 목록과 예문에 보이는 꼴만 적습니다. 있을 법한
    활용형을 상상해 채우면 사전이 커지기만 하고 맞는 일이 없습니다.
  - 한 활용형은 한 표제어에만 붙일 수 있습니다. 「삽니다」는 「사다」에도
    「살다」에도 갈 수 있는데, 그러면 어느 뜻이 나갈지 정할 수 없습니다.
    **이런 꼴은 양쪽 모두에서 빼세요.**

### 반드시 지킬 것

1. **모르면 빼세요.** 확신이 없는 낱말은 그 줄을 통째로 내보내지 마세요.
   빈 칸은 학습자가 채우면 되지만, 틀린 뜻은 외우고 나서야 압니다. 목록을
   다 채우는 것보다 틀린 줄이 없는 것이 훨씬 중요합니다.
2. **사람 이름과 지명은 빼세요.** 「민수」「지현」「뚜언」「링링」 같은 것은
   지문 속 인물이라 단어장에 담을 말이 아닙니다.
3. **문제지의 상투어는 빼세요.** 「고르십시오」「알맞은」「것을」처럼 문제를
   싸는 말은 지문의 어휘가 아닙니다.
4. **드린 예문의 쓰임을 따르세요.** 「시장」은 `market` 과 `mayor` 둘 다지만,
   예문이 「시장에서 옷을 샀습니다」라면 `market` 입니다. 예문에 맞는 뜻을
   앞에 두세요.
5. 표제어는 한글만. 숫자·괄호·공백을 넣지 마세요.

### 보기

받은 줄:

```
있습니다	98	아버지하고 어머니가 계십니다. 귀여운 남동생도 한 명 있습니다.
주말에	28	주말에 학교 친구들과 같이 산에 가기로 했습니다.
민수	19	민수 씨는 버스를 타고 회사에 갑니다.
```

내보낼 것:

```json
[
  { "ko": "있다", "en": "to be (there); to have", "alt": ["있습니다"] },
  { "ko": "주말", "en": "weekend", "alt": ["주말에"] }
]
```

「민수」는 사람 이름이라 뺐습니다.

## 다른 말을 더할 때

`en` 말고 다른 칸을 더하면 그 말을 쓰는 학습자에게 그 말로 나갑니다.
칸 이름은 두 글자 언어 코드입니다 — `ja` 일본어, `zh` 중국어, `es` 스페인어,
`fr` 프랑스어, `de` 독일어, `it` 이탈리아어, `ru` 러시아어, `vi` 베트남어,
`th` 태국어, `pt` 포르투갈어, `id` 인도네시아어, `ar` 아랍어, `ko` 한국어 뜻풀이.

```json
{ "ko": "주말", "en": "weekend", "ja": "週末", "vi": "cuối tuần", "alt": ["주말에"] }
```

**`en` 은 어느 경우에도 빼지 마세요.** 학습자가 고른 말에 뜻이 없으면 영어로
물러서게 되어 있습니다. 영어마저 없으면 빈 칸이 나갑니다.

한 번에 한 말씩 더하는 편이 낫습니다. 열 말을 한꺼번에 시키면 검사기가
잡지 못하는 자리(뜻이 미묘하게 어긋나는 것)에서 틀리기 시작합니다.
