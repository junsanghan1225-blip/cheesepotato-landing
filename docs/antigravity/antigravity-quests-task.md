> **5묶음**: 1 = write(상황 퀘스트) · 2 = continue(이어 쓰기) · 3 = fix(고쳐 쓰기) · 4 = translate(영어 → 한 문장) · 5 = speak(즉석 말하기). 한 묶음 = 한 모드 10개.
> 먼저 `docs/plans/weave-fluency.md` 의 7번과 `docs/weave.json` 의 `quests` 를 열어 **모양과 질을 맞춘다**(지금 37개).

## 화면이 하는 일 (이걸 알아야 과제를 맞게 쓴다)
학생이 한 화면에서 **한 문장을 통으로** 쓴다(마이크로 말해도 된다). 쓰는 즉시 앱의 **인식기**가 이음말(-는데 · -지만 · -아서/어서 · -(으)니까 · -고 · -(으)면)을 찾아 문장을 **마디**로 나누고, 과제의 **조건**(`req`)을 하나씩 확인한다. 조건을 다 채우면 통과. 다섯 모드는 하는 일이 다르다 — **모드가 서로 비슷해 보이면 실패**다.
| 모드 | 학생이 하는 일 | 화면에 보이는 것 |
|---|---|---|
| `write` 🧩 상황 퀘스트 | 상황을 읽고 조건을 채워 한 문장 쓰기 | 상황 · 질문 칩(`cues`) · (초급) 틀(`frame`) |
| `continue` ✍️ 이어 쓰기 | 주어진 **첫 마디**에서 이어 문장을 길게 키우기 | 첫 마디(`start`, 글 칸에 미리 들어 있다) |
| `fix` 🔧 고쳐 쓰기 | **이상한 글**(이음말이 틀림 · 끊김 · 빠짐 · 한 가지만 반복)을 고치기 | 고칠 글(`start`, 글 칸에 미리 들어 있다) |
| `translate` 🌏 영어 → 한 문장 | 영어 뜻을 한국어 **한 문장**으로 말하기 | 영어 문장(`meaning`) · 낱말 칩(`hints`) |
| `speak` ⏱ 즉석 말하기 | 주제를 보고 **40초** 안에 쉬지 않고 말하기(마이크) | 주제 · 타이머 |

## 과제 하나의 모양 (`docs/weave.json` 의 `quests` 에 **더한다** — 이미 있는 것은 건드리지 않는다)
```json
{ "id": "q-hobby", "mode": "write", "lv": 2, "icon": "📷",
  "title": { "ko": "내 취미", "en": "My hobby" },
  "situation": { "ko": "취미를 이유와 함께 소개해요.", "en": "Introduce your hobby with a reason." },
  "cues": ["무슨 취미예요?", "왜 좋아해요?"],
  "req": { "conn": ["aseo"], "clauses": 3, "one": true, "polite": true },
  "model": { "ko": "저는 사진을 좋아해서 주말마다 카메라를 들고 나가요.", "en": "…" },
  "bonus": { "req": { "clauses": 4 }, "model": { "ko": "…", "en": "…" } } }
```
- **공통**: `id`(영문 소문자 · 숫자 · -, 겹치지 않게 — write `q-…` · continue `c-…` · fix `f-…` · translate `t-…` · speak `s-…`) · `mode` · `lv`(1~5) · `icon`(이모지 하나) · `title`(ko · en) · `situation`(ko · en: 학생에게 하는 지시) · `req`(조건) · `model`(모범 답 ko · en).
- **`req` 조건** — 쓸 수 있는 것만:
  | 키 | 뜻 |
  |---|---|
  | `conn: ["nde","jiman",…]` | 이 이음말을 꼭 쓴다(`nde -는데` · `jiman -지만` · `aseo -아서/어서` · `nikka -(으)니까` · `go -고` · `myeon -(으)면`) |
  | `no: ["jiman"]` | 이 이음말은 쓰지 않는다 |
  | `minConns: 3` | 이음말(종류 상관없이) 3개 이상 |
  | `clauses: 4` | 4마디 이상(마디 = 이음말로 이어진 토막 + 마지막 토막) |
  | `words: ["조용","공원"]` | 이 낱말(앞부분)이 글에 들어 있다 — 「조용」은 조용한 · 조용해요 모두 인정 |
  | `distinct: true` | 같은 이음말은 한 번씩만 |
  | `minWords: 12` | 12어절 이상 |
  | `keep: "비가 오는데"` | 글이 이 첫 마디로 시작한다(continue 전용) |
  | `one: true` | 한 문장(중간에 마침표 · 「~요」로 끊지 않기) |
  | `polite: true` | 해요체(~요)로 끝내기 |
- **모드마다 더 필요한 것**: continue → `start`(첫 마디 + 끝에 공백, 예 `"비가 오는데 "`) 와 `req.keep`(공백 없이 같은 말). fix → `start`(고칠 글). translate → `meaning`(영어 한 문장) · `hints`(낱말 3~6개, 한국어 기본형). speak → `timer`(40 기본, 20~90). write → 선택으로 `cues`(질문 칩) · `frame`(초급만) · `source`(합치기용 짧은 문장들) · `bonus`(`req` 에 더할 조건 + 그 조건도 채우는 `model`).

## 꼭 지킬 것 — 검사가 막는 것 (`node tools/check-weave.mjs`)
1. **모범 답(`model.ko`)이 자기 `req` 를 전부 채워야 한다.** 검사가 화면과 **같은 인식기**로 돌려 본다. 인식기가 못 알아보는 꼴이면 실패한다 — 그 과제는 고쳐 쓴다.
2. **fix 의 `start`(고칠 글)는 `req` 를 채우면 안 된다**(이미 맞는 글이면 고칠 거리가 없다).
3. **`bonus.model`은 `req` + `bonus.req` 를 모두 채워야 한다**(bonus 를 쓰는 과제만).
4. continue 의 `start.trim()` = `req.keep` 이고, 모범 답이 그것으로 시작한다. translate 는 `meaning` · `hints` 3개 이상, speak 은 `timer`.
5. `id` 가 겹치지 않는다. 한국어 · 영어 둘 다.

## 인식기가 이음말을 찾는 법 — 모범 답을 쓸 때 꼭 알 것
- 학생(과 모범 답)이 쓴 **낱말 하나하나**를 본다. `-는데`는 「사는데 · 조용한데 · 학생인데」, `-지만`은 「좋아하지만 · 어렵지만」, `-아서/어서`는 「와서 · 먹어서 · 재미있어서」, `-(으)니까`는 「싸니까 · 추우니까」(**「-ㅂ니까?」 의문은 아니다**), `-고`는 「먹고 · 친절하고」, `-(으)면`은 「오면 · 있으면」.
- **이음말로 안 세는 것**: 「-고 싶다 · -고 있다」(보조 — 「일하고 싶어요」의 「일하고」), 「라면 · 냉면 · 화면」 같은 명사. **「-아도 · -(으)려고 · -(으)ㄹ 때 · -기 때문에」 같은 다른 연결은 이번 인식기가 모른다** — 모범 답에 넣어도 되지만 `req` 조건으로 요구하지 않는다.
- **한 문장**: 마디 끝이 「~요 · ~니다」이거나 마침표가 중간에 있으면 「끊김」으로 센다. 모범 답은 **끝에서만** 끝낸다.
- 안 되는 말이 나오면 문장을 바꾼다(예: 불규칙 · 드문 낱말). **검사를 통과해야 올린다.**

## 모드별 쓸 것 (한 묶음 10개) — 서로 다른 소재 · 다른 난이도
공통: **일상 · 학교 · 직장 · 여행 · 음식 · 건강 · 취미 · 도시 · 계획 · 후회 · 비교** 같은 여러 소재. 이미 있는 과제와 소재가 겹치지 않게(지금 있는 것: write 사는 곳 · 좋아하는 것 · 비 오는 날 · 내 하루 · 한국어 공부 · 이번 주말 · 우리 동네 · 내 친구 · 맛집 추천 · 나의 꿈 · 한국 여행 계획 · 합치기 ①② / continue 비가 오는데 · 시간이 없지만 · 배가 고파서 · 한국어가 어렵지만 · 주말에 시간이 있으면 · 저는 서울에 사는데 / fix 이음말이 안 맞아요 · 반대인데 이유로 · 끊긴 문장 ①② · 이음말이 빠졌어요 · -고만 너무 많아요 / translate 서울 · 커피 · 내일 · 친구 · 점심 · 여행 / speak 어제 · 계절 · 가족 · 고향 · 가 보고 싶은 곳 · 학교).

### 1묶음 — write(상황 퀘스트) 10개
- `lv` 분포: 1 × 2 · 2 × 3 · 3 × 3 · 4 × 1 · 5 × 1(쪼개진 문장 합치기: `source` 에 짧은 문장 4개, `req` 에 `minConns`·`words`·`one`).
- 1~2단계는 `frame`(틀)이나 `cues`(질문 칩)를 준다. 3단계부터는 `cues` 만. 상황은 **누구에게 무엇을 말하는지**가 분명하게(친구에게 소개 · 가게에서 부탁 · 면접 자기소개 · 후기 쓰기 …).
- `bonus` 를 **6개 이상**에 단다(한 마디 더 · 다른 이음말 더).
- 같은 이음말만 쓰는 과제 금지 — 과제마다 `req.conn` 의 짝이 다르다.

### 2묶음 — continue(이어 쓰기) 10개
- `start` 는 **이음말로 끝나는 첫 마디**(「…는데 · …지만 · …아서 · …(으)니까 · …(으)면 · …고」). 첫 마디의 이음말이 과제마다 골고루(6가지 × 최소 1).
- `req`: `keep` + `clauses` 4~6 + `minConns`(첫 마디 포함) + `one` + `polite`. 높은 단계는 `distinct`.
- 첫 마디가 **뒤를 상상하게** 해야 한다(「비가 오는데…」 → 우산? 약속? 계획?). 한 가지 답만 나오는 첫 마디는 피한다.

### 3묶음 — fix(고쳐 쓰기) 10개
- 고칠 글의 **잘못 유형**을 섞는다(각 2개 안팎): ① 이음말의 **뜻이 안 맞음**(이유인데 -지만) → `conn` + `no` ② 문장이 **끊김**(짧은 문장 3~4개) → `minConns` + `words` + `one` ③ 이음말이 **빠짐**(「날씨가 추워요 옷을 입어요」) ④ **한 가지 이음말만 반복**(-고 -고 -고) → `distinct` ⑤ 해요체와 다른 끝(`polite`) 정도는 곁들이기.
- **고칠 글이 `req` 를 못 채워야** 하고(검사), 고치면 채울 수 있어야 한다(`model`).
- 고칠 글이 **자연스러운 오류**여야 한다(학생이 실제로 쓰는 실수) — 어색한 인위적 오류 금지.

### 4묶음 — translate(영어 → 한 문장) 10개
- `meaning` = 자연스러운 영어 한 문장(이음말 2~3개가 필요한 뜻). `hints` = 핵심 낱말 기본형 3~6개(꼭 모범 답의 낱말과 같지 않아도 된다).
- `req.words` 는 모범 답의 **핵심 낱말 2~4개**(앞부분)를 요구한다 — 같은 뜻의 다른 낱말로 쓸 수 있는 말은 `words` 에 넣지 않는다(학생이 억울하다).
- 지시(`situation`)에 **쓸 이음말**을 알려 준다(「이음말: -는데 · -아서」). 난이도가 오르면 이음말을 알려 주지 않고 `minConns` 만.

### 5묶음 — speak(즉석 말하기) 10개
- 주제 카드 한 줄(`title`) + 지시. 학생이 **마이크로 40초 말한다**(`timer` 40, 어려운 것은 30). 모범 답은 **40초에 말할 수 있는 길이**(한 문장 4마디, 15~25어절).
- 주제는 **말할 거리가 있는 것**: 어제 · 가장 기억에 남는 여행 · 내 방 · 좋아하는 음식 · 하고 싶은 일 · 우리 학교 · 요즘 고민 · 주말 계획 …
- `req`: `clauses` 3~5 + `minConns` + `one` + `polite`. (시간 조건은 화면이 알아서 더한다.)

## 질 (사람이 보는 것 — 검사가 못 거르는 것)
1. **입에 붙는 말** — 소리 내어 말해 보고 걸리면 고친다. 모범 답은 학생이 실제로 말할 법한 말이어야 한다(논문체 · 번역투 금지).
2. 해요체 한 가지로 통일. 높임 · 시제가 흔들리지 않게.
3. 영어(`en`)는 자연스러운 한 문장.
4. **실제 사건 · 기관 · 사람 이름 금지**(민수 · 지수 같은 흔한 이름은 괜찮다). 기출 아님.
5. 이음말만 많다고 좋은 문장이 아니다 — **뜻이 이어지는** 문장.
