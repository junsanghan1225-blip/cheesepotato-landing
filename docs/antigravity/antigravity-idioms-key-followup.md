# 안티 그래비티 보충 지시서 — 「필수 관용 표현」 운영자가 고른 28개 + 새 표현 1개

> 브랜치 `ag/idioms-key` 를 **이어서** 쓴다(`git fetch origin && git checkout ag/idioms-key && git pull`). 지난번 결과(`docs/idioms/key-expressions.json`)는 잘 받았다. 다만 운영자가 단원마다 직접 고른 표현(`docs/idioms/picks.json`, 63개) 중 **28개가 안티가 고른 150개에 없다.** 아래 28개만 **같은 모양으로** `units` 의 해당 단원 배열에 **더한다**(이미 있는 항목은 건드리지 않는다. 단원당 5개를 넘어도 된다).

## 할 일 2 — 빈출도 1개 더
운영자가 「낯이 설다」를 빼고 **「신경을 쓰다」**(`xi-151`, 단원 `ex-05`, 뜻: 어떤 일에 마음을 쓰다)를 새로 넣었다. `freq` 에 `{"id":"xi-151","head":"신경을 쓰다","freq":…,"why":…,"conf":…}` 한 줄을 더하고, `xi-010`(낯이 설다) 줄은 **지운다**. 이러면 `freq` 는 449개가 된다.

## 끝나면
`JSON.parse` 가 되는지, `freq` 449개, `units` 에 위 28개가 모두 들어갔는지 답글에 적는다. 이 파일만 커밋 · 푸시.
