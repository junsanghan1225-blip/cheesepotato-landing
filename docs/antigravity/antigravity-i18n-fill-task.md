# 안티 그래비티 작업 지시 — 화면 번역 빈칸 채우기 (10개 언어 한 번에)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해.」
> 브랜치: `i18n-fill` (main 에서 새로). 2026-10-17 운영자 「포르투갈어 했는데 번역 안 돼 있어」 — 번역을 끝낸 뒤 새 화면(친구 초대 · 구간 · 미니 테스트 · 자주 묻는 질문 …)이 들어와서, 언어마다 **아직 없는 글 119~181개**가 화면에 영어로 보인다.

## 무엇을
- 먼저 `git pull` 로 main 의 최신 `docs/i18n/strings.json` 과 언어 사전을 받는다.
- `node tools/i18n-missing.mjs` 로 언어마다 빠진 수를 보고, `node tools/i18n-missing.mjs <언어>` 로 **빠진 영어 원문 목록**을 뽑는다.
- 그 글을 옮겨 `docs/i18n/<언어>.json` 에 `{ "영어 원문": "번역" }` 으로 **더한다**(열쇠는 영어 원문 글자 그대로). `ko` 는 strings.json 에서 뜻을 헷갈릴 때 참고만.
- 언어 차례: **pt → id → ne → ru → mn → uz → vi → ja → zh → my**. 한 언어가 끝나면 그 언어만 커밋하고 다음 언어로.
- **이미 있는 줄은 건드리지 않는다.** 빈칸만 채운다.

## 꼭 지킬 것
- **각 언어의 원래 지시서 `docs/antigravity/antigravity-i18n-<언어>-task.md` 의 「꼭 지킬 것」 · 「이 언어에서 더 알아 둘 것」을 그대로 따른다**(말투 · 표기 · 자리 표시 `{0}` · HTML 태그 · 한국어 낱말 그대로 · `CheesePotato` · `Pro` · `TOPIK` 그대로). 같은 낱말은 그 사전에 이미 쓰인 번역과 맞춘다(예: 「Pro」 단추 · 「레슨」을 이미 옮긴 말).
- 「12개 언어」 같은 숫자 · 언어 이름 목록은 원문 그대로의 뜻으로 옮긴다(언어를 더하거나 빼지 않는다).
- 결제 · 환불 · 개인정보 문구는 뜻을 바꾸지 않고 그대로 옮긴다(더 좋게 들리게 고치지 않는다).

## 올리기
- 언어마다: `node tools/check-i18n.mjs` → `node tools/build-i18n.mjs` → 그 언어 빠진 수가 0인지 `node tools/i18n-missing.mjs`
- 커밋: 언어마다 `docs/i18n/<언어>.json` · `i18n-<언어>.js` 두 파일만. 메시지: `화면 번역 빈칸 — <언어> X개`
- 다 하면 `i18n-fill` 브랜치를 푸시한다(PR 은 만들지 않는다 — Claude 가 검토해 넣는다).
