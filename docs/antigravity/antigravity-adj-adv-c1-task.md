## 무엇을
- 책 틀 `docs/books/korean-adj-adv-c1.json` 의 `_plan` 에 단원 17개(id · 다룰 것)가 있다. **견본 단원 `adv-confusing-pairs` 는 이미 `inline` 에 있다 — 모양 · 수준 · 말투를 그대로 따른다.**
- 묶음: 1묶음 = 형용사의 바탕 4단원 · 2묶음 = 형용사 넓히기 4단원 · 3묶음 = 부사의 체계 5단원 · 4묶음 = 실전 나머지 3단원(`adv-agreement` · `adj-adv-register` · `adj-adv-writing`).
- 한 단원 = `inline["<id>"]` 에 학습지 모양 하나(모양은 `docs/worksheets/_schema.md`). `parts` 는 고치지 않는다(Claude 가 검토 뒤 넣는다).

## 단원 모양 (견본과 같이)
- `id` · `title {en,ko}` · `sub {en,ko}` · `level: "C1"` · `sections` · `howto`(영어 한 줄) · `koSummary`.
- `sections`: **표 3~4개 + 「고르는 순서」 같은 짧은 글(text) 1개 + 연습 3개**.
  - 표: `cols` 는 4칸 `["Word · 낱말", "Use · 쓰임", "Example · 예", "English"]`(단원에 맞게 이름은 바꿔도 4칸). 줄 3~6개. `note` 한 줄로 흔한 실수.
  - 연습 A 고르기(「( 가 / 나 )」 꼴, 6~8문제) · B 어색한 곳 고치기(4~6문제) · C 내 문장 쓰기(3~4문제, 정답은 「예) …」).
- 「쓰임」 칸은 **차이가 드러나게** 짧게: 양 · 결과 · 말/글 · 격식 · 누구의 감정인지 · 부정과 같이 쓰는지.

## 지킬 것
1. **C1 수준**: 기초 낱말 나열이 아니라 「언제 무엇을 고르나」. 예문은 신문 · 회사 · 일상 대화에서 실제로 쓰는 자연스러운 문장.
2. **사실**: 뜻 · 활용 · 맞춤법은 표준국어대사전 기준. 확실하지 않은 쓰임은 쓰지 않는다. 「항상 · 절대」 같은 단정은 예외가 없을 때만.
3. **정답이 하나**: 고르기 · 고치기는 다른 답도 자연스러우면 문제를 바꾼다(견본: 「끝내 합격했다」는 가능해서 뺐다). 쓰기 정답은 「예)」.
4. **창작**: 모든 문장은 새로 쓴다. TOPIK 기출 · 다른 교재 문장을 옮기지 않는다.
5. **줄표(—) 금지**(책 글). 이모지 금지. 큰따옴표 대신 「 」.
6. 영어 칸은 자연스러운 뜻 번역(직역 X), 한 줄.
