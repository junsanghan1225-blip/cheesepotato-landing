# Gemini Spark 에 넘길 재료

Spark 는 이 저장소를 못 본다. 그래서 **아래 블록만 복사해 붙이면 되게**
각 프롬프트가 필요한 것을 다 안고 있다.

순서는 이렇다.

1. **§1 을 한 번만** Spark 의 Skill(개인 맞춤 지침)에 등록한다.
2. 필요할 때 **§2~§5 중 하나를 복사해 붙인다.**
3. 돌아온 Docs 를 사람이 보고, 확정본을 나(Claude)에게 주면 저장소 데이터로 넣는다.

**Spark 는 초안까지다.** 시험 문항이 틀리면 학습자가 틀린 것을 배운다.
반드시 사람이 보고 넘긴다.

## 1. Skill 에 한 번만 등록할 것

> Spark 설정 → 개인 맞춤 지침(Skill) 에 붙여 넣는다.

```
[치즈감자 TOPIK 문항 작성 지침]

나는 한국어 학습 사이트(everykoreans.com)의 TOPIK II 쓰기 연습 문항을
만들고 있다. 아래 규칙을 항상 지켜라.

■ 저작권 — 가장 중요
- 실제 TOPIK 기출 지문·문항을 그대로 옮기거나 조금 고쳐 쓰지 마라.
- 유형과 난이도만 같게 하고 소재·인물·상황·수치는 전부 새로 지어내라.
- 기출에서 본 문장이 떠오르면 그 소재를 버리고 다른 소재로 바꿔라.

■ 출력 형식
- 결과는 항상 Google Docs 문서 하나로 만들어라.
- 문서 안에서 문항마다 아래 여섯 칸을 반드시 채워라.
  1) 유형   2) 지문   3) 조건   4) 모범답안
  5) 채점 포인트      6) 흔한 감점 요인
- 각 칸의 제목을 그대로 써라. 칸을 합치거나 이름을 바꾸지 마라.

■ 한국어
- 지문의 문체는 문항 유형이 요구하는 것을 지켜라
  (안내문·설명문은 하십시오체/합니다체, 논술은 -(느)ㄴ다체).
- 학습자용이므로 소재는 정치·종교·성·폭력을 피하고
  일상·학교·직장·환경·기술처럼 누구나 쓸 수 있는 것으로 하라.

■ 하지 말 것
- 점수를 후하게 주지 마라. 예시 답안의 점수는 실제 기준에 맞춰라.
- 내가 요청하지 않은 문항을 덧붙이지 마라.
```

## 2. 51번 (실용문 빈칸) — 복사해 붙일 것

```
치즈감자 TOPIK 문항 작성 지침에 따라 51번 유형 문항 5개를 만들어
Google Docs 로 정리해 줘.

[51번이 어떤 문항인가]
- 안내문·이메일·문자·모집글 같은 실용문이 지문이다.
- 지문 안에 빈칸이 두 곳 있고 (㉠) (㉡) 으로 표시한다.
- 학습자는 각 빈칸에 한 문장씩 쓴다. 빈칸 하나에 5점, 합 10점.
- 앞뒤 문맥으로 무엇을 써야 할지 정해지는 자리여야 한다.
  여러 답이 가능해도 되지만 '아무 말이나' 되면 안 된다.

[반드시 지킬 것]
- 지문 전체의 문체를 통일하고, 빈칸에 들어갈 문장도 그 문체여야 한다.
  (예: 안내문이면 합니다체 — "신청해 주시기 바랍니다")
- 빈칸 두 개 중 하나는 '요청/부탁', 하나는 '정보 제공'이 되게 하면 좋다.
- 지문은 150자 안팎으로 짧게.

[각 문항에 채울 여섯 칸]
1) 유형: 51번 (실용문 빈칸)
2) 지문: (㉠) (㉡) 를 포함한 전체 글
3) 조건: 각 빈칸에 한 문장, 지문의 문체를 지킬 것
4) 모범답안: ㉠ 과 ㉡ 각각에 대해 **허용 가능한 답을 3개씩**
   (뜻이 같고 표현만 다른 것들)
5) 채점 포인트: 각 빈칸에서 무엇을 보는지 한 줄씩
6) 흔한 감점 요인: 학습자가 자주 틀리는 것 2~3개
   (특히 문체가 어긋나는 경우를 꼭 넣을 것)

소재는 5개가 서로 겹치지 않게: 동아리 모집 / 물건 판매 글 /
분실물 안내 / 아르바이트 구인 / 행사 초대 중에서 골라 줘.
```

## 3. 52번 (설명문 빈칸) — 복사해 붙일 것

```
치즈감자 TOPIK 문항 작성 지침에 따라 52번 유형 문항 5개를 만들어
Google Docs 로 정리해 줘.

[52번이 어떤 문항인가]
- 일반적 사실을 설명하는 짧은 글이 지문이다. 실용문이 아니다.
- 빈칸 두 곳 (㉠) (㉡). 각 5점, 합 10점.
- 51번과 달리 **논리 관계**로 답이 정해진다.
  앞 문장과의 관계(대조·인과·예시·부연)를 읽어야 쓸 수 있어야 한다.

[반드시 지킬 것]
- 문체는 -(느)ㄴ다체 (설명문). "~한다", "~이다".
- 빈칸 앞뒤에 '그러나 · 따라서 · 예를 들어' 같은 이음말을 두어
  무슨 관계인지 단서를 남길 것.
- 지문은 150~200자.
- 소재는 상식 수준이어야 한다. 전문 지식이 있어야 풀리면 안 된다.

[각 문항에 채울 여섯 칸]
1) 유형: 52번 (설명문 빈칸)
2) 지문
3) 조건
4) 모범답안: 빈칸마다 허용 답 3개씩
5) 채점 포인트: **이 빈칸이 어떤 논리 관계인지** 반드시 밝힐 것
6) 흔한 감점 요인 (해요체를 쓰는 경우를 꼭 넣을 것)

소재 5개: 수면과 건강 / 재활용 / 습관이 만들어지는 과정 /
색이 주는 느낌 / 걷기의 효과
```

## 4. 53번 (자료 설명) — 복사해 붙일 것

```
치즈감자 TOPIK 문항 작성 지침에 따라 53번 유형 문항 3개를 만들어
Google Docs 로 정리해 줘.

[53번이 어떤 문항인가]
- 도표·그래프 자료를 보고 200~300자로 설명하는 문항. 30점.
- 우리 사이트는 그림을 못 넣으므로 **자료를 글로 적어 준다.**
  예: "조사 기관: 한국문화원 / 대상: 외국인 유학생 500명 /
      2020년 32% → 2025년 61% / 이유 1위: ○○ 2위: ○○"

[반드시 지킬 것]
- 수치는 지어내되 **현실적이어야** 한다. 합이 100%를 넘지 않게.
- 학습자가 반드시 다뤄야 할 항목을 3개로 정해 준다
  (예: 조사 개요 / 변화 추이 / 원인).
- 문체는 -(느)ㄴ다체.

[각 문항에 채울 여섯 칸 + 예시 답안]
1) 유형: 53번 (자료 설명)
2) 지문: 자료를 글로 옮긴 것 + 과제 지시문
3) 조건: 200~300자, 다뤄야 할 항목 3개
4) 모범답안: 250자 안팎 한 편
5) 채점 포인트: 내용 및 과제 수행 7 / 전개 구조 7 / 언어 사용 16
   — 각각에서 무엇을 보는지
6) 흔한 감점 요인

+ 추가로, 문항마다 **예시 답안 3편**을 아래 형식으로 더 써 줘.
  상(27~30점) / 중(17~22점) / 하(7~12점)
  각 편마다: 글 전문 · 세 항목 점수 · 그 점수를 준 이유 두 줄
  ※ 중·하 편은 실제 학습자가 하는 실수를 담아라
    (분량 미달, 자료 수치를 안 씀, 해요체 섞임, 문단 안 나눔)
```

## 5. 54번 (논술) — 복사해 붙일 것

```
치즈감자 TOPIK 문항 작성 지침에 따라 54번 유형 문항 3개를 만들어
Google Docs 로 정리해 줘.

[54번이 어떤 문항인가]
- 주제 하나로 600~700자 논술. 50점. 쓰기 영역에서 배점이 가장 크다.
- 주제문 아래에 **세부 과제 3개**가 붙는다. 이 셋을 다 다뤄야 만점권이다.
  (예: "○○이란 무엇인가 / ○○의 좋은 점은 무엇인가 / 어떻게 해야 하는가")

[반드시 지킬 것]
- 문체는 -(느)ㄴ다체. 절대 해요체가 아니다.
- 찬반이 갈리는 주제는 피하고 **누구나 쓸 거리가 있는** 주제로.
- 세부 과제 3개는 서로 겹치지 않고, 셋을 이으면 글 한 편이 되게.

[각 문항에 채울 여섯 칸 + 예시 답안]
1) 유형: 54번 (논술)
2) 지문: 주제문 + 세부 과제 3개
3) 조건: 600~700자, -(느)ㄴ다체
4) 모범답안: 650자 안팎 한 편
5) 채점 포인트: 내용 및 과제 수행 12 / 전개 구조 12 / 언어 사용 26
6) 흔한 감점 요인

+ 추가로, 문항마다 **예시 답안 3편**을 아래 형식으로 더 써 줘.
  상(43~50점) / 중(28~36점) / 하(12~20점)
  각 편마다: 글 전문 · 세 항목 점수 · 그 점수를 준 이유 두 줄
  ※ 중·하 편에는 실제 학습자의 실수를 담아라
    - 세부 과제 3개 중 하나를 빠뜨림
    - 문단을 안 나누고 한 덩어리로 씀
    - 해요체가 섞임
    - 같은 문법만 되풀이 (언어 사용 점수가 깎이는 가장 큰 이유)

주제 3개: 습관의 힘 / 실패에서 배우는 것 / 함께 일한다는 것
```

## 6. 돌아온 것을 어떻게 넘기나

Docs 를 사람이 검토한 뒤, **그 문서 내용을 그대로** 나에게 주면 된다.
형식을 다시 다듬을 필요 없다 — §1 의 여섯 칸만 지켜져 있으면
`topik.js` 데이터로 옮기고 검사기에 태운다.

넘길 때 같이 알려 줄 것:

- 어느 문항을 **쓰기로 확정**했는지 (초안 전부를 넣지는 않는다)
- 사람이 고친 곳이 있으면 어디를
- 예시 답안의 점수에 동의하는지 (이게 AI 채점의 닻이 된다)

- 치즈감자 비공개 테스트 참여자 수 (내가 알려 준 최신 숫자 기준)

- 이번 주에 내가 하기로 한 일 중 안 끝난 것
