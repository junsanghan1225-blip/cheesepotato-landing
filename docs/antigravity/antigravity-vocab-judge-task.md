# 안티 그래비티 작업 지시 — TOPIK II 단어장 낱말 빈출도 · 난이도 판단

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해.」
> 운영자 2026-10-31 「책 안에서 많이 쓰는 낱말도 난이도 있는 낱말도 보이게 · 안티한테 판단하게」. 낱말 · 뜻 · 예문은 **고치지 않는다.** 숫자 두 개만 적는다.

## 왜
TOPIK II 단어장(워크북 1·2·3, 급수별)의 감자(🥔 빈출도)는 우리 연습 자료에 나온 횟수로 정한다. 그런데 자료에 아직 안 나온 낱말은 감자가 비어 모든 쪽이 비슷해 보인다. 그 낱말들을 **한국어 교사의 눈**으로 판단해 숫자를 준다.

## 이번 묶음 (운영자 2026-10-31 「단어장 전체수정」)
단어장이 급수별 3권(워크북 1 = 3~4급 · 2 = 5급 · 3 = 6급)으로 바뀌어서 세 권의 낱말이 모두 대상이다. 한 번에 다 한다.

## 무엇을
`node tools/vocab-judge-list.mjs` 가 보여 주는 낱말마다 두 가지를 매긴다(약 1,550개).
- `fq` **빈출도 1~5** — TOPIK II 시험 글 · 듣기와 일상 대화에서 얼마나 자주 만나는가. 5 = 거의 매 시험 · 매일 / 4 = 자주 / 3 = 보통 / 2 = 가끔 / 1 = 드묾(한자어 · 전문어 · 문어체).
- `d` **난이도 1~3** — 같은 급(3~6급) 안에서 외우기 · 쓰기 어려운 정도. 1 = 쉬움(뜻이 짐작되고 짧음) / 2 = 보통 / 3 = 어려움(뜻이 안 짐작되고 철자 · 쓰임이 까다로움).

## 하는 법
1. `git pull` → 브랜치 `ag/vocab-judge`.
2. `node tools/vocab-judge-list.mjs` 로 목록을 본다(낱말 | 품사 | 급 | 뜻 | 예문).
3. `docs/vocab-judge/topik2.json` 에 `{ "낱말": { "fq": 4, "d": 2 }, … }` 로 적는다. 키는 낱말 그대로.
4. `node tools/vocab-judge-list.mjs --check` 가 「N/N 매김」으로 끝나면 커밋 · 푸시.

## 지킬 것
- **한 급 안에서도 고루 퍼지게**: 전부 3 · 2 로 몰지 않는다(모든 숫자 1~5, 1~3 이 다 나와야 한다).
- 사실만: 모르면 중간값(fq 3 · d 2)이 아니라 사전 · 예문에서 짐작되는 쪽으로. 근거 없는 통계를 지어내지 않는다(이 숫자는 교사의 판단이고, 공식 통계가 아니다).
- 결과 파일 말고는 건드리지 않는다. 검토는 Claude 가 한다(샘플 50개 눈으로 확인 후 책에 넣음).
