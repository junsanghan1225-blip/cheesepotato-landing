# Argon 검수 지시 — TOPIK II 쓰기 책 2권 (51~52번 · 53~54번, 디지털판 v1.5)

> 아래 「붙여 넣을 말」 전체와 `review-text.md` 두 개를 함께 준다. 이번 일은 **글 검수만** — 파일 · 브랜치를 만들지 않고, 결과는 **채팅 답의 표**로만 돌려준다.

## 붙여 넣을 말
TOPIK II 쓰기 연습 책 2권의 글을 검수해 줘. 한국어 선생님이 영어권 학습자를 위해 만든 책이고, 문항은 전부 창작(기출 아님)이야. 두 파일(51~52번 책 · 53~54번 책)을 읽고 **틀렸거나 헷갈리게 쓴 곳만** 골라 아래 표로 돌려줘. 취향 차이는 빼고, 파일은 고치지 마.

**눈금**
1. 맞춤법 · 띄어쓰기 · 오타 (한국어와 영어 모두)
2. 문체 — 51번은 지문 문체(-ㅂ니다 / -(으)세요)와 모범답안의 문체가 같은가. 52 · 53 · 54번 모범답안은 -(느)ㄴ다체인가, 해요체 · 구어가 섞이지 않았나
3. 51 · 52번 빈칸 — 모범답안이 빈칸 앞뒤와 문법적으로 이어지나, 인정할 다른 답이 빠졌거나 틀린 답이 들어갔나
4. 53번 — 모범답안의 숫자 · 증감 표현(%와 %p 포함)이 자료와 맞나, 글자 수가 200~300자 안인가
5. 54번 — 글자 수가 600~700자 안인가, 세 질문을 모두 다뤘나, 서론 · 본론 · 결론 틀이 맞나
6. 유형 분류 — 문항이 묶인 유형(예: 51번 「모집 · 초대」, 54번 「찬반 · 장단점」)에 맞나. 어긋난 것은 문항 id 와 어느 유형이 맞는지
7. 유형 안내 쪽(글의 틀 · 읽는 법 · 주요 표현 · 조심할 것 · 준비 운동) — 표현의 문법이 맞나, 예시 문장이 자연스러운가, 준비 운동의 정답이 맞고 정답이 둘 이상인데 하나만 적지 않았나
8. 채점 기준 · 예시 풀이 · 상중하 점수 — 점수가 글의 실제 수준과 맞나, 이유가 사실인가
9. 앞부분(시험 소개 · 계획표 · 원고지 · 말→글 표 · 자가 점검표) — 사실을 단정한 곳(문항 수 · 배점 · 시간 · 원고지 규칙)은 **확실하지 않으면 「확인 필요」**. 말→글 표의 짝이 맞나. 계획표의 문제 번호가 책 속 번호와 어긋나지 않나
10. 영어 설명 — 틀렸거나 어색한가
11. 기출 아님 — 실제 TOPIK 기출을 베낀 듯한 문장 · 자료가 있으면 알려 줘(없으면 「없음」)

**꼭 지킬 것**: 확실하지 않으면 「확인 필요」. 지어내지 마. 기관 · 제도 · 점수 규정은 특히.
