# 안티 그래비티 작업 지시 — Kindle 전용 책 2 「Korean Short Stories for Beginners 2」 이야기

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해. 이번 묶음은 **10편 (번호 a~b)** 이야.」
> 브랜치: `ag/kdp-stories2-N` (main 에서 새로). 계획: `docs/plans/kdp-original.md` (시리즈 2권). 운영자 2026-10-28 「2권 지시문 만들어줘」.
> 이 책도 Kindle 에서 **읽기만으로** 끝난다. 사이트 · QR · 종이가 필요한 문제 없음. 1권(`docs/kdp-orig/short-stories.json`)은 **건드리지 않는다.**

## 무엇을
**새 파일** `docs/kdp-orig/short-stories-2.json` 에 이야기를 더한다(전체 40편, 한 묶음 10편: 1~10 · 11~20 · 21~30 · 31~40. 이미 있는 것은 건드리지 않는다). 첫 묶음이면 파일을 만든다:
```json
{ "id": "kdp-short-stories-2", "title": { "en": "Korean Short Stories for Beginners 2" },
  "stories": [
  { "no": 1, "level": "A2",
    "title": { "ko": "…", "en": "…" },
    "lines": [ { "ko": "…", "en": "…" }, … 14~20줄 ],
    "vocab": [ { "ko": "…", "en": "…" }, … 7~10개 ],
    "check": [ { "q": "English question about the story", "a": "answer in English" }, … 3개 ] }
] }
```
- 번호 1~20 은 **A2**(어절 8개 안쪽, 해요체, TOPIK I 2급~II 3급 낱말), 21~40 은 **B1**(어절 10개 안쪽, 해요체 + 가끔 합니다체, 이유 · 대조 · 시간 순서 · 「-(으)ㄴ/는데」 「-(으)니까」 「-기 때문에」 같은 이어 주는 말이 자연스럽게 나온다).
- 한 편은 한국어 **350~450자**, 한 줄(문장) 하나에 영어 한 줄. 줄 14~20개. 하나의 작은 사건(시작 · 일 · 끝, 가능하면 작은 반전이나 깨달음).
- 주제는 1권과 **다르게**(1권: 시장 · 생일 · 비 · 지하철 · 병원 · 이사 · 캠핑 …). 2권은 이사 간 뒤의 일상 · 새 직장 · 동네 가게 · 취미 모임 · 요리 · 여행 계획과 실수 · 오해가 풀리는 이야기 · 이웃 · 반려동물 · 계절 행사 · 온라인 주문 · 은행 · 도서관 · 운동 · 자원봉사 · 작은 용기. 같은 틀만 반복하지 않는다. 1권의 등장인물(민수 · 지수 · 하나)을 다시 써도 되지만 사건은 새로.
- `vocab` 은 그 이야기에 실제로 나온 낱말만, 기본형 + 영어 뜻. `check` 는 **영어 질문 · 영어 답** 3개(읽으면 답이 나오는 것, 답은 한 문장, 같은 시제). 쓰기 · 말하기 시키는 문제는 쓰지 않는다.

## 영어 쓰는 법 (1권을 다듬으며 정한 규칙 — 처음부터 지킨다)
1. 영어 이야기는 **과거 시제로 통일**한다(대사 안은 현재 가능). 한국어 줄이 현재형(해요체)이어도 영어는 과거.
2. 주어(이름 · he / she / they)를 분명히. 한국어 생략 주어를 영어에서 채운다.
3. **직역투 금지**(「heart pounded」 → 「his heart raced」). 한 줄은 영어 한 문장.
4. 영어는 한국어와 **같은 뜻** — 없는 내용을 더하지 않는다. 읽기 문제는 본문에 있는 내용으로만.

## 꼭 지킬 것
1. **전부 창작.** 실제 기관 · 인물 · 사건 · 법 · 제도 · 가격 · 전화번호 · 상호를 쓰지 않는다. 이름은 흔한 이름. 기출 아님. 우리 사이트의 동화 · 회화 · 학습지, 그리고 1권의 문장을 옮기지 않는다.
2. 한국어는 자연스러운 해요체, 띄어쓰기 · 맞춤법.
3. 낱말 수준을 지킨다(어려운 낱말이 꼭 필요하면 `vocab` 에 넣는다).
4. 이야기 안에 「쓰세요 · 말해 보세요 · QR · 웹사이트 · 인쇄」 같은 문장을 넣지 않는다.
5. 노래 가사 · 방송 · 유명인 · 상표를 쓰지 않는다.
