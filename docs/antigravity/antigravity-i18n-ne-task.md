# 안티 그래비티 작업 지시 — 화면 글자 네팔어 번역 (500개 한 묶음 × 6)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해. 이번은 **N묶음**이야.」
> 브랜치: `i18n-ne` (main 에서 새로). 운영자 결정 2026-10-12 — 화면 언어 늘리기(인도네시아어 → 네팔어 → 미얀마어).

## 무엇을
`docs/i18n/strings.json` — 사이트 화면 글자 약 2,570개(`{ en, ko, n }`, 많이 쓰는 차례). **`en` 을 네팔어로** 옮겨
`docs/i18n/ne.json` 에 `{ "영어 원문": "Nepali translation" }` 로 더한다(열쇠는 영어 원문 **글자 그대로**). `ko` 는 뜻을 헷갈릴 때 참고만.
- **한 묶음 = `docs/i18n/ne.json` 에 아직 없는 글 중, strings.json 차례대로 앞에서 500개**(화면 글이 늘거나 줄어 번호가 바뀌므로 번호 대신 「아직 없는 것」으로 센다). 마지막 묶음은 남은 것 전부.
- 먼저 `git pull` 로 main 의 최신 strings.json · ne.json 을 받은 뒤 시작한다.
- 이전 묶음 줄은 건드리지 않는다. 한 묶음씩 올린다.

## 꼭 지킬 것
1. **`{0}` `{1}` 자리 표시는 그대로**(숫자 · 이름이 들어가는 자리). 순서는 네팔어에 맞게 바꿔도 된다: 자리 표시의 위치는 그 말의 어순에 맞게 옮긴다.
2. **HTML 태그 그대로**(`<br>` `<b>…</b>` `<em>` `<small>`) — 태그 수와 종류가 같아야 한다.
3. **한국어 학습 내용은 옮기지 않는다** — 영어 원문 안의 한국어 낱말 · 문법(`-아요`, `「가다」`, `TOPIK`, `L3`)은 그대로 둔다.
4. 사이트 이름 `CheesePotato` · `Cheesepotato` · `Every Koreans` · `Pro` · `TOPIK` · `AI` 는 **그대로 둔다**(영어 글자 그대로).
5. 말투: 친근하지만 예의 바르게 — **「तपाईं」 높임말**. 단추는 1~3낱말. 숫자는 **아라비아 숫자(0-9) 그대로** 둔다(네팔 숫자로 바꾸지 않는다 — 값 자리와 어긋난다). 데바나가리(देवनागरी) 글자로 쓴다.
6. 이모지 · 화살표(→ ✓ ·)는 그대로.

## 이 언어에서 더 알아 둘 것
네팔어는 한국에 일하러 오는 사람(EPS)과 학생이 쓴다. 번역이 확실하지 않은 전문 용어는 영어 낱말을 그대로 두고 괄호로 뜻을 붙이지 말고 쉬운 네팔어로 풀어 쓴다.
