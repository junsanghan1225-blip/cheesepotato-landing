## 꼭 지킬 것 (지난 묶음에서 고친 실수 — 같은 것이 또 나오면 되돌려 보낸다)
- **「읽기」 칸(Spoken reading · Reading tip)에는 진짜로 소리가 바뀌는 말만** 쓴다(연음 · 비음화 · 경음화: 반갑습니다 → 반갑씀니다, 걸어서 → 거러서, 할게요 → 할께요). 어미 「요」를 「여」로 쓴 읽기(주세여 · 가여)나 소리가 안 바뀌는 말을 적지 않는다. 없으면 「—」.
- 영어 소리 비교(모음 등)는 정확한 것만. 모르면 쓰지 않는다.
- 높임말 칸에는 어떤 맥락에 쓰는지(자기 · 남 · 윗사람)를 한 줄로.
- 문제 속 빈칸은 「___」 하나, 정답은 하나. 빈칸 뒤 조사(는 · 도)는 띄어 쓰지 않는다(「___는」).

## 지킬 것
- 한 편은 표(또는 설명) 2~4칸 + 연습 3~4묶음(묶음당 4~8문제) + 정답. 연습 문장은 전부 창작, 실제 TOPIK/EPS 기출 문항 금지.
- 영어가 주(검색 노출 · 전 세계 학습자), 한국어는 제목 · 요약에 곁들인다. 쉬운 말.
- 사실은 확실한 것만: 수 · 요일 · 날짜 · 활용 · 발음. 모르는 것은 빼고 `note` 에 적지 않는다. 한 칸의 한국어는 짧게.
- 한 줄에 하나의 정답만 나오는 문제로(정답이 여럿이면 `a` 에 「A / B」로 둘 다). 문제 글(`q`)에 정답이 보이면 안 된다.
- id 는 `영문-소문자-하이픈`(예 `family-terms`). 파일 이름 = `<id>.json`.
- 올리기 전에 `node tools/build-sheets.mjs --check` 가 통과해야 한다(모양 검사).
