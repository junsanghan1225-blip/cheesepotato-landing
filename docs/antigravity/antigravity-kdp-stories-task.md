# 안티 그래비티 작업 지시 — Kindle 전용 책 1 「Korean Short Stories for Beginners」 이야기

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해. 이번 묶음은 **N편 (번호 a~b)** 이야.」
> 브랜치: `ag/kdp-stories-N` (main 에서 새로). 계획: `docs/plans/kdp-original.md`. 운영자 2026-10-28 「KDP 는 우리 내용 안 따라가도 되고 · 개별 책으로」.
> 이 책은 Amazon Kindle 에서 **읽기만으로** 끝나는 책이다. 사이트 · QR · 종이가 필요한 문제를 쓰지 않는다.

## 무엇을
`docs/kdp-orig/short-stories.json` 에 이야기를 더한다(전체 40편, 한 묶음 10편: 1~10 · 11~20 · 21~30 · 31~40. 이미 있는 것은 건드리지 않는다). 모양:
```json
{ "stories": [
  { "no": 1, "level": "A1",
    "title": { "ko": "…", "en": "…" },
    "lines": [ { "ko": "…", "en": "…" }, … 8~14줄 ],
    "vocab": [ { "ko": "…", "en": "…" }, … 6~8개 ],
    "check": [ { "q": "English question about the story", "a": "answer in English" }, … 3개 ] }
] }
```
- 번호 1~15 는 A1(한 문장 어절 5개 안쪽, 해요체, TOPIK I 1~2급 낱말), 16~40 은 A2(어절 8개 안쪽, 해요체, 이유 · 대조 · 시간 순서가 들어간 이야기).
- 이야기 한 편은 한국어로 약 250자 안팎, 한 줄(문장) 하나에 영어 번역 한 줄. 하나의 작은 사건(시작 · 일 · 끝)이 있다.
- 주제는 골고루: 집 · 학교 · 직장 · 시장 · 음식 · 날씨 · 여행 · 교통 · 가족 · 친구 · 취미 · 병원 · 계획 · 실수 · 선물. 같은 틀(「아침에 일어났어요 → 먹었어요」)만 반복하지 않는다.
- `vocab` 은 그 이야기에 실제로 나온 낱말만, 기본형 + 영어 뜻. `check` 는 **영어 질문 · 영어 답** 3개(이야기를 읽으면 답이 나오는 것, 정답은 한 문장). 쓰기 · 말하기 시키는 문제는 쓰지 않는다.

## 꼭 지킬 것
1. **전부 창작.** 실제 기관 · 인물 · 사건 · 법 · 제도 · 가격 · 전화번호를 쓰지 않는다. 이름은 민수 · 지수 · 하나 같은 흔한 이름. 기출 아님. 우리 사이트의 동화 · 회화 · 학습지 문장을 옮기지 않는다(`docs/` 의 기존 자료와 겹치면 안 됨).
2. 한국어는 자연스러운 해요체, 띄어쓰기 · 맞춤법. 영어는 자연스러운 한 문장(don't · it's 따옴표 빠뜨리지 않기).
3. 영어 번역은 한국어와 **같은 뜻** — 없는 내용을 더하지 않는다. 한 줄은 한 문장.
4. 낱말 수준을 지킨다(A1 에 어려운 낱말 · 문법 금지). 어려운 낱말이 꼭 필요하면 `vocab` 에 넣는다.
5. 이야기 안에 「쓰세요 · 말해 보세요 · QR · 웹사이트 · 인쇄」 같은 문장을 넣지 않는다.

## 올리기
- JSON 문법이 맞는지 `node -e "JSON.parse(require('fs').readFileSync('docs/kdp-orig/short-stories.json','utf8'))"` 로 확인.
- 커밋 메시지: `KDP 이야기 N묶음 — a~b번`. 푸시까지 해야 끝(PR 은 만들지 않는다). Claude 가 검토해 넣는다.
