# 안티 그래비티 작업 지시 — 문장 늘리기 「틀린 조각」 쓰기 (더 어렵게)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해. 이번 묶음은 **<코스 id 앞부분>** 이야.」
> 운영자 2026-10-21 「문장 늘리기가 너무 단순하다」. 레슨의 「문장 늘리기」는 조각 3개를 순서대로 놓는 문제라 짐작으로 풀린다 — **틀린 조각 1~2개를 섞어** 어렵게 한다. 원본 레슨 글은 **고치지 않는다.**

## 무엇을
레슨마다 있는 문장 늘리기(`expand`) 단계마다, 정답 조각 사이에 섞을 **틀린 조각**(decoys)을 쓴다.
- 지금 상태: `node tools/expand-list.mjs --todo <코스 id 앞부분>` — 레슨 id · 단계 · 정답 조각 · 영어 뜻이 나온다(전체 361개 · 725단계).
- 결과 파일: **`docs/expand-decoys.json`** (한 파일, 묶음마다 이어서 더한다). 브랜치 `ag/expand-decoys-N`.

## 결과 모양
```json
{ "im-02-02-01": [ ["쓰는 바람에"], ["쓰고 나서", "마감 보고서가"] ] }
```
- 키 = 레슨 id(`expand-list` 첫 줄 그대로). 값 = **단계별 배열**(1단계, 2단계 … 순서). 틀린 조각이 필요 없는 단계는 `[]`.
- 한 단계에 **1~2개**(문자열). 정답 조각과 **똑같은 글자는 안 된다**(도구가 막는다).

## 틀린 조각의 눈금 (꼭 지킬 것)
1. **그럴듯하지만 그 자리엔 틀려야 한다** — 영어 뜻과 맞지 않거나, 이 레슨 문법을 틀리게 쓴 조각. 예: 레슨이 「-느라고」면 `쓰는 바람에`(뜻이 다름) · `쓰느라고요`(말투가 어긋남).
2. **무엇이 틀렸는지 한 줄로 말할 수 있어야 한다** — 설명이 안 되는 조각은 쓰지 않는다. 쓰기 어려우면 그 단계는 `[]`.
3. **정답 조각을 대신해 들어가도 문장이 말이 되면 안 된다.** 다른 위치에 넣어서 맞는 문장이 되는 조각(어순만 다른 것)은 **쓰지 않는다**(한국어는 어순이 자유로워 억울한 오답이 생긴다).
4. 모양은 정답 조각과 비슷하게(길이 · 어미), 그러나 **같은 뜻의 다른 표현은 금지**(예: `한숨도 못 잤어요` 가 정답인데 `거의 못 잤어요` 는 정답으로도 읽힌다).
5. 실제 TOPIK · EPS 기출 문장을 쓰지 않는다. 지어내지 않는다(없는 한국어 표현 금지 — 확실하지 않으면 그 단계는 `[]`).
6. 한 레슨 안에서 같은 틀린 조각을 반복하지 않는다.

## 하는 법
1. `git pull` 로 main 을 받고 브랜치를 만든다.
2. `node tools/expand-list.mjs --todo <코스 id 앞부분>` 으로 한 묶음(레슨 30개쯤)을 본다.
3. `docs/expand-decoys.json` 에 키를 더한다(이미 있는 키는 건드리지 않는다).
4. `node tools/build-lesson-blocks.mjs` 가 에러 없이 끝나면(틀린 조각이 정답과 같거나 3개 이상이면 에러) 커밋한다.
5. 의심스러운 단계는 `docs/antigravity/expand-decoys-notes.md` 에 레슨 id 와 한 줄로만 적는다(고치지 않는다).

## 올리기
- 커밋 메시지: `문장 늘리기 틀린 조각 — <코스 id 앞부분> N단계`. 브랜치를 푸시한다(PR 은 만들지 않는다 — Claude 가 검토해 넣는다).
- 끝나면 한 줄로 알린다: 「<브랜치> · N레슨 M단계 · 건너뜀(`[]`) K · <커밋 앞 7자리> 올림」.
