# 안티 그래비티 작업 지시 — 쓰기 칸 지시문에서 정답 활용형 빼기 (기본형으로 바꾸기)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해. 이번 묶음은 **<코스 id 앞부분>** 이야.」
> 운영자 2026-10-21 「쓰기 칸 지시문을 기본형으로 바꾼다」. 레슨마다 쓰기 칸(`write`)이 하나 있다(390개). 지금은 지시문에 **활용이 끝난 정답 조각**이 그대로 적혀 있어 베껴 쓰게 된다 — 이것을 **기본형(사전형) + 만들 문법 이름**으로 바꾼다. 원본 레슨 글은 **고치지 않는다.**

## 무엇을
- 지금 상태: `node tools/write-list.mjs --todo <코스 id 앞부분>` — 레슨 id · 지금 지시문(`q`) · 꼭 들어갈 조각(`must`) · 예시 답(`sample`) · 이 레슨 낱말.
- 결과 파일: **`docs/write-prompts.json`** 한 파일(묶음마다 이어서 더한다). 브랜치 `ag/write-hints-N`.

```json
{ "bg-14-01": "Write one sentence saying you rested at home because you were tired. Use 피곤하다 + -아/어서 and 쉬다 (past tense).",
  "bg-11-01": "Say what you are doing at the library right now. Use 공부하다 + -고 있어요." }
```
- 키 = 레슨 id. 값 = **새 지시문 한 덩어리**(영어, 지금 지시문과 같은 말투 · 길이).

## 새 지시문의 규칙 (꼭 지킬 것)
1. **상황 + 기본형 + 만들 문법 이름**으로 쓴다. 예: `Use 가다 + -(으)세요.` · `Use 듣다 (ㄷ irregular) in the polite present.`
2. **활용이 끝난 정답 조각을 쓰지 않는다** — `must` 의 조각(`피곤해서` · `쉬었어요` …)과 `sample` 문장이 지시문에 글자 그대로 들어 있으면 안 된다(도구가 `sample` 이 통째로 들어 있으면 막는다). 문법 이름 속 어미(`-아/어서` · `-고 있어요`)는 괜찮다.
3. **`must` 는 그대로다** — 학습자가 새 지시문대로 쓰면 `must` 조각이 **자연스럽게 나오게** 써야 한다. 예: `must` 가 `피곤해서` 면 지시문이 `피곤하다 + -아/어서` 를 요구해야 한다. 다른 어미로 써도 맞는 지시문이면 안 된다.
4. `must` 가 `는` · `지만` 처럼 짧은 조각이면 그 조각이 필요한 **문법 이름**(`은/는 contrast` · `-지만`)을 적는다.
5. 지시문만 쓴다 — 단원 안내(`why`) · 예시 답 · 다른 칸은 건드리지 않는다. 의심스러운 레슨은 `docs/antigravity/write-prompts-notes.md` 에 레슨 id 와 한 줄로만 적는다.
6. 이 레슨에서 아직 안 배운 문법 · 낱말을 요구하지 않는다(그 코스 레슨 순서 안에서).

## 하는 법
1. `git pull` 로 main 을 받고 브랜치를 만든다.
2. `node tools/write-list.mjs --todo <코스 id 앞부분>` 으로 한 묶음(코스 3~4개, 레슨 30개쯤)을 본다.
3. `docs/write-prompts.json` 에 키를 더한다(있는 키는 건드리지 않는다).
4. `node tools/build-lesson-blocks.mjs` 가 에러 없이 끝나면 커밋한다.

## 올리기
- 커밋 메시지: `쓰기 지시문 — <코스 id 앞부분> N레슨`. 브랜치를 푸시한다(PR 은 만들지 않는다 — Claude 가 검토해 넣는다).
- 끝나면 한 줄로 알린다: 「<브랜치> · N레슨 · 건너뜀 K · <커밋 앞 7자리> 올림」.
