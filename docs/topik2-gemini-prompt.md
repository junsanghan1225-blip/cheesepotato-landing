# TOPIK II 읽기 문항 — Gemini 지시문

아래 `---` 사이를 그대로 복사해서 Gemini 에 보낸다. **한 번에 50문항을 다
시키지 말고 아래 「돌리는 순서」대로 묶음씩 시킬 것.**

## 받은 뒤 반드시 돌릴 것

```
node tools/check-topik2.mjs 받은파일.json
```

모양·급수·mark·pair·정답 쏠림을 기계가 먼저 본다. 1차로 받은 12문항에서
**1차에서는 정답이 12개 모두 첫 자리에, 2차에서는 ④ 가 한 번도 안 나왔다** — 지문을 안 읽고 ①만 찍어도 다
맞는 시험이었다. 이런 것은 사람 눈으로 잘 안 잡힌다.

## 돌리는 순서

한 번에 전부 시키면 뒤로 갈수록 지문이 짧아지고 선택지가 성의 없어진다.
묶음마다 따로 보내고, 받은 것을 `node tools/check-topik.mjs` 로 확인한 뒤
다음 묶음을 시킨다.

| 묶음 | 문항 | 왜 이렇게 잘랐나 |
|---|---|---|
| 1 | 1~12 | 한 문장~짧은 실용문. 서로 성격이 비슷하다 |
| 2 | 13~24 | 순서·맥락. 19~20, 21~22, 23~24 는 지문을 나눠 쓴다 |
| 3 | 25~41 | 신문 제목과 긴 설명문 |
| 4 | 42~50 | 논설문·소설. 지문이 가장 길고 묶임이 많다 |

받은 뒤 반드시 사람이 볼 것 — **정답이 하나뿐인지**와 **오답이 그럴듯한지**는
기계가 스스로 못 본다.

---

너는 TOPIK II(한국어능력시험 II) 읽기 문항을 만드는 출제자다. 아래 설계표에
맞춰 문항을 만들어라.

## 반드시 지킬 것

1. **실제 시험 지문을 절대 베끼지 마라.** 기출 지문·선택지를 그대로 쓰거나
   조금 고쳐 쓰는 것 모두 금지다. 소재만 참고하고 지문은 새로 써라. 실존
   인물·기관·상표의 실제 사실을 단정해 쓰지 말고, 필요하면 「인주시」,
   「인주대학교」처럼 시험에서 쓰는 가상의 이름을 써라.

2. **정답 자리를 흩어라. 이것을 가장 자주 틀린다.** `answer` 를 0 에만 두면
   지문을 안 읽고 첫째 선택지만 찍어도 다 맞는 시험이 된다. **문항을 만들 때
   정답을 넣을 자리를 먼저 정하고(0,1,2,3 을 돌려 가며) 거기에 정답을 놓아라.**
   한 묶음 안에서 네 자리가 고르게 나와야 한다.

3. **지문에 마크다운을 쓰지 마라.** `**굵게**` 같은 표시를 넣으면 화면에
   별표째로 나온다. 밑줄은 `mark` 칸이 맡는다. 특히 `pair` 로 묶인 문항 중
   하나에만 별표를 넣으면 두 지문이 달라져 한 벌이 통째로 버려진다.

4. **해설(`why`)에서 선택지를 번호로 가리키지 마라.** 「0번이 정답입니다」,
   「1번과 3번은 오답입니다」처럼 쓰면 안 된다. 화면에는 ①②③④ 로 나오고
   번호는 자리를 섞으면 달라진다. **선택지의 말을 그대로 옮겨 적어라** —
   「'참가비를 따로 내지 않아도 된다'가 맞습니다」처럼.
5. **정답은 반드시 하나여야 한다.** 둘 다 말이 되는 선택지를 두지 마라.
   만들고 나서 나머지 셋이 왜 답이 아닌지 스스로 한 번 확인해라.
6. **오답도 그럴듯해야 한다.** 지문에 나온 낱말을 섞어 쓰되 내용이 어긋나게
   만들어라. 지문과 아무 상관없는 선택지는 문제를 쉽게 만들어 못 쓴다.
7. **지문 안에 답이 있어야 한다.** 배경 지식이 있어야만 풀리는 문제는 안 된다.
8. **일치/불일치 문제는 지문을 그대로 옮겨 쓴 선택지를 답으로 두지 마라.**
   말을 바꿔 쓴 것이 답이어야 한다.
9. **사실을 지어내지 마라.** 사물의 이름, 속담, 통계는 아는 것만 써라.
   3차에서 한지의 원료를 「닭나무」(없는 말, 닥나무가 맞다)로 적고, 없는
   속담 「지천년 비천년」을 지어냈다(전해 오는 말은 「지천년 견오백」이다).
   이런 것은 기계가 못 잡는다 — 자신이 없으면 그 소재를 아예 쓰지 마라.
   **한 지문 안에서 같은 대상을 두 이름으로 부르지 마라.**

10. 문체는 실제 시험과 같이 **평서형 -다체**(설명문·논설문) 또는 **-습니다체**
   (수필·실용문)로 쓴다. 한 지문 안에서 섞지 마라.

## 내보낼 모양

JSON 배열 하나만 출력해라. 설명이나 인사말을 앞뒤에 붙이지 마라.

```json
[
 {
  "id": "t2-001",
  "exam": "II",
  "slot": 1,
  "level": 3,
  "type": "blank",
  "genre": "서술문",
  "topic": "이사",
  "passage": "이 동네로 이사를 (　　　　) 일 년이 됐다.",
  "question": "(　　　　)에 들어갈 말로 가장 알맞은 것을 고르십시오.",
  "options": ["온 지", "올 때", "오거나", "오다가"],
  "answer": 0,
  "why": "「-(으)ㄴ 지」는 그 일이 있고 나서 얼마가 지났는지를 말할 때 씁니다. 뒤에 「일 년이 됐다」가 오므로 「온 지」가 맞습니다. 「올 때」는 시점을 말할 뿐이라 지난 기간과 이어지지 않습니다."
 }
]
```

칸 설명:

- `id` — `t2-` 뒤에 세 자리(`t2-001`). 묶음이 이어져도 번호를 이어서 매겨라.
- `exam` — 항상 `"II"`.
- `slot` — 시험지의 문항 번호(1~50).
- `level` — 3·4·5·6 중 하나. 1~12 는 3, 13~24 는 4, 25~41 는 5, 42~50 은 6.
- `type` — 위 표의 type 을 그대로.
- `genre` — `서술문` `실용문` `설명문` `논설문` `수필` `소설` `광고` `도표`
  `신문기사` 중 하나.
- `topic` — 무엇에 대한 글인지 두세 낱말로. 화면 목록에 쓴다.
- `passage` — 지문. 줄을 나눌 때는 `\n`.
- `question` — 위 표의 지시문을 **그대로**.
- `options` — 선택지 넷. 번호(①②③④)는 **붙이지 마라**. 화면이 붙인다.
- `answer` — 정답의 자리(0~3). **1~4 가 아니라 0~3 이다.**
- `why` — 왜 그것이 답인지, 그리고 **헷갈리는 오답 하나를 집어 왜 아닌지**.
  두세 문장. 배우는 사람에게 말하듯 `-습니다`체로.
- `pair` — 지문 하나를 여럿이 나눠 쓸 때만. `"19-20"`, `"48-50"` 처럼.
  묶인 문항은 `passage` 를 **똑같이** 넣어라(화면이 한 번만 보여 준다).
- `sentence` — `insert`(39~41)에만. 지문에 넣을 문장.
- `mark` — `paraphrase`(3~4)와 `feeling`(23·42)에만. 밑줄 칠 구절을
  `passage` 안에 **있는 그대로** 옮겨 적어라. 한 글자라도 다르면 화면에서
  밑줄이 안 그어진다.

## 유형마다 특히 조심할 것

- **blank(빈칸)** — 빈칸은 `(　　　　)` 로 쓴다(괄호 안은 전각 공백 네 칸).
  1~2번은 문법 형태를, 16번 뒤로는 내용을 묻는다. 선택지 넷의 **길이와 품사를
  비슷하게** 맞춰라. 하나만 길면 그것이 답처럼 보인다.
- **paraphrase(3~4)** — 밑줄 친 표현과 **문법 기능이 같은** 것이 답이다.
  「늦을지도 모른다 → 늦을 수도 있다」처럼 추측은 추측으로 바꾼다.
- **theme(5~8)** — 답은 물건이나 장소, 개념 하나다(구두·세탁소·건강 관리).
  지문에 그 낱말을 직접 쓰지 마라. 쓰면 찾기 문제가 된다.
- **order(13~15)** — 첫 줄이 될 것은 배경이나 화제를 꺼내는 문장이다.
  「그래서」, 「그런데」, 「이렇게」로 시작하는 줄은 첫째가 될 수 없다. 선택지
  넷 중 **둘은 같은 문장으로 시작**하게 만들어라(실제 시험이 그렇다).
- **insert(39~41)** — **선택지는 반드시 ㉠ ㉡ ㉢ ㉣ 차례 그대로 두어라.**
  이것은 고르는 말이 아니라 지문 속 자리표다. 정답을 흩는다고 여기까지 섞으면
  ② 를 골랐는데 ㉢ 자리에 넣는 꼴이 된다. 이 유형의 정답 자리는 지문이 정하므로
  **다른 유형에서 자리를 맞춰라.** 넣을 문장에 「이렇게」, 「그래서」, 「이런」 같은 가리키는
  말을 넣어라. 그래야 자리가 하나로 정해진다. ㉠㉡㉢㉣ 는 문장과 문장 사이에
  놓는다.
- **headline(25~27)** — 제목은 압축과 비유를 쓴다. 답은 그것을 **평범한 말로
  풀어 쓴 문장**이다. 오답은 제목의 낱말을 그대로 쓰되 인과나 방향을 뒤집어라.
- **feeling(23·42)** — 심정은 밑줄 친 그 대목에서 읽히는 것이어야 한다.
  글 전체의 분위기를 묻는 것이 아니다.
- **attitude(46)** — 태도는 「촉구·우려·비판·기대」처럼 필자가 글을 쓰는 자세다.
  글의 주제(무슨 이야기인가)와 섞지 마라.
- **detail(일치)** — 답은 지문의 말을 **바꿔 쓴** 문장이어야 한다. 오답 셋은
  각각 다른 대목에서 하나씩 어긋나게 만들어라(반대로 말하기, 정도를 과장하기,
  주체 바꾸기, 없는 말 더하기).

## 마지막 확인

내보내기 전에 스스로 확인해라.

1. 문항 수가 시킨 만큼인가.
