# 강의 영상 올리기 — 운영자용 (2026-10-03)

영상은 **유튜브에 「일부 공개」**로 두고, 사이트 **배우기 → 🎬 강의 영상**(`#learn/lectures`)에 링크만 건다.
파일이 사이트 서버에 없으니 용량 · 전송량 걱정이 없다. 표: `db/add_lectures.sql`(처음 한 번 SQL Editor 에서 돌린다).

## 한 편 올리기

1. **유튜브 스튜디오** → 만들기 → 동영상 업로드 → 파일 고르기.
2. 공개 범위에서 **「일부 공개」**(링크가 있는 사람만) → 저장. 위에 나오는 **영상 링크를 복사**.
3. 사이트에 운영자 계정으로 로그인 → **배우기 → 🎬 강의 영상** → 맨 위 **「＋ 강의 올리기」**.
4. 유튜브 링크 붙여 넣기 · 제목(예: 1강 — 한글 모음) · (선택) 영어 제목 · 수준 · 순서 · 설명 → **「강의 올리기」**.
5. 목록 맨 앞에 바로 뜬다. 순서는 「순서」 숫자가 작을수록 앞.

## 고치기 · 숨기기

강의를 열면 아래에 **고치기 · 숨기기 · 지우기**(운영자에게만 보인다). 숨기면 학생에게 안 보이고, 지워도 유튜브 영상은 그대로 남는다.
