# TOPIK I 읽기 문항(reading-i) 검토 메모

## 문항 구조 및 기출 유사 검토
- 전체 400문항(1급 136문항, 2급 264문항)의 필수 속성(지문, 질문, 보기 4개, 정답 인덱스, 해설) 정합성 확인 완료.
- 49~70번 세트 지문(2문항 1지문: `49-50`, `51-52`, `53-54`, `55-56`, `59-60`, `61-62`, `63-64`, `65-66`, `67-68`, `69-70`)은 지문을 공유하되 개별 문항의 질문 유형(빈칸 추론, 내용 일치, 중심 생각, 문장 삽입 등)에 맞추어 개별 난이도 산정.
- 특이 결함이나 기출 복제 의심 문항 없음(전 문항 고유 창작 지문 및 보기 확인).
