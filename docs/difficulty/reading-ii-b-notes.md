# TOPIK II 읽기 문항 (reading-ii-b) 검토 메모

## 문항 구조 및 기출 유사 검토
- 전체 300문항 (4급 91문항: slot 20~24 / 5급 117문항: slot 25~41 / 6급 92문항: slot 42~50) 정합성 확인 완료.
- 각 슬롯(유형)별 문항 특성(지문 길이, 어휘 수준, 오답 유사도, 추론 단계)을 반영하여 상대 난이도 1(쉬움 78개, 26.0%) / 2(보통 144개, 48.0%) / 3(어려움 78개, 26.0%) 산정 완료.
- 특이 결함이나 기출 복제 의심 문항 없음(전 문항 고유 창작 지문 및 보기 확인).
