# 녹음소 — 사이트의 소리를 내 목소리로

주소: **https://everykoreans.com/record.html** (검색에 안 나오는 운영자 도구)

사이트에서 소리가 나는 자리를 한곳에 모았다. 갈래마다 「소리 없음(로봇 목소리로 나옴)」과
「기계 목소리」를 세어 보여 주고, 급한 것부터 녹음한다.

| 갈래 | 무엇 | 지금 |
|---|---|---|
| EPS-TOPIK 듣기 | EPS 듣기 대본 50문항 | 전부 로봇 |
| TOPIK 듣기 | TOPIK 듣기 대본 45문항 | 전부 로봇 |
| 코스 소리 · 글자 카드 | 레슨에서 누르면 나는 소리 | 375개 로봇 · 209개 기계 |
| TOPIK 쓰기 지문 | 51·52번 지문 | 32개 로봇 · 26개 기계 |
| 사전 낱말 · 예문 | 가나다 순, 낱말 → 그 예문 | 「나태」까지 내 목소리 · 새 낱말은 로봇 |
| 예문 만들기 · 읽기 지문 | | 대부분 기계 |

숫자는 `node tools/record-list.mjs` 를 돌릴 때마다 새로 센다.

## 녹음하는 법

1. PC 크롬(또는 엣지)으로 녹음소를 연다 → **🎙️ 마이크 켜기** → 허용.
2. 위 갈래를 고른다. 글자가 크게 뜬다.
3. **Space** 를 누르고 읽고, **Space** 로 멈춘다. 저절로 다음으로 넘어간다.
   - 앞뒤 빈 소리는 저절로 잘리고, 크기도 고르게 맞춰진다. Space 누르는 「딸깍」도 잘린다.
   - 틀렸으면 **←** 로 돌아가 다시 Space. 새 녹음이 덮어쓴다.
   - **P** 로 방금 것을 들어 본다. 「멈추면 들려주기」를 켜면 매번 들려준다.
   - 「🤖 지금 소리」는 사이트에서 지금 나오는 기계 목소리 — 비교용.
4. 듣기(EPS · TOPIK)는 **줄마다** 녹음한다. 「남」「여」「안내」가 적혀 있다.
   내보낼 때 0.5초씩 띄워 한 파일로 이어 붙인다.
   **「여」 줄은 여자 목소리로** — 문제가 「여자는 무엇을 합니까」를 묻는 경우가 있다.
   부탁할 사람이 있으면 같은 브라우저에서 「여」 줄만 녹음하면 된다.
5. 녹음은 **이 브라우저에 저장**된다. 창을 닫아도 남는다. 다른 컴퓨터 · 다른 브라우저에서는 안 보인다.

## 올리는 법

한 번에 끝까지 할 필요 없다. 몇십~몇백 개 할 때마다:

1. 오른쪽 위 **📦 ZIP 내보내기** → `cheesepotato-녹음-….zip` 이 내려받아진다.
   (이미 내보낸 것은 다음 ZIP 에 안 들어간다. 다시 녹음한 것은 다시 들어간다.)
2. 둘 중 하나:
   - **쉬운 길** — ZIP 을 구글 드라이브에 올리고 Claude 에게 「녹음 올렸어」라고 말한다.
     Claude 가 받아서 확인하고 사이트에 넣는다.
   - **직접** — 저장소 폴더 맨 위에서 ZIP 을 풀고(`assets/audio/…` 가 제자리에 들어간다)
     ```bash
     node tools/record-list.mjs     # 녹음소 목록을 새로 센다
     node tools/stamp.mjs
     git add assets/audio record && git commit -m "녹음 추가" && git push
     ```

ZIP 안의 `assets/audio/recorded/<때>.txt` 는 「이 파일들은 사람이 녹음했다」는 표시다.
`record-list.mjs` 가 이것을 보고 녹음소 목록에서 뺀다 — 지우지 말 것.

## 잘 녹음하는 요령

- 조용한 방, 입과 마이크 사이 한 뼘. 에어컨 · 선풍기는 끈다.
- 막대(마이크 크기)가 빨개지면 너무 크다 — 조금 떨어진다.
- 낱말은 또박또박 **보통 빠르기**로. 느리게 끄는 것보다 자연스러운 게 배우는 데 낫다.
- 사전 예문 · 듣기는 실제로 말하듯이.
- 한 번에 30분쯤 하고 쉰다. 목이 지치면 소리가 달라진다.
