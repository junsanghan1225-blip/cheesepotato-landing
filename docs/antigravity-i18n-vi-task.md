## 무엇을
`docs/i18n/strings.json` — 사이트 화면 글자 2,007개(`{ en, ko, n }`, 많이 쓰는 차례). **`en` 을 베트남어로** 옮겨
`docs/i18n/vi.json` 에 `{ "영어 원문": "bản dịch" }` 로 더한다(열쇠는 영어 원문 **글자 그대로**). `ko` 는 뜻을 헷갈릴 때 참고만.
- **한 묶음 = `docs/i18n/vi.json` 에 아직 없는 글 중, strings.json 차례대로 앞에서 500개**(화면 글이 늘거나 줄어 번호가 바뀌므로 번호 대신 「아직 없는 것」으로 센다). 마지막 묶음은 남은 것 전부.
- 먼저 `git pull` 로 main 의 최신 strings.json · vi.json 을 받은 뒤 시작한다.
- 이전 묶음 줄은 건드리지 않는다. 한 묶음씩 올린다.

## 꼭 지킬 것
1. **`{0}` `{1}` 자리 표시는 그대로**(숫자 · 이름이 들어가는 자리). 순서는 베트남어에 맞게 바꿔도 된다: `"{0} words"` → `"{0} từ"`.
2. **HTML 태그 그대로**(`<br>` `<b>…</b>` `<em>` `<small>`) — 태그 수와 종류가 같아야 한다.
3. **한국어 학습 내용은 옮기지 않는다** — 영어 원문 안의 한국어 낱말 · 문법(`-아요`, `「가다」`, `TOPIK`, `L3`)은 그대로 둔다.
4. 사이트 이름: `CheesePotato` · `Cheesepotato` → 그대로, `Every Koreans` → 그대로. `Pro` · `TOPIK` · `AI` 는 그대로.
5. 말투: 친근하고 짧게(앱 단추 · 안내 말). 단추는 짧게. 학습자는 「bạn」으로 부른다.
6. 이모지 · 화살표(→ ✓ ·)는 그대로.
