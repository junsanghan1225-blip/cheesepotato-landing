# 안티 그래비티 작업 지시 — 레벨테스트 문제 늘리기 (레벨마다 8 → 20)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해.」

**왜:** 승급 테스트(레벨 L → L+1)가 그 레벨 문제 8개 + 아래 레벨 2개로 10문제를 낸다. 레벨마다 문제가 **8개뿐**이라
다시 보면 똑같은 문제가 나온다. 레벨마다 **20개**가 되게 채운다(`docs/level-plan.md` 6층 ②).

## 문제 모양 — 이미 있는 것과 똑같이

```js
{ lv: 4, q: '내일 비가 ___ 우산을 가져가세요.', options: ['오면', '와서', '오니까', '오지만'], answer: 0,
  why: '조건을 말할 때는 「-(으)면」을 써요.' },
```

- `options` 는 꼭 4개, 서로 달라야 한다. `answer` 는 정답 자리(0부터). 화면에서 섞이므로 정답을 늘 0 에 둬도 된다.
- `why` 는 **반드시** 쓴다. 한 줄, 학습자에게 보이는 말투(-요).
- **같은 레벨끼리 모아 둔다** — 그 레벨 주석(`// ── L4 …`) 아래, 그 레벨의 마지막 문제 뒤에.
- 이미 있는 문제와 **같은 문장을 또 쓰지 않는다**(검사기가 잡는다). 비슷한 문장도 피한다 — 승급 테스트가 다른 문제를 내려는 것이다.

## 레벨마다 무엇을 묻나

| 레벨 | 묻는 것 | 보기 |
|---|---|---|
| L0 | 한글 낱말을 소리 내어 읽기(받침 · 된소리 · 겹모음 ㅘ ㅝ ㅢ 도 섞는다) | 로마자 4개 (`ba-na-na` …) |
| L1 | 이에요/예요 · 은/는 · 이/가 · 인사말 · 아주 흔한 낱말 뜻 · 숫자 | |

## 반드시 지킬 것

1. **정답이 하나뿐이어야 한다.** 오답 보기도 말이 되는 문장이면 그 문제는 버린다.
2. **그 레벨 문법 · 낱말로만 풀려야 한다.** L3 문제에 L5 낱말이 끼면 L3 학생이 문법이 아니라 낱말 때문에 틀린다.
3. 사람 이름은 흔한 것(민수 · 지현)만. 실제 TOPIK 기출 문장을 옮기지 않는다(전부 새로 쓴다).
4. 한자를 쓰지 않는다.
5. 검사기를 고치지 않는다.
