# 반 · 숙제 — QR 로 들어오기 · 구글 캘린더 수업 일정 (운영자 순서)

2026-10-07 운영자 요청: 「선생님이 QR 보내면 로그인만 하면 바로」 · 「반 학생이면 숙제부터」 · 「구글 캘린더와 연결해 수업이 언제 남았는지」 · 「선생님 탭에서 학생 진도 · 숙제 결과」.

## 한 번만 하는 것 (운영자)
1. Supabase → SQL Editor → `db/add_class_calendar.sql` 내용을 붙여 넣고 Run.
2. Supabase → Edge Functions → Deploy a new function → 이름 `class-schedule` → `supabase/functions/class-schedule/index.ts` 내용을 붙여 넣기 → Deploy.
   Verify JWT 는 켠 채로 둔다. 따로 넣을 비밀 값은 없다.

## 반마다 하는 것 (선생님)
1. 사이트 → 반 · 숙제 → 반 카드의 「📱 QR로 학생 부르기」 → 「QR 그림 저장」 → 학생에게 보낸다(카톡 · 왓츠앱 · 인쇄).
   학생은 카메라로 찍고 로그인만 하면 그 반에 들어간다(이름은 계정 이름).
2. 구글 캘린더(컴퓨터) → 왼쪽 그 캘린더 「⋮」 → 「설정 및 공유」 → 맨 아래 **「iCal 형식의 비공개 주소」** 복사.
3. 반 카드 「📅 수업 일정 · 구글 캘린더」 → 주소 붙여 넣기 → (한 캘린더에 여러 반이 있으면) 「이 말이 든 일정만」에 예: `A반` → 저장.
   이제 구글 캘린더에서 수업을 옮기거나 빼면 사이트에도 저절로 바뀐다(최대 10분 늦게).
   - 비공개 주소는 그 캘린더 전체를 읽는 열쇠라 선생님만 본다.
   - **1:1 수업(기본, 「1:1 수업」 칸 켜짐)**: 학생은 **자기 수업만** 본다. 사이트가 학생을 알아보는 길은 둘 —
     ① 구글 캘린더 일정에 학생 메일이 손님으로 초대돼 있다(그 학생이 사이트에 같은 메일로 로그인할 때), 또는
     ② 진도 리포트의 학생 카드 「캘린더에서 찾는 말」에 그 학생 이름(예: 일정 제목 「Korean class - Gali」 → `Gali`)을 저장.
     둘 다 아니면 그 학생에게는 수업이 안 보인다(다른 학생 · 선생님 일정은 절대 안 간다).
   - 여러 학생이 같이 듣는 반이면 「1:1 수업」 칸을 끄면 반 전체가 같은 일정을 본다.
   - **캘린더 파일을 내보내서(.ics · zip) 올리는 것이 아니라 「비공개 주소」를 붙여 넣어야** 일정이 저절로 따라온다 — 내보낸 파일은 그날의 사진일 뿐.

## 수업이 끝난 학생 — 저절로 나가기
- 1:1 반에서 그 학생의 마지막 수업이 **3주보다 오래됐고 앞으로 잡힌 수업도 없으면** 반에서 저절로 빠진다(반 학생 Pro 도 같이 끝).
  학생에게는 아무것도 묻지 않고 첫 화면의 숙제 카드만 사라진다. 숙제 기록은 남고, 다시 QR 로 들어오면 그대로.
- 확인은 그 학생이 사이트를 열 때 · 선생님이 진도 리포트를 열 때 한다.
- 캘린더에서 한 번도 안 맞은 학생(찾는 말을 아직 안 정한 학생)은 건드리지 않는다.
- 바로 빼고 싶으면 학생 카드의 「반에서 빼기」.

## 학생이 보는 것
- 첫 화면 맨 위 「🏫 반 이름 · 숙제 N개 남았어요」 + 다음 수업 + 남은 숙제(기한 가까운 것부터) 「하기 →」.
- 반이 아니면 이 카드는 안 보이고 첫 화면은 그대로.

## 선생님이 보는 것
- 반 카드 「📊 진도 리포트」 → 학생마다 카드(완료율 막대 · 기한 지남 · 평균 점수 · 마지막으로 한 날). 누르면 숙제마다 결과.
  챙겨야 할 학생(기한 지난 숙제)이 맨 위 · 빨간 테두리. 「표로 한눈에 보기」 · CSV 받기는 그대로.
