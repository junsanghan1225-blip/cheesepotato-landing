# 안티 그래비티 작업 지시 — TOPIK II 낱말 채우기 (500개 한 묶음)

> 이 파일과 `AGENTS.md` 를 같이 붙여 넣는다. 첫 줄: 「AGENTS.md 를 먼저 읽고, 이 지시문대로만 해. 이번은 **N묶음**이야.」
> (N 은 운영자가 적는다 — 1, 2, 3 …)

## 왜
「단어」 섹션(`docs/vocab-plan.md`)의 TOPIK I 1,930개는 끝났다. 이제 **TOPIK II(3~6급)** 다.
`vocab/data/topik2.json` 에 씨앗이 있다 — 국립국어원 표준 교육과정 어휘 **3~6급** 중 TOPIK I 에 없는 낱말,
우리 TOPIK II 문항 · 중고급 코스에 자주 나오는 순서로 서 있다. 표제어 · 급수 · (있으면) 사전 영어 뜻 · 길잡이말(`hint`)만
있는 **C급**이다. 이것을 **B급**으로 올린다. 모양은 `docs/vocab-schema.md`.

TOPIK I 네 묶음에서 배운 것을 그대로 지킨다(아래 「TOPIK I 에서 고친 것」).

> **11묶음은 잘했다** — 지킬 칸 그대로. `rel` 4개만 뺐다. 모두 **소리만 같은 다른 낱말**에 이은 것이다: 악↔선(우리 자료의 「선」은 맞선) ·
> 생↔사(「사」는 사다) · 식=의식(의식은 consciousness) · 신바람=흥. **`rel` 에 넣기 전에 그 낱말이 자료에서 무슨 뜻(`en`)인지 본다** — 한 글자 낱말은 특히.
>
> **10묶음 — `src` 를 고쳤다**(36개에서 `krdict` 를 뺐다). `src` 는 출처 표시라 **절대 고치지 않는다** — 영어 뜻이 국립국어원 사전에서 왔다는 기록이다. Claude 가 되돌렸다.
>
> **8묶음은 지금까지 가장 좋았다** — `rel` 에서 10개만 뺐다(답변↔질문 · 본질=근본 · 막상=실제로 …). 이대로 한다.
>
> **7묶음은 6묶음보다 좋아졌다.** 그래도 `rel` 에서 반대말 49개 · 비슷한 말 81개를 뺐다 — 월세↔전세 · 외과↔내과 · 처녀↔총각 · 한국인↔외국인(짝꿍),
> 저축=예금 · 종교=신앙 · 자주색=보라색 · 강의실=교실(뜻이 다름), 코피=비출혈 · 창가=창변 · 용=용호(없는 말). 계속 「확실한 것만, 모르면 비움」.
>
> **6묶음은 지킬 칸을 다 지켰다(잘했다).** 대신 **`rel` 이 엉망이었다** — Claude 가 반대말 97곳 · 비슷한 말 210개를 뺐다.
> 7묶음부터 `rel` 은 **사전에서 확실한 것만, 없으면 비운다**(대부분의 낱말은 비어 있는 게 맞다):
> - `ant` 에 짝꿍 말을 넣었다 — 남미↔북미 · 신사↔숙녀 · 벽시계↔손목시계 · 설↔추석 · 아침밥↔저녁밥 · 공주↔왕자. **정반대만**(금연↔흡연 · 로그인↔로그아웃).
> - `syn` 에 없는 말을 지어냈다 — 바둑=기둑 · 분필=백필 · 양배추=가두배추 · 뷔페=부챗식당 · 사자=백수의 왕 · 맨발=적족.
>   뜻이 다른 말도 넣었다 — 사건=사고 · 성당=교회 · 시험지=답안지 · 삶다=데치다 · 동양=아시아. 표제어 자신 · 기호(g · $)도 넣지 않는다.
>
> **⚠ 4 · 5묶음에서 어긴 것 (6묶음부터 꼭 지킨다):** 이미 B 인 낱말 **300개의 `level` 을 바꿨다**(가급적 5 → 4 …),
> **채워진 `en` 374개에 뜻을 덧붙였다**(navy blue → navy blue; deep blue), 빈 `hint` 를 10곳 만들었다. Claude 가 전부 되돌렸다.
> `level` · `hint` · 채워진 `en` 은 **어떤 줄에서도** 바꾸지 않는다 — 급수는 국립국어원 표준 교육과정 값이다.
> 이번 묶음의 C 줄 500개 **밖은 한 글자도 건드리지 않는다.** 두 묶음을 한꺼번에 하지 말고 한 묶음씩 올린다.
>
> **3묶음도 잘했다.** 한 가지만: `vocab-topik2.js` · `vocab-topik2-ex/`(예문 조각) 는 **만들지도 커밋하지도 않는다**(`node tools/build-vocab.mjs` 를 돌리지 않는다) —
> Claude 가 main 기준으로 굽는다. 커밋에는 `vocab/data/topik2.json` 하나만. (검사기가 「vocab-topik2.js 가 원본과 다르다」고 해도 그대로 둔다.)
>
> **2묶음은 완벽했다** — 고칠 것 없음(한자 326개 모두 맞음, 건너뛴 20개도 채움). 3묶음부터 그대로 한다.
>
> **1묶음은 잘했다** — 예문 평균 24글자, 둘째 예문이 전부 글말, 지킬 칸 그대로. 두 가지만 고친다(2묶음부터):
> 1. **한자:** 고유어에 뜻이 같은 한자를 붙였다 — 먼지 → 埃 · 뿌리 → 根 · 빛 → 光 · 숲 → 林 · 시스템 → 制度 · 양 → 気(일본 글자).
>    **한자어만**(소리가 한자에서 온 말) 적고, 한자 글자 수는 음절 수와 같아야 한다(경제 → 經濟, 경제적 → 經濟的).
>    같은 소리의 다른 한자(점 = 點 · 店)는 **이 낱말의 뜻(en)에 맞는 것**으로. 검사기가 글자 수를 본다. Claude 가 22곳을 고쳤다.
> 2. **건너뛴 20개는 낱말이다:** 안정 · 약품 · 여기다 · 영양 · 예정 · 원래 · 원인 · 이루다 · 이하 · 일상생활 · 자료 · 잠기다 ·
>    전자 · 점퍼 · 조리 · 조상 · 주요 · 즉시 · 직장인 · 통 — C 로 둔 것은 **낱말이 아닐 때만**이다. 이번 묶음 맨 앞에서 채운다.

## 이번 묶음: **grade 가 `"C"` 인 줄 중 앞 500개**
B 줄이 끝난 뒤의 C 줄부터 500개만 한다. 이미 B 인 줄은 건드리지 않는다.

낱말마다:
1. **pos** — 비었으면 채운다. **en** — 비었으면 채운다(사전식 짧은 영어 뜻). 채워져 있으면 고치지 않는다.
2. **topics** — `vocab/taxonomy.json` 에서 **1~3개**, 「대분류/소분류」 꼴. 맞는 칸이 없으면 가장 가까운 것 하나 +
   PR 설명의 「새 칸이 필요한 낱말」. taxonomy 파일은 고치지 않는다.
3. **purposes** — `topik2` 는 그대로 두고, 맞으면 더한다: `eps`(공장 · 건설 · 농축산 · 안전 · 근로 조건) · `work`(사무 · 직장) ·
   `life`(한국 생활 · 행정 · 은행 · 집) · `medical`(병원 · 약) · `campus`(대학) · `kculture`(드라마 · 음악 · 문화) · `travel`.
   **`intro` 는 붙이지 않는다.** 붙일 목적이 없으면 `topik2` 하나만 둔다 — 억지로 붙이지 않는다.
4. **en_simple** — 학습자용 쉬운 영어 뜻 1~4단어. `en` 은 고치지 않는다.
5. **examples** — **두 개**로 맞춘다(이미 하나 있으면 하나 더). TOPIK II 는 초급과 다르다:
   - **첫째는 말하는 문장**(해요체), **둘째는 글의 문장**(-ㄴ다/-는다 · -습니다 — 신문 · 안내문 · 보고서 투).
     TOPIK II 쓰기 · 읽기가 글말이라서 둘 다 필요하다.
   - 문법은 급수에 맞게: 3~4급 낱말은 중급 문법(-는데 · -(으)니까 · -기 때문에 · -도록 · -게 되다 · -는 것 …)까지,
     5~6급 낱말은 고급 문법 · 한자어 표현(-에 따르면 · -(으)ㄹ 뿐만 아니라 · -에 비해 …)도 된다.
   - 낱말 **하나를 배우는 문장**. 한 문장에 어려운 낱말을 여럿 넣지 않는다. 빈칸 빼고 **30글자 안팎**(검사기는 32글자를 넘으면 짚는다).
   - 표제어가 문장에 들어가야 한다(활용형이면 된다). `en` 번역을 반드시 단다.
   - `hint`(길잡이말, 예: 「경제가 발전하다」)가 있으면 그 짝말을 살려 쓴다.
   - 새로 쓴다 — 드라마 · 노래 · 기사 · **기출 문장**을 옮기지 않는다. 실제 기관 · 통계 · 사람 이름을 지어내지 않는다.
6. **hanja** — 한자어이고 **확실할 때만** 한자를 적는다(경제 → `經濟`, 환경 → `環境`). 조금이라도 헷갈리면 비운다 —
   틀린 한자를 외우게 하느니 없는 편이 낫다. 고유어 · 외래어는 비운다.
7. **rel** — 확실한 것만: `syn`(비슷한 말) · `ant`(반대말) · `hon`(높임말). 모르면 비운다.
   - `ant` 는 뜻이 **정반대인 짝**만(증가↔감소 · 찬성↔반대). 짝꿍 말(남편·아내 · 수입·수출이 아닌 것)은 넣지 않는다.
   - `hon` 은 **이 낱말의 높임말**이다. 이미 높임말인 낱말에는 적지 않는다.
   - `syn` 은 같은 급수 안팎의 말로. 뜻이 넓게만 비슷한 말(「관계 = 사이」가 아닌 것)은 넣지 않는다.
8. **grade** — 위를 다 채웠으면 `"B"` 로 바꾼다.
9. **level** — 고치지 않는다(모두 표준 교육과정 급수 `std` 가 있다).

**손대지 않는 것:** `id` · `head` · `level` · `freq` · `src` · `std` · `hint` · 채워진 `en`, 이미 B 인 줄, 이번 500개 뒤의 C 줄.
낱말이 아닌 것(어미 조각 · 접사 · 사람 이름)이 보이면 **grade 를 C 로 두고** 건너뛰고 PR 설명에 적는다 — 뜻을 지어 붙이지 않는다.

## TOPIK I 에서 고친 것 (이번에도 이렇게)
- 낱말이 아닌 줄에 뜻을 지어 붙이지 않는다(「보 → weir」 「타 → others」 — Claude 가 64줄을 뺐다).
- 반대말 · 높임말: 짝꿍 말(이것↔저것 · 작년↔내년 · 고모↔이모 · 치마↔바지)은 반대말이 아니다. 높임말을 거꾸로 적지 않는다(말씀 → 말 ✗).
- 채워진 `en` 은 고치지 않는다 — 고칠 만하면 고치지 말고 PR 설명의 「영어 뜻이 이상한 낱말」에 적는다.

## 순서
```bash
git checkout main && git pull origin main
git checkout -b vocab-topik2-bN          # N = 묶음 번호
# C 줄 앞 500개 채우기 — 한 줄에 낱말 하나 모양을 지킨다
node tools/check-vocab.mjs --all          # 「고쳐야 할 것」 0 · 「길다」 0
node tools/check-vocab.mjs --base origin/main   # 지킬 칸(level · src · hint · 채워진 en · 다른 줄)을 건드렸으면 여기서 걸린다 — 0 이어야 한다
git add vocab/data/topik2.json
git commit -m "vocab: TOPIK II batch N to grade B"
git pull origin main
node tools/stamp.mjs && node tools/stamp.mjs --check
git push -u origin vocab-topik2-bN
```
**`git push` 까지 해야 끝이다** — 올리지 않으면 운영자와 Claude 가 볼 수 없다.
