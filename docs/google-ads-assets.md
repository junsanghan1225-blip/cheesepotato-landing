# 광고에 넣을 글

콘솔에 붙여넣을 것만 모았다. 왜 이렇게 쓰는지와 캠페인 설계는
`google-ads.md` 에 있다.

**글자 수는 세어서 맞춰 두었다.** 구글은 넘으면 저장을 안 받아 준다.
고칠 때도 세어 볼 것 — 헤드라인 30자, 긴 헤드라인·설명 90자다.

**여기 적힌 숫자는 전부 첫 화면에 적힌 것과 같다.** 광고가 랜딩 페이지보다
크게 말하면 심사에서 걸리고, 걸리지 않더라도 들어온 사람이 속았다고
느낀다. 사이트의 숫자를 고치면 여기도 같이 고칠 것.

---

## 어떻게 짜는가 — 문장보다 조합이 먼저다

구글은 여기 적은 것 가운데 **셋을 골라 「A ｜ B ｜ C」로 붙여** 내보낸다.
그래서 한 줄 한 줄을 다듬는 것보다 **어느 셋이 붙어도 말이 되는가**가 훨씬
중요하다. 같은 말을 하는 열다섯 개를 넣으면 어떤 조합이 나와도 같은 광고가
된다.

### 하나만 지킬 규칙

> **놀이터는 문이고, 체계는 안이다.**

들어오라고 부르는 말(놀이터)과 들어와서 헛걸음이 아니라는 증거(체계)는 **둘
다 있어야 한다.** 문만 보이면 가벼워 보여서 진지한 학습자가 안 누르고, 안만
보이면 흔한 학원 광고가 되어 아무도 안 누른다.

그래서 칸마다 맡은 일을 다르게 둔다.

| 자리 | 하는 일 | 아래 묶음 |
| --- | --- | --- |
| 첫째 | **이게 뭔지** — 검색어를 되비춘다 | ① |
| 둘째 | **어떤 곳인지** — 분위기 | ③ |
| 셋째 | **믿을 만한지** — 체계와 숫자 | ④ ⑤ |

**셋 가운데 하나는 반드시 ② 나 ④ 에서 나오게 한다.** 놀이터 말(③)이 둘
이상 붙으면 공부하는 곳으로 안 보인다. 가장 좋은 것은 ② — 한 줄에 둘을
다 담아서, 어느 자리에 놓여도 균형이 무너지지 않는다.

**고정(pin)은 한 칸만.** ① 에서 하나를 골라 첫째 자리에 고정하면 「이게
뭔지」는 늘 보장되고, 나머지 두 칸은 구글이 실험한다. 세 칸을 다 고정하면
실험이 없어져 광고 효력 점수가 떨어진다.

### 광고그룹마다 말투를 바꾼다

**TOPIK 그룹에는 놀이터 말투(③)를 쓰지 않는다.** 시험이 두 달 남은 사람에게
놀이터라고 하면 미덥지 않다. 그쪽은 ① ④ ⑤ ⑥ 으로만 채운다. 놀이터 말은
「learn korean free」 · 「how to self study korean」처럼 **아직 정하지 못한
사람**이 치는 검색어에서 힘을 쓴다.

## 그림

P-Max 자산 그룹은 **가로 1장과 정사각 1장을 반드시 받는다.** 로고 칸은 그림
칸과 따로다. 다 구워서 `assets/ads/` 에 두었으니 그대로 올리면 된다.

| 파일 | 어디에 | 치수 |
| --- | --- | --- |
| `assets/ads/landscape-1200x628.png` | 가로 이미지 (필수) | 1200×628 (1.91:1) |
| `assets/ads/square-1200x1200.png` | 정사각 이미지 (필수) | 1200×1200 (1:1) |
| `assets/ads/portrait-960x1200.png` | 세로 이미지 (선택) | 960×1200 (4:5) |
| `assets/ads/logo-square-1200x1200.png` | **로고** 칸 | 1200×1200 (1:1) |
| `assets/ads/logo-wide-1200x300.png` | **로고** 칸 | 1200×300 (4:1) |

세로는 없어도 되지만 넣으면 지면이 늘어난다 — 유튜브와 디스커버가 세로
자리를 따로 가진다.

### 무엇을 그렸나

**획을 더하면 소리가 세진다** — ㄱ→ㅋ, ㄴ→ㄷ→ㅌ, ㅁ→ㅂ→ㅍ. 이 그림 하나가
문과 안을 같이 말한다. 글자 모양은 놀이처럼 보이고, 화살표로 이어진 줄은
**규칙이 있다**는 말이다. 블로그의 「한글은 정말 한나절이면 읽나」가 하는
이야기를 그대로 그림으로 옮긴 것이라, 눌러 들어온 사람이 같은 이야기를
다시 만난다.

글자를 거의 안 넣었다. 구글은 이 그림을 지면에 맞춰 **제멋대로 잘라 쓴다**
— 글이 많으면 잘려서 말이 안 되는 채로 나간다. 상표와 주소만 발치에 둔다.

### 다시 굽기

색이나 로고를 고쳤으면 다시 구워야 광고도 따라 바뀐다.

```
npm i playwright && npx playwright install chromium
node tools/build-ad-images.mjs
```

판은 `tools/ad-images.html` 이다 — 브라우저로 열어 보면 그대로 보이므로,
고칠 때는 거기를 고치고 다시 구우면 된다.

## 검색 테마 / 키워드

P-Max 는 「검색 테마」, 검색 캠페인은 「키워드」라 부른다. 글자는 같이 쓴다.
검색 캠페인이라면 **구문검색(`"..."`)으로 시작**할 것 — 확장검색은 전환
자료가 쌓이기 전에 돈을 태운다.

| 광고그룹 | 키워드 | 보낼 곳 |
| --- | --- | --- |
| 한글 배우기 | `learn hangul` · `korean alphabet` · `how to read korean` · `learn korean for beginners` | `/#learn/courses` |
| TOPIK | `topik practice test` · `topik 1 reading` · `topik listening practice` · `korean proficiency test app` · `topik study materials` | `/#learn/topik` |
| 문법 | `korean grammar` · `korean particles` · `eun neun i ga difference` | `/sentence/` |
| 무료·독학 | `learn korean free` · `free korean lessons` · `how to self study korean` · `best app to learn korean` | `/` |
| 어휘 | `korean vocabulary` · `korean flashcards` · `korean dictionary online` | `/#learn/library` |

**`korean` 한 단어만 넣지 말 것.** 그것만으로는 K-pop·드라마·여행·번역이
전부 들어온다. 배우려는 뜻이 담긴 말(`learn` · `study` · `grammar` ·
`TOPIK` · `practice`)과 반드시 짝지을 것.

## 제외 키워드 — 첫날부터

```
apk, mod, crack, download pdf, 기출문제 pdf, answer key, cheat,
jobs, hiring, 채용, salary, teacher jobs, tutor 구인,
translate, translator, translation, 번역,
netflix, drama, bts, kpop, lyrics, webtoon,
university, 유학, visa, 비자, 어학연수,

```

첫 2주는 **매일 검색어 보고서를 보고 여기에 더할 것.** 광고그룹 이름보다
이 목록이 성과를 더 많이 바꾼다.
